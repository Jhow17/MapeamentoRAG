# ML models

Machine learning (ML) models are computational algorithms or statistical models that are designed to perform specific tasks without being explicitly programmed. These models are trained on data to learn patterns, relationships, and dependencies within the data, and then they can make predictions or decisions based on new, unseen data.

You can integrate ML models into an Enterprise Data Catalog to enhance the catalog's capabilities in terms of data discovery, metadata management, and data governance. They are another asset that data users have access to and need to be cataloged and governed. ML models are seamlessly integrated into the Enterprise Data Catalog module, providing data users with a structured and governed environment to discover, understand, and utilize these valuable assets.

### Integrating ML models in the Enterprise Data Catalog

You can ingest ML models using [EDC ingestion](/v1/docs/edc-ingestion) via custom recipes or the LookML plugin.

To access ML models in the Enterprise Data Catalog:

1. In Securiti, open Enterprise Data Catalog module.
2. Click the **ML Models** tile to open the list of ML models integrated into the Enterprise Data Catalog.
3. Click on any model to open its details.

### Managing ML model associations

Use the right panel to add, edit or delete associations for the ML models. Read managing associations for more information.

Machine Learning (ML) refers to the use of algorithms to automatically detect, classify, and protect sensitive information (like personal, financial, or health data) across large and complex data environments. ML helps improve accuracy and scalability in identifying sensitive data patterns, reducing manual effort and enhancing data security and compliance.
