# EDC Dashboard - New Experience

You can view comprehensive business insights with the **New Experience** tab of the EDC Dashboard.

![EDC dashboard - new experience](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/edc dashboard - new experience tab.png)

The dashboard displays the following information.

| Insight | Description |
| --- | --- |
| Domains | Logical groupings of data assets based on business areas or functions. |
| Platforms | Source systems or technologies where data assets are stored or ingested from. |
| Data Quality – Checkpoint Score | A metric indicating the quality and reliability of data based on defined validation checks. |
| Governance Status per Domain | The compliance or governance state of assets grouped within each domain. |
| Assets per Owner | Distribution of data assets based on assigned owners or stewards. |
| Top Glossary Terms | Most frequently used or referenced business terms in the catalog. |
| Most Popular Assets | Data assets with the highest user engagement or access frequency. |
| Most Edited Assets | Data assets that have undergone the most updates or modifications recently. |

> [!NOTE]
> Note
> 
> The colon : is a reserved character in the search field. If the glossary term or domain name you are searching for contains a colon, wrap the search term in double quotes to return accurate results. For example, to search for a term named Customer:ID, enter Customer:ID in the search field.

### Filtering the dashboard

You can filter the dashboard by Domain or Owner, as shown below. Both filters support search, making it easier to locate specific domains or owners. When you apply a filter, all sections of the dashboard update to reflect your selection, including the following:

- Tile counts for Domains, Platforms, and Assets per Owner
- Onion graphs for Domains and Platforms
- Bar chart for Governance Status per Domain
- Top-list recommendations for Glossary Terms, Most Popular Assets, and Most Edited Assets
- Data Quality Checkpoint Score trends graph

To filter the dashboard:

From the upper section of the New Experience tab, select Domain or Owner, then search for and select the value you want to apply, as shown below.

![Dashboard displaying data catalog metrics, including domains, platforms, and data quality scores.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Final - Domain .png)

![Overview of the Enterprise Data Catalog with highlighted owner selection and data quality metrics.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Owners.png)

> [!NOTE]
> Note
> 
> Both Domain and Owner filters support multi-select. You can apply both filters simultaneously to further narrow down your dashboard view.

### Exporting the dashboard as a PDF

You can export the EDC Dashboard as a PDF, including the tile matrix and all charts, making it easier to share catalog insights and report on governance status across your organization.

To export the dashboard as a PDF:

- Apply the desired filters, then from the upper-right corner of the page, click **Options** (three dots) > **Generate PDF**, as shown below. A PDF file containing the current dashboard view is generated for download.

![Overview of data catalog showing domains, platforms, and data quality scores.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Generate PDF.png)
