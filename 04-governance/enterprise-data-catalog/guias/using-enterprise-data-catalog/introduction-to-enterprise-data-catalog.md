# Introduction to Enterprise Data Catalog

In the modern data-driven landscape, organizations require centralized metadata repositories that serve as authoritative sources for managing their data assets. These repositories are indispensable for maintaining comprehensive inventories of data, pinpointing its location, provenance, and impact, and gaining valuable insights into its attributes, including its nature, significance, intended applications, and sensitivity.

Securiti’s Enterprise Data Catalog module lets your users easily find, understand, trust, and access the metadata about the data they need, as well as lets them secure and govern the processes around their metadata.

The module focuses on the comprehensive cataloging and classification of your organization's data assets. It automatically identifies, classifies, and tags sensitive data, ensuring that it is properly managed and protected in accordance with data privacy regulations and your company policies.

If your environment uses multiple organizations, ensure that the relevant data systems and assets are configured under the Default Organization to be discoverable in EDC.

### Enterprise Data Catalog key features

| Feature | Description |
| --- | --- |
| Automated discovery | Scans and discovers data across various repositories and locations within an organization, providing a holistic view of data assets. |
| Data classification | Automatically classifies data, making it easy to identify sensitive information, such as personally identifiable information (PII), intellectual property, or financial data. |
| Data curation | Maps data assets to glossary terms, helping curation of the catalog. |
| Data lineage | Tracks the movement and transformation of data, enhancing transparency and understanding of data provenance and its impact. |
| Search and data discovery | Searches and discovers data assets easily and quickly, thanks to metadata tagging and intelligent search capabilities. This promotes data understanding and usability. |
| Data quality assessment | Ensures that data meets specific standards, expectations, and criteria, thereby improving data reliability and trustworthiness. |
| Business glossary | Serves as a centralized repository for defining and maintaining business-specific metadata such as terms, standards, policies, definitions, and descriptions related to data assets. This ensures clear communication and a shared understanding of data terminology among all stakeholders. |
| Data usage tracking | Monitors and reports on how data is accessed and used, aiding compliance and security efforts. |

#### Example

Imagine a financial services company, **FinanceSecure**, which deals with sensitive financial data, and must adhere to strict compliance regulations, including GDPR and financial industry standards. They face the challenge cataloging their extensive data assets with respect to their data terminologies.

### Securiti's Enterprise Data Catalog in action:

| Feature | Description |
| --- | --- |
| Data discovery | FinanceSecure has data scattered across various repositories, including databases, cloud storage, and on-premises systems. With Securiti's Enterprise Data Catalog, FinanceSecure can automatically scan and discover data in these repositories. This feature provides a holistic view of their data assets, which is crucial for a financial institution that needs to manage a vast amount of data assets to comply with various regulations. |
| Data classification | FinanceSecure deals with sensitive financial data and customer information. Securiti's data classification feature automatically identifies and links to its corresponding glossary term critical data elements, such as PII, financial data, and intellectual property. This automation ensures that critical data is protected and helps FinanceSecure maintain compliance with data privacy regulations. |

| Data lineage | FinanceSecure relies on accurate and trustworthy data for decision-making. Data lineage capability provides a comprehensive view of how data moves through a system from its origin to its consumption, while also capturing metadata about the data itself. This ensures transparency and data governance, enabling FinanceSecure to trace data back to its source and assess its reliability, which is crucial for financial reporting and auditing. |
| Search and data discovery | The financial institution needs a quick and efficient way to search for data assets. With metadata classification and intelligent search capabilities, Securiti's Enterprise Data Catalog simplifies data discovery. FinanceSecure uses a data quality assessment feature to ensure that data meets specific standards and expectations. That’s how Securiti's Enterprise Data Catalog module helps FinanceSecure manage its vast and sensitive data assets efficiently, maintain data quality and compliance, and ensure the security and privacy of financial data. All of which are critical for a multinational financial services corporation.

WCAG is a set of internationally recognized guidelines developed by the World Wide Web Consortium (W3C) to ensure web content is accessible to people with disabilities. It provides criteria for designing and creating websites that are usable by everyone, including those with auditory, cognitive, neurological, physical, speech, and visual disabilities.

Data classification is the process of organizing data into categories based on its type, sensitivity, or value to an organization. It helps identify and label data (e.g., public, internal, confidential, or highly sensitive) to apply appropriate security, privacy, and compliance controls.

Personally Identifiable Information (PII) refers to an information that is highly sensitive in nature as it can be used to accurately identify, contact, or locate an individual. This includes data elements such as names, addresses, social security numbers, email addresses, and biometric records.
