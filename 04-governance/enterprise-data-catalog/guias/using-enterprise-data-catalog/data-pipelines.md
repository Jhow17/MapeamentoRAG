# Data pipelines

A data pipeline is a structured sequence of data jobs that execute in a specific order, often based on dependencies between tasks. This structure is typically represented as a DAG (Directed Acyclic Graph), meaning:

- Directed – The tasks execute in a specific direction (one after another).
- Acyclic – There are no loops, ensuring the flow progresses without repetition.

### CRUD operations for managing pipeline properties

You can perform CRUD operations on pipeline properties, just as you can with other EDC entities like glossaries and datasets. With this ability, you can easily add new properties, modify existing ones, or remove outdated or unnecessary properties. This streamlines the process of keeping pipeline properties up to date, ensuring that the data remains relevant and useful.
