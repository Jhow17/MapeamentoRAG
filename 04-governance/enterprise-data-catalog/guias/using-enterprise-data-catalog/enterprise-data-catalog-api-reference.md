# Enterprise Data Catalog API reference

The Enterprise Data Catalog API documentation lets you programmatically interact with your organization's metadata graph using GraphQL and REST APIs, manage catalog entities including datasets, glossary terms, domains, tags, and data products, ingest metadata from sources such as Snowflake, Databricks, Tableau, and Salesforce, run data quality checks, track inferred lineage, and govern catalog entities across your enterprise.

This API documentation includes operations such as:

- Get, update, deprecate, or bulk delete datasets.
- Create and manage glossary terms, term groups, and glossary relationships across entities and domains.
- Create, execute, and roll back EDC ingestion sources and manage ingestion secrets.
- Create, edit, and execute data quality templates, expectations, and checkpoints, and retrieve data quality findings.
- Create, update, and manage inferred lineage jobs and retrieve lineage details and execution results.
- Create, set, move, and delete domains to manage domains and data products.
- Add, remove, and batch manage tags on catalog entities.
- Attach ownership, add governance flags and governance status, and export entity aspects.
- Post and retrieve comments via the Messaging Center and manage data catalog channels.

Use the Enterprise Data Catalog [REST API documentation](https://securiti-doc-router.securiti.ai/modules/data-catalog/apidocs/index.html) to explore and test Enterprise Data Catalog APIs, review HTTP endpoints, GraphQL mutations and queries, JSON request and response formats, query parameters, API schemas, authentication methods, and sample API requests, and access the Postman collection for supported GraphQL and REST API calls.
