# EDC Dashboard

The EDC dashboard provides a centralized view to discover, explore, and manage data assets across the organization. Securiti provides two views for your EDC Dashboard:

| View | Description |
| --- | --- |
| [Classic View](/latest/docs/edc-dashboard-classic) | The **Classic** tab features a powerful search bar for finding assets using names, descriptions, tags, or URNs, along with quick access to governance modules like Glossary, Domains, and Data Products. The dashboard highlights key metrics such as datasets, pipelines, and ML models, and includes widgets for domains and platforms to help assess data distribution. It also surfaces recently viewed, edited, and popular assets, along with top tags and glossary terms for easier navigation. |
| [New Experience](/latest/docs/edc-dashboard-new-experience) | The **New Experience** tab provides business insights such as Data Quality checkpoint scores, governance status by domain, asset ownership distribution, and visibility into top glossary terms, most popular assets, and most edited assets to support better decision-making and data governance. |
