# User personas

Use the following table to understand the roles of different types of users and what they are responsible for in the Enterprise Data Catalog module. From the Responsibilities column, use the links of the relative help topics to learn more about the responsibilities of the following roles.

| Role | Responsibilities |
| --- | --- |
| Data stewards | - Data stewards are contributors to the catalog. They are often [tasked with ensuring the quality](/v1/docs/data-quality-framework), security, understanding, and compliance of data. - They use the Enterprise Data Catalog to manage metadata (for example, [datasets](/v1/docs/datasets), [business glossaries](/v1/docs/glossary-terms)), enforce data governance policies, and document data lineage. - Data stewards monitor [data usage patterns](/v1/docs/usage-analytics) and conduct audits to identify any deviations from established policies. - Promotes data literacy by maintaining a curated Enterprise Data Catalog. |
| Data quality managers | - [Defines and implements data quality standards](/v1/docs/data-quality-framework). - Conducts regular data quality audits to assess how your company data is fit for the given purpose. - Identifies and rectifies data errors, inconsistencies, and anomalies. |
| Data analysts | - Data analysts are data consumers and readers of the catalog. - They use Enterprise Data Catalog to search for and explore available [datasets](/v1/docs/datasets). They leverage features like metadata search, [tagging](/v1/docs/tags), and categorization to discover relevant data sources. - They rely on metadata and data lineage information to understand the context and quality of the data. |
| Data engineers | - Data engineers are not just data consumers, and readers of the catalog, but also contributors. - They build, monitor, and troubleshoot ETL pipelines. - They create data warehouses or data lakes to store and organize data efficiently. - They use the Enterprise Data Catalog to discover and understand [data sources, schemas, and structures](/v1/docs/datasets). - They may also use it to identify data transformation processes and dependencies. - Data engineers are also tasked with ensuring and fixing data quality. |
| ML engineers | - Designs and develops [ML](/v1/docs/ml-models) and GenAI models. - Deploys models into production. - Fine tunes and optimizes model performance. |
