# Charts

A chart represents a single data visualization derived from a dataset. It provides insights into the data it represents.

### Managing chart associations

Use the right panel to add, edit or delete associations for the charts. Read managing associations for more information.

### CRUD operations for managing chart properties

You can perform CRUD operations on the properties of charts, just as you can with other EDC entities like glossaries and datasets. With this ability, you can easily add new properties, modify existing ones, or remove outdated or unnecessary properties. This streamlines the process of keeping chart properties up to date, ensuring that the data remains relevant and useful.
