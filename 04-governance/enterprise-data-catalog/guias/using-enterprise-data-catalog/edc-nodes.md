# EDC nodes

If you are subscribed to the Workflows module, you can create governance workflows. Securiti has a [Data Catalog Trigger](/v1/docs/trigger-nodes-data-catalog) node and a [Data Catalog Regular node](/v1/docs/data-catalog) in its Workflows module.

The Data Catalog Trigger node lets you create triggers to monitor and respond to any changes made to metadata within the EDC. Additionally, the Data Catalog node lets you update the EDC by incorporating metadata collected throughout the workflow, such as new recommendations for asset descriptions, certifications, or terms.
