# Dashboard

A dashboard is a collection of charts used for data visualization. It serves as a central place to present and analyze key metrics and insights. Dashboards can include multiple charts, which are visual representations of datasets.

### Managing dashboard associations

Use the right panel to add, edit or delete associations for the dashboard. Read managing associations for more information.

### CRUD operations for managing dashboard properties

You can perform CRUD operations on the dashboard, just as you can with other EDC entities like glossaries and datasets. With this ability, you can easily add new properties, modify existing ones, or remove outdated or unnecessary properties.
