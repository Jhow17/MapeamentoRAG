# Using Enterprise Data Catalog

[Enterprise Data Catalog](/v1/docs/introduction-to-enterprise-data-catalog) is a centralized data explorer that lets you register datasets manually and automatically, including all the technical and classification metadata, and organize them. Using Enterprise Data Catalog, you can search for any registered dataset and the related information. The catalog offers a variety of features and widgets to provide easy access to your data in an organized way.
