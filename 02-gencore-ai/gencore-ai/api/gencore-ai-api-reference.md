# Gencore AI API reference

The Gencore AI API documentation lets you create and manage AI pipelines, configure supported AI models and providers, manage vector databases and embeddings, execute pipeline queries, and retrieve pipeline metadata and results.

This API documentation includes operations such as:

- Create and manage GenAI pipelines
- Configure LLM providers, embedding providers, and vector databases
- Execute pipeline queries and retrieve responses
- View pipeline configurations and metadata
- Monitor pipeline execution, performance, and status
- Create and manage firewall profiles, policies, rules, and exemplars
- Retrieve and evaluate standalone firewall profiles
- Configure and manage web widgets
- Configure and manage Securiti-hosted and self-hosted user portals
- Configure external OAuth providers
- Configure external storage providers
- Integrate and manage messaging applications such as Slack and Microsoft Teams

Use the Gencore AI REST API documentation to explore and test [Gencore AI APIs](https://securiti-doc-router.securiti.ai/modules/gencore/apidocs/index.html) and [Gencore AI custom URL APIs](https://securiti-doc-router.securiti.ai/modules/gencore/genia_apidocs/index.html), review HTTP endpoints, JSON request and response formats, query parameters, API schemas, authentication methods, sample API requests, and access the Postman collection for supported Gencore AI operations.
