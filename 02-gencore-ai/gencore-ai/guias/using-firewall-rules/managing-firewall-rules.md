# Managing firewall rules

You can perform the following actions on a firewall rule:

- [View](/v1/docs/managing-firewall-rules#viewing-a-firewall-rule)
- [Edit](/v1/docs/managing-firewall-rules#editing-a-firewall-rule)
- [Clone](/v1/docs/managing-firewall-rules#cloning-a-firewall-rule)
- [Delete](/v1/docs/managing-firewall-rules#deleting-a-firewall-rule)

### Viewing a firewall rule

1. On the list of rules, locate the card for the rule you want to view.
2. To the right side of the card, choose **Options** (three dots), and select **View**.

### Editing a firewall rule

1. On the list of rules, locate the card for the rule you want to edit.
2. To the right side of the card, choose **Options** (three dots), and select **Edit**.
3. Update the rule as required.
4. To save changes, click **Save Changes**.

### Cloning a firewall rule

1. On the list of rules, locate the card for the rule you want to clone.
2. To the right side of the card, choose **Options** (three dots), and select **Clone**. A dialog box displays with the name of the rule to be cloned as the name of the original rule with the word “duplicate” added to it. You can edit the name as required.
3. To clone the rule, click **Clone**.

### Deleting a firewall rule

1. On the list of rules, locate the card for the rule you want to delete.
2. To the right side of the card, choose **Options** (three dots), and select **Delete**.
3. To confirm deletion, on the confirmation popup box, click **Delete Rule**.
