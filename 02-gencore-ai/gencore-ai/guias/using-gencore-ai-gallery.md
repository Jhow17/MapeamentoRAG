# Using Gencore AI Gallery

The Gencore AI gallery contains all the pipeline templates, preconfigured providers and relevant models, and firewalls.

To open the **Gallery** section, in Securiti, open **Gencore AI** and select **Gallery**.

![Gallery of Claude AI models showcasing various generative language models and their features.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/GenAI-gallery.png)

The Gencore AI gallery contains all the preconfigured providers and relevant models. The left side panel shows the following:

- Templates
- [Model cards for LLM and embedding models](/latest/docs/using-gencore-ai-gallery#model-cards-for-llm-and-embedding-models)
- Vector storage
- Firewalls

When you select a category, Securiti displays the relevant models or provider list on the right.

The Gencore AI Gallery offers the following capabilities:

- You can search for a provider and relevant model.
- You can view the models in a Grid or Tabular format.

To view model card details, click the relevant model card. The model card details include the following information:

- Utility, Safety and Trustworthiness metrics
- Input and output details
- Use cases
- Language support
- Token details
- Access details
- Costing and license information
- Architecture and technical details
- Training and data gathering
