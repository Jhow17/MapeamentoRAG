# Searching for and filtering pipelines

You can search for a pipeline and filter pipelines from the GenAI Pipelines dashboard.

### Searching for a pipeline

1. On the **GenAI Pipelines** dashboard, click in the search box.
2. Enter the name of the pipeline you want to search.

### Filtering pipelines

The pipelines list filter lets you select various options to specify the criteria by which you want to filter the projects.

Clicking any of the filter options opens its menu, displaying a list of values that you can choose from. Once the filter is applied, the list updates to display only the pipelines that meet the specified criteria.

- **Data system**: The Data system menu provides you with the option to filter the pipelines based on the type of data system.
- **Status**: You can filter the pipelines based on the status.
  - **Draft**: The pipeline is not configured completely.
  - **Scheduled**: The pipeline is scheduled for execution.
  - **Loading**: The pipeline is in loading state.
  - **Complete**: The pipeline is complete.
  - **Error**: The pipeline incurred error in execution.
  - **Timeout**: The pipeline incurred a timeout error.
  - **Canceled**: The pipeline has been cancelled.
  - **Canceling**: The pipeline is in the process of cancelling.
- **Owner**: You can filter the pipelines based on the email address of the project Owner.
- **Created Date**: Filter pipelines based on creation date.
  1. Select parameter:
    - Before
    - After
  2. Select date.
  3. Click **Apply**.
- **Modified Date**: Filter pipelines based on modification date.
  1. Select parameter:
    - Before
    - After
  2. Select date.
  3. Click **Apply**.

A set of criteria that focuses your view by eliminating elements that fall outside the scope of interest. When you filter Securiti pages and dashboards, you choose criteria in the filter panel to reduce the number of elements Securiti displays to just those of interest.
