# Supported data sources

The following data sources are supported for GenAI pipelines.

| Data Source | Entitlements Support | Scope |
| --- | --- | --- |
| Alfresco | Not supported | - |
| Alibaba Cloud OSS | Not supported | - |
| Amazon S3 | Not supported | - |
| Asana Enterprise | Not supported | - |
| Azure Blob Storage | Not supported | - |
| Azure Data Lake Storage (ADLS) Gen2 | Not supported | - |
| Azure Files | Not supported | - |
| Box | Not supported | - |
| Citrix ShareFile | Not supported | - |
| Confluence Cloud | Supported | Entitlements for spaces, groups, and users to be used in GenAI pipelines |
| Confluence Data Center | Not supported | - |
| DocuSign | Not supported | - |
| Dropbox | Supported | Entitlements for groups and users to be used in GenAI pipelines |
| GitHub | Supported | Entitlements for spaces, groups, and users to be used in GenAI pipelines |
| GitLab | Supported | Entitlements for projects, groups, and users to be used in GenAI pipelines |
| Go File Room | Not supported | - |
| Google Cloud Storage | Not supported | - |
| G Suite Gmail | Not supported | - |
| G Suite Gmail Message Body (Legacy) | Not supported | - |
| G Suite Google Drive | Supported | Entitlements for organizations, groups, and users to be used in GenAI pipelines |
| HDFS | Not supported | - |
| JIRA Cloud | Supported | Entitlements for files, organizations, groups, and users to be used in GenAI pipelines |
| Microsoft 365 Lists | Not supported | - |
| Microsoft 365 OneDrive | Supported | Entitlements for groups and users to be used in GenAI pipelines. |
| Microsoft 365 Outlook | Supported | - |
| Microsoft 365 Outlook Attachments (Legacy) | Not supported | - |

| Microsoft 365 SharePoint Online | Supported | Entitlements for sites, groups, and users to be used in GenAI pipelines. |

| Oracle Object Storage | Not supported | - |
| Quickbase | Not supported | - |
| S3 Compatible Storage | Not supported |  |
| Securiti for Box | Supported | - |
| ServiceNow Files | Not supported | - |
| SFTP | Not supported | - |
| Slack | Not supported | - |
| Slack Enterprise Grid | Supported | - |
| SMB | Not supported | - |
| Zendesk Support | Supported | Entitlements for Zendesk Support file objects to be used in GenAI pipelines |

The GenAI pipeline continuously load structured and unstructured data from supported data sources and safely transforms it to be used by GenAI models.
