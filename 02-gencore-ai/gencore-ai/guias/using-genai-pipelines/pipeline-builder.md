# Pipeline Builder

You can view the visual representation for your GenAI pipeline in the **Builder** view. To enter the Builder view, click the **Builder** tab.

The Builder view has the following two sections:

- **GenAI Canvas** on the left side
- **Components Sidebar** on the right side

![Builder view illustrating a data processing pipeline with various components and their connections.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Builder.png)

### GenAI Canvas

The **GenAI Canvas** displays the created pipeline and information flow visually. Each stage is defined by a different color.

With **GenAI Canvas** you can:

- Zoom in and out of the canvas.
- View the pipeline in a vertical or horizontal representation.
- View the pipeline with a fit-to-screen option.

### Components sidebar

The **Components** sidebar consists of all the available components categorized as the pipeline stages.

With **Components sidebar** you can:

- View the available components and their relevant count for each stage.
- Search for required components with the Search bar at the top.

The GenAI pipeline continuously load structured and unstructured data from supported data sources and safely transforms it to be used by GenAI models.
