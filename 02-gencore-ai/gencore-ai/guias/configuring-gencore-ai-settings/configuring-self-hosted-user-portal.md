# Configuring self-hosted user portal

To create and configure your self-hosted user portal:

1. In the upper right corner of the **Self-Hosted** section, click **+ New Self-Hosted Portal**.

![User portal interface displaying options for self-hosted deployments and portal management.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/User portals - New selfhosted portal.png)
2. In the **New Self-Hosted Portal** popup, add the following information:

| Field | Description |
| --- | --- |
| Portal name | Enter the name for your self-hosted user portal. |
| Domain | Enter the domain for your self-hosted user portal. For example: e.g. myportal.self.com) |
| Description | Enter the description for your self-hosted user portal. |
| Organization | Select the organization for your self-hosted user portal. > [!NOTE] > Note > > When creating a portal, Securiti only displays the organizations you have selected within the tenant. |
3. Click **Create Portal**. Securiti displays the **Self-Hosted Portals** page.
4. In your self-hosted portal settings, configure and review:
  1. [Installation in your Kubernetes infrastructure](/latest/docs/self-hosted-user-portal-installation)
  2. [Deployment Configuration](/latest/docs/self-hosted-user-portal-firewall-deployment)
  3. [Portal Single Sign-on](/latest/docs/configuring-user-portal-single-sign-on)
  4. [Linking portal pipelines](/latest/docs/configuring-user-portal-pipelines)
  5. [Integrating messaging apps](/latest/docs/messaging-app-integrations)
  6. [Pod status](/latest/docs/podcustom-installation-guides)
