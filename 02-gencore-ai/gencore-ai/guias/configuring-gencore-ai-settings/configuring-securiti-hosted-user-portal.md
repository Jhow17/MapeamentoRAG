# Configuring Securiti-hosted user portal

To create and configure your default Securiti user portal:

1. In the upper right corner of the **Default** section, click **+ New Securiti-Hosted Portal**.

![New securiti-hosted portal](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/user portals - default new securiti-hosted portal.png)
2. Select your organization. By default Securiti selects the **Default Organization**.

> [!NOTE]
> Note
> 
> When creating a portal, Securiti only displays the organizations you have selected within the tenant.

![Form to create a new Securiti portal with organization selection and action buttons.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/New securiti portal popup org.png)
3. To save your selection, click **Create Portal**.

![Form to create a new Securiti portal with organization selection and action buttons.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/securiti hosted - create portal.png)

Securiti displays the **Securiti-Hosted Portal** page where you can configure the following:

1. [Portal Single Sign-on](/latest/docs/configuring-user-portal-single-sign-on)
2. [Portal pipelines](/latest/docs/configuring-user-portal-pipelines)
3. [Messaging apps](/latest/docs/configuring-messaging-app-integrations)
