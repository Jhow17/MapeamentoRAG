# Replacing deprecated models

In case an already configured model is deprecated, a relevant icon displays in the LLMs listing.

![Deprecated icon for model](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Deprecated icon for model.png)

To review and replace the deprecated or discontinued models:

1. Click the information icon against the models. Securiti displays the relevant detail regarding discontinuation.
2. To review the deprecated or discontinued models, click ​**Review**​​.

![Deprecated icon - hover - review models](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Deprecated icon hover.png)

The deprecated models are listed with the status as ​**Deprecated**​​.

![highlighted model with deprecated status](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/LLM providers - LLM models - deprecated.png)
3. To replace the deprecated model:
  1. Click ​Options​ (three-dot menu) with the deprecated model. Securiti displays the ​**Replace**​​ option.

![deprecated models replace option](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/LLM providers - replace option.png)
  2. Click ​**Replace**​​. Securiti displays the ​**Replace LLM Model**​​ popup.

![Updated models list](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Replace LLM model list.png)
  3. Select the new model and click ​**Replace**​​.

![updated model](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/new model-replace .png)

> [!NOTE]
> Important
> 
> Securiti displays models from the same provider.
4. To view the affected pipelines, under ​**Provider Details**​ tab, click ​**view affected pipelines**​​.

![View affected pipelines notice](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/LLM providers - view affected pipelines.png)

Securiti displays the ​GenAI pipelines​​ dashboard with a list of pipelines using the deprecated model(s).

> [!NOTE]
> Important
> 
> When a model in a pipeline is deprecated, Securiti prompts you to reconfigure the pipeline. For more information, see [LLM selection](/latest/docs/llm-selection#reconfiguring-llm-in-case-of-deprecation) node.
5. To view the changelog for the model(s), click ​**Changelog**​​.

![Model changelog with previous and updated model information and modification date.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/new changelog.png)
6. Save the details.
