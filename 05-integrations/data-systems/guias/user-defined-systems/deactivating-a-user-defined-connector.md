# Deactivating a user-defined connector

If you ever need to deactivate the Connector for upgrading or troubleshooting:

1. In Securiti, from the main navigation bar, click the **Jewel** icon and choose **Integrations > User-Defined**.
2. For the user-defined connector in question, from the left menu, click **Overview** tab to view connector details.
3. In the **Authentication** section, on the right side of the **Reconfigure** button, click the down arrow to open menu.
4. Select **Deactivate**, as shown below.
