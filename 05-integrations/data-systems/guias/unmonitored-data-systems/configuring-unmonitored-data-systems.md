# Configuring unmonitored data systems

You configure unmonitored data systems in Securiti's [Data Mapping Automation](/v1/docs/using-data-mapping-automation) module to represent those data systems that might contain personal data relevant to a DSR request. When Securiti accepts a DSR request, it uses these data systems to create and assign subtasks. However, since Securiti does not monitor these data systems, it cannot apply any automation to help you accomplish them. The subtask owners must access the Data system themselves to process the subtask.

See [Creating and editing data assets](/v1/docs/using-data-mapping-automation) for more information.
