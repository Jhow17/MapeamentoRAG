# Acquire authentication credentials in Dot Digital

1. Log in to Engagement Cloud (Dot Digital).
2. Click the **person-and-cog** icon in the bottom left corner to open the settings menu.

![Group_1.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-e2753e1d-cede-df2e-a5f0-29293605619c.png)
3. Select **Access** as shown.

![Group_2.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-ceaa69db-54da-f6ec-2ce3-dc257186fd73.png)
4. Click the **API users** tab.

![Group_3.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-673203f4-ef92-809b-6d29-c2e8cc1b310e.png)
5. Click **New User**. The Username (email address) is automatically generated for you. Do not edit it.

![Group_6.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-374652b6-4832-a46e-af39-302372e3c0d6.png)
6. Record the Username to use later.
7. Enter a password and confirm it.
8. Mark the **Enabled** checkbox, if not already marked.

![Group_4.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-c34870e2-acbc-a206-201f-1fc121504acc.png)
9. Click **Save**. Dot Digital shows you a page with your API endpoint as shown below, for example, "https://r1-api.dotmailer.com".

![Group_5.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-9474e174-ccd4-3087-8c01-667483634abf.png)

The **Region** is your value just before "-api" in the API endpoint.
10. Record the Region to use later. In this example, it is "r1".
11. Proceed to [Activate the Dot Digital connector in Securiti](/v1/docs/activate-the-dot-digital-connector-in-securiti).
