# Add a user to the Power BI workspace

To access all Power BI workspaces, you must add the user who is activating the Power BI data system connector to those workspaces.

Use the following steps to add a user to Power BI workspaces:

1. Log in to your [Power BI](https://app.powerbi.com/home?experience=power-bi) account.
2. On the left navigation menu, click **Workspaces**, then select the workspace to which you want to add the user.
3. On the top right of the selected workspace page, click **Manage access**. ![Power BI workspace interface showing task flow options and a paperclip icon.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/ws-access.png)
4. On the **Manage access** right pane, click **+ Add people or groups**. ![Power BI workspace interface showing options to add tasks and manage access.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Add people.png)
5. On the **Add people** right pane, search and select the user you want to assign to this workspace, as shown below.
6. After selecting the user, click **Add**, and close the right pane. ![Power BI workspace interface showing options to add people and select task flows.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/search-user.png)
7. Scroll down to the datasets table, in the **Name** column, hover over the dataset that you want to assign access to the user.
8. On the right side of the dataset name, click the More options **(three dots)** icon, and select **Manage permissions** from the menu.

> [!NOTE]
> Note
> 
> Manage Permissions only appear for datasets belong to workspace that is under your ownership.

![Menu options for managing tasks and permissions in a project management interface.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/manage-permissions(1).png)
9. On the access management page, choose the **Direct access** tab.
10. On the top left of the page, click **Add User**.
11. On the **Grant people access** popup, search and select the user you want to give access.
12. Once the user is selected, click **Grant access**. ![User access settings with options to grant permissions and send notifications.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Access-dataset.png)
13. Repeat the previous steps for all the workspaces and tables for which you want to give access to the specific user.
