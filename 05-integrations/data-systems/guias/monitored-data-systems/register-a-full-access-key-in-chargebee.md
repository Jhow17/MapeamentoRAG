# Register a full access key in Chargebee

To integrate Securiti with Chargebee for DSR automation, you first register a full access key within Chargebee to receive an API key as described below.

1. Log in to your Chargebee account.
2. On the Chargebee dashboard, choose **Settings > Configure Chargebee**, then click **API keys and webhooks** as shown below.

![C00064.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-1c2c75a3-f1fb-0a4c-05d9-d1ed7f066605.png)
3. Click **+ Add API Key**.

![C00065.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-f79f0b1c-49b4-64ef-d917-9e8e7aed98c6.png)
4. Click **Full-Access Key**.

![C00066.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-ce403040-078c-9c52-a050-edecb8ffa4e8.png)
5. Enter a name for the API key and click **Create Key**.

![C00067.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-06a37d3b-1d67-79ac-0cfb-7cca2a549420.png)

Chargebee generates a new API key and shows it to you.

![C00068.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-e5b46227-3b10-e793-b6ae-9f9441ffcbd5.png)
6. Record the new API key to use later.
7. Proceed to [Connecting Chargebee with Securiti](/latest/docs/new-ui-connecting-chargebee-with-securiti).
