# Asana and Asana Premium

Asana is a web and mobile task management tool that helps teams organize, track, and manage their work.

Asana offers a set of Data Access, Management and Portability APIs that let data controllers easily access and manage their team member data through the Securiti platform. Using these APIs, Securiti bots execute DSR automation workflows to directly access, export, and delete data within the Asana platform without any user intervention.

Asana falls under the category of [Monitored, Scanless](/latest/docs/managing-data-system-connectors) data systems.
