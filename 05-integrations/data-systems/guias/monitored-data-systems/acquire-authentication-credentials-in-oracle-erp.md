# Acquire authentication credentials in Oracle ERP

> [!NOTE]
> **Note**
> 
> This procedure assumes that you have access to the Oracle Cloud Instance before Connector Activation.

1. Login to Oracle ERP.
2. The Connector requires the following parameters for Activation:
  - **Base URL** - Prefix of login URL, as shown below:

```plaintext
https://adc4-zkaz-fa-ext.oracledemos.com/
```
  - **User Name** - Login username
  - **Password** - Login password
3. Proceed to [Connect Oracle ERP Cloud connector with Securiti](/latest/docs/connect-oracle-erp-cloud-connector-with-securiti).
