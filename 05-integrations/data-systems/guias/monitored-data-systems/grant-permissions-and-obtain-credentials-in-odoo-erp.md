# Grant permissions and obtain credentials in Odoo ERP

Odoo ERP data systems require a username, password, and Instance id to activate the Connector in Securiti.

> [!NOTE]
> **Note**
> 
> We assume you have an Odoo ERP Instance running or you're the admin for the account before proceeding with the Connector Authentication.

Use the matching procedure below.

1. (Optional) You can sign up for a trial account at [https://www.odoo.com/trial](https://www.odoo.com/trial).
2. Log in to your Odoo ERP account with the admin Credentials you used to register.
3. Record the **User** and **Password** for later use (the same you used when registering the Odoo ERP account).
4. On the Odoo ERP dashboard, record the **Instance ID** for later use, as shown below.

<https://**demoaccount**.odoo.com/%s>

The *demoaccount* in the example URL before ".odoo.com" is your Instance id.
5. Proceed to [Activate the Odoo ERP connector in Securiti](/v1/docs/activate-the-odoo-erp-connector-in-securiti).
