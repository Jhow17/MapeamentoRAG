# Configuring Graph API permissions

1. In the **Manage** area of the navigation pane for the connector page, click **API permissions** as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/configuring-graph-api-permissions-en-image-to40kslb.png)
2. On the API permissions page, click **Add a permission**.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/configuring-graph-api-permissions-en-image-6nq2jeyy.png)
3. On the Request API permissions page, click **Microsoft Graph**.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/configuring-graph-api-permissions-en-image-vsb4xgz4.png)
4. Click **Application Permissions**.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/configuring-graph-api-permissions-en-image-5hscypbe.png)
5. On the Select Permissions page for Microsoft Graph, expand the various areas and mark the checkboxes for the following permissions for the Microsoft Calendar connector:
  - Directory.Read.All
  - Calendars.Read
  - User.Read.All

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/configuring-graph-api-permissions-en-image-8oec5e7i.png)
6. Near the bottom of the Request API permissions box, click **Add permissions**.
