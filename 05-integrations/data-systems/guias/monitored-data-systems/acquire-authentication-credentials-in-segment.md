# Acquire authentication credentials in Segment

1. Log in to Segment.
2. Segment requires the following Credentials for Activation.
  - API Access Token
  - Workspace Region
3. To record the API access Token.
  1. Navigate to **Settings > Workspace Settings > Access Management > Tokens**

![segment_tokens.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-dc02af47-99aa-9c63-2450-351a1e8b5bbc.png)
  2. Click **Create Token** and enter a name for the new Token.
  3. Under **Individual Permissions**, select **Workspace Owner**.

![segment_createtoken.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-51eaa686-ea77-6f62-844f-5ddf2c33112e.png)
  4. Record the generated **Access Token** to use later

![segment_7.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-f181791a-1dbd-e0ff-a41a-7ea09e32aaaf.png)
4. Proceed to [Connecting Segment with Securiti](/latest/docs/connecting-segment-with-securiti).
