# Segment

Segment falls under the category of [Monitored, Scanless](/latest/docs/managing-data-system-connectors) data systems.

### Connect Segment connectors with Securiti

To configure the Segment connector, perform the procedures in the following topics:

1. [Acquire authentication credentials in Segment](/latest/docs/acquire-authentication-credentials-in-segment)
2. [Connecting Segment with Securiti](/latest/docs/connecting-segment-with-securiti)

## Additional links

For more information about how Securiti uses the Segment connector for DSR requests, see [Fulfilling DSR requests for Segment](/latest/docs/fulfilling-dsr-requests-for-segment) .

If you are using enhanced DSR processing as described in [Understanding enhanced DSR request processing](/v1/docs/understanding-identifiers-for-dsr-request-processing), see [Segment data element types for enhanced DSR processing](/v1/docs/segment-data-element-types-for-enhanced-dsr-processing) for a list of the data element types supported as identity PD.
