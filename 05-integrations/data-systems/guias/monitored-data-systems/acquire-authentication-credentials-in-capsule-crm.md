# Acquire authentication credentials in Capsule CRM

Capsule CRM data system connector uses API credentials for authentication and activation later.

> [!NOTE]
> **Note**
> 
> We assume you can access a running Capsule CRM instance or its admin to acquire Client ID and Client Secret for connector activation.

1. Register the app by visiting [capsule developer portal](https://developer.capsulecrm.com/clients/new).

> [!NOTE]
> **Note**
> 
> You can create a free (trial) Capsule CRM account to test users, partner organizations, and their use cases and tasks.
2. After registration, the app presents you with the Client ID and Secret.

Record them to use later.
3. Proceed to [Connecting Capsule CRM with Securiti](/latest/docs/connecting-capsule-crm-with-securiti).
