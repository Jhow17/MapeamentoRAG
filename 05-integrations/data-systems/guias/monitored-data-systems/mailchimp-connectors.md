# Mailchimp

Mailchimp is a marketing automation platform and an email marketing service that offers customizable solutions designing and deploying email marketing campaigns. Mailchimp offers the RESTful 3.0 API to enable the automation of queries, authentication, and error handling. Mailchimp (Securiti-Cloud) falls under the category of monitored, structured data systems.

### Supported connector types and modules

| Connector type | Modules supported |
| --- | --- |
| Mailchimp (Securiti-Cloud) | DSR Automation |

### Supported authentication methods

For Securiti Cloud connector:

- API Key based authentication

### Prerequisites for configuring Mailchimp connector

#### 1. Mailchimp account access

You must have an active Mailchimp account to activate the connector.

#### 2. Private Cloud Storage configuration

You must configure Private Cloud Storage (PCS) for your tenant to successfully authenticate Mailchimp data system connector. For more information on configuring PCS, see [Configuring Private Cloud Storage](/v1/docs/system-settings-configuring-private-cloud-storage).

### Connect Mailchimp with Securiti

To configure your Mailchimp (Securiti-Cloud) connector, perform the procedures in the following topics:

1. Authenticate and record credentials for Mailchimp connector. For more information see, [Authenticate the Mailchimp connector](/latest/docs/authenticate-the-mailchimp-connector).
2. [Connecting Mailchimp with Securiti](/latest/docs/new-ui-connecting-mailchimp-with-securiti).
