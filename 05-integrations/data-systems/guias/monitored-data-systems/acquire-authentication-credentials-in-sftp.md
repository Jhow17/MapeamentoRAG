# Acquire authentication credentials in SFTP

1. Log in to the server running SFTP.

> [!NOTE]
> **Note**
> 
> It is assumed that you have SFTP (SSH File Transfer Protocol) installed before connector activation.
2. SFTP requires SSH (Secure Shell) Credentials as input. Record the following parameters for later use:
  - **Authentication Type** (Password Based or Key Based)
  - **Host**
  - **Port**
  - **Path**
  - **Username**
  - **Password** or **Key** (based on the selected Authentication Type)

> [!NOTE]
> **Note**
> 
> Depending on the server Configuration, an appropriate Authentication method is used.
3. Proceed to [Connecting SFTP with Securiti](/latest/docs/connecting-sftp-with-securiti).
