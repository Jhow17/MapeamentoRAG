# Acquire the API key in Files.com

1. Log in to Files.com.

![login_files_com_1_1.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-ad6b653f-7fa3-f567-daf2-82ccc70aff64.png)
2. On the account dashboard, in the left navigation menu, click **Settings**, as shown below.

![settings_files_com_1.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-5ca5cd9d-61a7-76b9-ce6d-7bb19018b8fe.png)
3. In the menu, click **API Keys** and then click **Add Key** to generate the API Key, as shown below.

![API_key_files_com_1.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-b9f08a03-aa63-c7b9-8f4f-553d23bde373.png)
4. Record the API Key to use later.
5. Proceed to [Connect Files.com connector with Securiti](/latest/docs/connect-filescom-connector-with-securiti).
