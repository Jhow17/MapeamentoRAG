# Domo

The Domo Self-hosted connector falls under the category of [Monitored, Structured](/latest/docs/managing-data-system-connectors) data systems, as shown below.

### Connect Domo connectors with Securiti

To configure the Domo Self-hosted connector, perform the following procedures in sequence:

1. [Grant permissions and obtain credentials in Domo](/latest/docs/grant-permissions-and-obtain-credentials-in-domo)
2. [Connecting Domo with Securiti](/latest/docs/connecting-domo-with-securiti)
3. [Configure discovery scans in Domo](/latest/docs/configure-discovery-scans-in-domo)

## Additional resource

See [Fulfilling DSR requests for Domo](/latest/docs/fulfilling-dsr-requests-for-domo) for more information about how Securiti uses the Domo Self-hosted data to respond to DSR requests.
