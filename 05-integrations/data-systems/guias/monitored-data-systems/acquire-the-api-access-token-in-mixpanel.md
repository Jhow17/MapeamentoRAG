# Acquire the API access token in MixPanel

To acquire the API access Token in MixPanel:

1. Log in to MixPanel.
2. Click the **Settings icon** in the top right corner of your screen.

![mixpanel_nought.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-5b92b977-7958-3257-3651-38960bc3136c.png)
3. Select your profile.

![mixpanel_1_1.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-0e35cd6a-1b13-4316-cc28-f737cf845100.png)
4. Under **Personal Settings**, choose **Data & Privacy**.

![mixpanel_2.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-4dd7d5b0-6740-f97f-a7e1-3ac8dc90f675.png)
5. At the bottom, under **GDPR API**, click **Generate**.

![mixpanel_3.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-d641ff3c-1e83-55c5-ab73-a67aee6ed33a.png)
6. In MixPanel Settings, select your profile.
7. Under **Projects**, record the Token and API Secret to use later.

![mixpanel_4_4.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-8420b3ce-a6a1-f072-6187-d20c358ebf91.png)
8. Proceed to [Connect MixPanel connector with Securiti](/latest/docs/connecting-mixpanel-connector-with-securiti).
