# Register an API in Ad Butler

To integrate Securiti with Ad Butler for DSR automation, you first register an API in Ad Butler to receive an API Key as follows:

1. Log into your Administrator account at Ad Butler.
2. On the Dashboard page, near the top of the left sidebar click the Administrator portrait and choose **API Settings** as shown below.

![C00214.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-caff8ffc-6c61-7829-745c-d0127aa2e253.png)
3. On the AdButler API page, click **Create API Key** as shown below.

![C00215.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-a1d9080c-77f5-5248-2310-389e890ee140.png)
4. On the Create API Key pop-up, enter a convenient name and set the Type as **Live**.

![C00216.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-8e66f50b-9ba1-5f67-53dd-5f60d1ae38b1.png)
5. Click **Save**.

AdButler shows you the new API and its key as shown below.

![C00217.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-1e01c509-bdfe-992d-f2ea-ca5e98952bbb.png)
6. Record the API key to use later.
7. Proceed to [Connecting Ad Butler with Securiti](/latest/docs/new-ui-connecting-adbutler-with-securiti).
