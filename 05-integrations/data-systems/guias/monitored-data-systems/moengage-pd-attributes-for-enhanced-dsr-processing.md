# MoEngage PD attributes for enhanced DSR processing

If you are using enhanced DSR processing, you can use the following MoEngage PD attributes as identity PD for DSR requests:

- ID
- CONTACT_PHONE
- ADVERTISING_IDENTIFIER
- CONTACT_EMAIL
- GOOGLE_ADVERTISING_ID
- USER_SECONDARY_ID

To learn more about enhanced DSR processing, see [Understanding enhanced DSR request processing](/v1/docs/understanding-identifiers-for-dsr-request-processing) (only available if you are subscribed to the Data Subject Rights module).
