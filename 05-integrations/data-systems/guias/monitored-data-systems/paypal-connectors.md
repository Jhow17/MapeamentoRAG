# PayPal

PayPal is an online payment solutions provider that offers services such as online fund transfers and payment processing for online merchants and auctioneers. PayPal uses web cookies that have a defined expiry date. Upon expiration, these cookies are disabled and any cache data is automatically deleted. PayPal also uses of personal data to automate financial decisions on its platforms.

Paypal falls under [Monitored, scanless data systems](/latest/docs/managing-data-system-connectors).

### Supported Connector types and modules

| Connector type | Modules supported |
| --- | --- |
| Paypal (Securiti-Cloud) | DSR Automation using APIs |

### Supported authentication methods

Securiti supports basic authentication method for PayPal connector.

### Prerequisites for configuring PayPal Self-hosted connector

#### 1. Paypal application

You must create a Paypal application to obtain the authentication credentials. For more information, see [Register an application in PayPal](/latest/docs/register-an-application-in-paypal).

### Connect Paypal with Securiti

To configure the Paypal (Securiti-Cloud) connector, perform the procedures in the following topics:

1. [Register an application in PayPal](/latest/docs/register-an-application-in-paypal).
2. [Connecting Paypal with Securiti](/latest/docs/connecting-paypal-with-securiti).
