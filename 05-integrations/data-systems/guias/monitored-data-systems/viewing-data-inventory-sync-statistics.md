# Viewing data inventory sync statistics

The Data Inventory Sync Statistics page provides a consolidated view of inventory and scan-related metrics for an application. It helps you monitor scan progress, duration, and data processing activity.

Use the following table to understand the inventory statistics metrics.

| **Metric** | **Description** | **Example** |
| --- | --- | --- |
| Total Scan Duration | Displays the total time taken by the scan, shown in days, hours, minutes, and seconds. This represents the cumulative runtime from scan start until completion. | 0 days, 0 hours, 15 mins, 31 secs |
| Scan Started On | Displays the exact date and time when the scan was initiated. | 1:11 AM, Jan 30, 2026 |
| Files Cataloged | Total number of files successfully cataloged | 60,000 |
| Files per Hour Cataloged | Average rate at which files are cataloged per hour | 12,000/hr |
| Files per Hour Discovered | Total number of files discovered per hour | – |
| Data Size Cataloged | Total volume of data cataloged | 29.90 MiB |
