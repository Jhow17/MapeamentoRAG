# Trello

Trello is an easy-to-use platform that helps individuals and teams organize and track tasks and projects. It uses a visual system with boards for projects, lists for stages or categories, and cards for individual tasks. Trello (Securiti Cloud) connector is a scanless connector.

For more information, see [Data systems classification](/v1/docs/managing-data-system-connectors).

### Supported connector types and modules

| Connector type | Modules supported |
| --- | --- |
| Securiti Cloud connector | DSR Automation using APIs |

### Supported authentication methods

- API token

### Prerequisites for configuring Trello connector connectors

#### 1. Trello account access

You must have an active Trello account to activate the connector.

#### 2. Private Cloud Storage (PCS) configuration

> [!WARNING]
> **Important**
> 
> This prerequisite applies to the Securiti Cloud connector only

You must configure Private Cloud Storage (PCS) for your tenant to successfully authenticate Trello data system connector. For more information on configuring PCS, see [Private Cloud Storage](/latest/docs/private-cloud-storage).
