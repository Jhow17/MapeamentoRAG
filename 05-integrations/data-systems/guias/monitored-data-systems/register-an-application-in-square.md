# Register an application in Square

1. Log in to your Square account, then click **Apps** on the left sidebar as shown below.

![C00136.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-8a3f8053-1af0-4770-4574-edc575fd922c.png)
2. On the Apps page, click **My Apps** on the left sidebar as shown below.

![C00137.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-e9349c11-1806-96bc-c53a-8de5abb9a7fe.png)
3. On the My Apps page, click **Go to Developer Dashboard** as shown below.

![C00138.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-f44999f1-ddb9-32f2-627e-2287f0dc4cec.png)
4. On the Square Developer Portal page, click **New Application** as shown below.

![C00139.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-b90a663f-db4b-46a1-73c1-1bd2a7d1473d.png)
5. On the New Application page, give the new application a convenient name and click **Create Application**, as shown below.

![C00140.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-a9799340-f63a-57cf-0a2e-c42ea9385241.png)

Square creates the new application and redirects you to the Credentials page where it shows you the Application ID.
6. Record the Application ID to use later.

![C00141.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-0e30c0d9-3ea2-64c6-39ab-19b75ea3aa5e.png)
7. On the left sidebar, click **OAuth** to open the OAuth page.
8. On the OAuth page, record the Application Secret as shown below to use later.

![C00142.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-75047714-a6aa-3d61-e718-26089898f368.png)
9. Proceed to [Connect Square connector with Securiti](/latest/docs/connect-square-connector-with-securiti).
