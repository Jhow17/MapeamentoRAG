# NetSuite (Self-hosted) file permissions

This topic covers the Permissions required for accessing files in your NetSuite account for **Customer Center** and **SuiteCommerce** user roles.

> [!WARNING]
> **Important**
> 
> NetSuite has revised Permissions for accessing files for **Customer Center** and **SuiteCommerce** user roles, effective August 31, 2024. We recommend you update Permissions using the procedure below, to prevent loss of access or functionality.

The below sections cover updated Permissions for **Customer Center** and **SuiteCommerce** NetSuite roles.

### SuiteCommerce Configuration permissions

NetSuite has updated SuiteCommerce Configuration record Permissions effective from August 27, 2024. The updated Permissions impact how external roles and unauthenticated users access certain custom records.

See [Setting Permissions for a Custom Record Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2879388.html#subsect_0816050536), for more information.

Previously, the SuiteCommerce Configuration provides access levels beyond "View" for external roles and unauthenticated users, which include:

- **External Roles Access**: Full
- **Unauthenticated Users Access**: Full
- **Record locked on installation**

After the update on August 27, 2024, these Permissions will be adjusted as follows:

- **External Roles Access**: Changed from "Full" to "View"
- **Unauthenticated Users Access**: Changed from "Full" to "View"
- **Record locked on installation**: Records will be unlocked on installation for approximately two months, after which they will be locked again with no possibility to modify the permission levels.

Perform the following actions to ensure that your SuiteCommerce customizations continue to work correctly after the Permissions update.

1. Navigate to the custom records impacted by this change.
2. Ensure that any roles or users who require more than "View" access are updated to use elevated Permissions where necessary.
3. Adjust any custom scripts or configurations that rely on the affected access levels to accommodate the new "View" Permissions.
4. After making the necessary changes, thoroughly test all customizations to ensure they operate as expected under the new permission settings.

### File Cabinet permissions for Customer Center role

NetSuite has added stricter access controls for files shared using the **Customer Center** role, effective August 31, 2024.

See [Setting Permissions on Files for Customer Centers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4799276714.html#subsect_0530052000) for more information.

Previously, users with the Customer Center role could access files in the File Cabinet through a URL provided by an Administrator or NetSuite Support. After August 31, 2024, stricter access controls will be implemented based on the Permissions set on your files. This may result in Customer Center role users losing access to certain files if Permissions are not properly configured.

Perform the following actions to ensure that users with the Customer Center role have the appropriate access:

1. Login to your NetSuite account and access the File Cabinet by navigating to **Documents > Files > File Cabinet**.
2. Navigate to the Log Files folder within the File Cabinet.
3. Open the **Files for Access Review** folder.
4. Open the report file generated by NetSuite. This report includes IDs of potentially impacted files or folders, their file paths, and details on how often these files are accessed by users with the Customer Center role.

> [!NOTE]
> **Note**
> 
> NetSuite generates this report every 24 hours to ensure you have the most recent information.
5. If you want the file to remain accessible to users with the Customer Center role, edit the file and check the **Company-Wide Usage** box.
6. If the file is attached to a record, such as a Message or Case record, specify which user roles can access the attached file.
