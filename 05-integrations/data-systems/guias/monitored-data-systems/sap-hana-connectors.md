# SAP HANA

The SAP HANA connector enables Securiti to securely connect to SAP HANA databases and support key privacy and data governance use cases. It allows organizations to discover and classify sensitive data through Sensitive Data Intelligence (SDI), while also enabling Data Subject Request (DSR) workflows by locating and retrieving personal data associated with individuals to support privacy rights fulfillment and regulatory compliance. SAP HANA data system falls under the [Monitored, Structured data systems](/v1/docs/managing-data-system-connectors).

### Supported connector types and modules

| Connector type | Modules supported |
| --- | --- |
| SAP HANA (Self-hosted) | - Sensitive Data Intelligence (SDI) - Data Subject Rights (DSR) |

### Supported Pod type

- Standard Securiti Pod.

### Supported authentication method

SAP HANA supports the basic authentication method, including username and password.
