# Couchbase NoSQL restriction requests

Data subjects can request restriction of processing where the accuracy is contested, where processing is unlawful, where the controller no longer needs the personal data but the data subject needs it for legal proceedings, or when the controller is trying to outline the legal basis for processing.

The copy of user data that Securiti automatically extracts and attaches to the restriction subtask is exactly the same as the data extracted through an access request. See [Couchbase access requests](/v1/docs/couchbase-nosql-access-requests) for information about the data that is extracted and attached to the subtask.

Securiti does not implement any additional automated action within Couchbase for restriction requests. The objection task owner must manually inspect the Couchbas object and take any action required by your organization's data restriction policies.
