# Grant permissions and obtain credentials in HackerRank

HackerRank data systems use Work API Key to establish a successful connection in Securiti.

Use the matching procedure below.

1. > [!NOTE]
> **Note**
> 
> We assume you have a HackerRank instance running or you're the account admin to provide the required Permissions.

Log in to your HackerRank account.

*(Optional)* If you haven't, you can create a trial account for HackerRank at [Start your free trial](https://www.hackerrank.com/work/free-trial).

> [!NOTE]
> **Note**
> 
> Your business email is the one you must use to log in.
2. In the upper right corner of the page, click your profile icon and select **Teams Management > Users** tab.

![teams_management.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-45fef5b9-18d6-45c5-84df-88e764fbdd37.png)

![users_tab.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-dab49c67-b05b-1f18-fb9d-19c8c72d8d00.png)
3. Select the user account for which you want to generate the API key.
4. Mark the **Edit** radio button for the *Access to Shared interviews (within teams)* permission, as shown below.

![edit_permission.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-e0346285-7bd9-3338-c7bd-819adc9a2f4c.png)
5. On the HackerRank dashboard, click your profile icon and select **Settings**.

In the left sidebar, click **My API Tokens**, then on the right side pane, **Generate New Token**.

![generate_new_api_token.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-ea974acb-11e2-52a6-d602-f2cdeb6182cb.png)
6. Enter a Token label in the field and *record* the Token for later use as it is displayed only once.

![enter_label_record_token.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-b65e3c93-385f-f444-ad0b-ff426fca50a0.png)
7. Proceed to [Connecting HackerRank with Securiti](/latest/docs/connecting-hackerrank-with-securiti).
