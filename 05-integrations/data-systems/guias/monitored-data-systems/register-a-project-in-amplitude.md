# Register a project in Amplitude

You first register a project with Amplitude and receive an API Key and Secret Key that you use to activate the Amplitude connector in Securiti. To register a new project in Amplitude:

1. Log in to Amplitude and click **Manage Data** near the bottom of the left sidebar, as shown below.

![C00201.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-ff6642d0-3930-c199-289e-e2a540ff4d53.png)
2. On the Manage Data page, click **Create Project** as shown below.

![C00202.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-2f2c398c-2805-bb8b-0671-6aef5561eca5.png)

Amplitude opens a Create New Project pop-up.
3. Enter a custom name for your project and click **Create** as shown below.

![C00203.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-53325fed-cf20-45b8-4144-6a60f41ba34c.png)

Amplitude creates a new project and generates an API key and a secret key as shown below.

![C00204.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-510f6d68-2545-15e7-55b3-77d8174fab26.png)
4. Record the API key and secret key to use later.
5. Proceed to [Connecting Amplitude with Securiti](/latest/docs/connecting-amplitude-with-securiti).
