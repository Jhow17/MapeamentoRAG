# Acquire authentication credentials in Loggly

1. Log in to your Loggly account.
2. On the account page, choose **API Tokens** and click **Add New**.

![Select_API_Tokens.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-8640079a-3f38-5e2b-3e25-f92b53fa353b.png)
3. Click **Create** on the "Create an API Token" dialog to proceed.

![Click_Create_Token.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-3e3a7460-2a13-3de4-3d78-ed8f6e6ee2d9.png)
4. An **API Token** is created as shown below.

![Copy_Paste_API_Token.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-249aa071-2d38-e094-8224-6bb51e724662.png)

Record the Token to use later.
5. Determine your account name from the Loggly URL as shown below.

*https://****<account>****.loggly.com*
6. Proceed to [Connect Loggly connector with Securiti](/latest/docs/connect-loggly-connector-with-securiti).
