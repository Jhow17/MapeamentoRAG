# Create a custom integration in Facebook Workplace

To integrate Securiti with Facebook Workplace for DSR Automation, you create a custom integration in Facebook Workplace and record the associated access token:

1. Log in to Facebook Workplace with your admin credentials.
2. On the left sidebar, click **Admin Panel** as shown below.

![FBWP_admin_panel.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-b1a888db-fde2-7837-6e2f-6ede14f24c45.png)
3. On the Admin Panel sidebar, click **Integrations** as shown below.

![FBWP_Integrations.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-4b124eb0-826b-5572-4c9d-c1d5c1cb6294.png)
4. In the **Integrations** area, click **Create Custom Integration** as shown below.

![FBWP_create_custom_integration.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-0e5828a5-1b4a-b1d8-809d-92a8894e4d39.png)
5. On the Create Custom Integration popup, enter a name and description for the custom Integration as shown below, then click **Create**.

![FBWP_Create_custom_integration_popup.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-7d1bde74-3701-e131-1973-70bb3fe5e528.png)
6. On the Integrations panel, click **Create Access Token** as shown below.

![FBWP_create_access_token.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-47934563-f3c7-9e0c-0956-3d58e16123d6.png)
7. On the New Token Created pop-up, click **Copy** to copy the access Token onto the clipboard. Then mark the **I Understand** checkbox and click **Done**.

![FBWP_new_token_created_popup.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-c6652b2b-0750-9aec-be2b-2697aec434be.png)
8. Save the access Token to use later.
9. Proceed to [Connect Facebook Workplace connector with Securiti](/latest/docs/connect-facebook-workplace-connector-with-securiti).
