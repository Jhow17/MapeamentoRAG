# Grant permissions and acquire authentication credentials in New Relic

New Relic data systems use an API key to establish a successful Connection in Securiti.

Use this procedure to create the API key.

> [!WARNING]
> **Important**
> 
> With user type keys, New Relic minimum Permissions are associated with the account you've used to create the API key. We assume you have a New Relic Instance running or are an admin before proceeding with generating **X-Api-Key**.

1. Log in to New Relic.
2. On the New Relic dashboard, in the left sidebar, near the bottom click your user name to expand it and click **API Keys**.

![unnamed__4_.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-08229853-ef24-5020-29f2-aab5e0b041b1.png)

![unnamed__3_.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-6eb6b3f0-4ac9-1b80-6796-a0746eb74a3b.png)
3. In the right side pane, from the list, click the actions icon **(three horizontal dots)** next to your admin account. Then click **Copy key**.

![unnamed__5_.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-a97561d6-320a-f61b-9a98-6310f088a1e2.png)
4. Record it for later use.
5. Proceed to [Connect New Relic connector with Securiti](/latest/docs/connecting-relic-connector-with-securiti).
