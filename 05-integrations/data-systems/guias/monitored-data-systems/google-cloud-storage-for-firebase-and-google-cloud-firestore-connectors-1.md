# Google Cloud Storage for Firebase and Google Cloud Firestore

Google Cloud Storage for Firebase and Google Cloud Firestore are both cloud-hosted NoSQL databases. Google Cloud Storage for Firebase and Google Cloud Firestore fall under the category of [Monitored, Unstructured data systems](/latest/docs/managing-data-system-connectors).

### Supported connector types and modules

| Connector type | Modules supported |
| --- | --- |
| - Google Cloud Firestore (Securiti cloud) - Google Cloud Storage for Firebase (Securiti cloud) | - Breach Analysis - Standard Data Scan |

### Supported authentication methods

- For Google Cloud Firestore, the supported authentication method is a Service Account key file.
- For Google Cloud Storage for Firebase, the supported authentication method is OAuth.

### Prerequisites for configuring the Google Cloud Firestore and Google Cloud Storage for Firebase connector

#### 1. Admin access

You must be an admin for your Google account to create projects.

#### 2. Enable APIs in Google Cloud Platform

In the Google Cloud Platform account, enable the **Admin SDK API** API.
