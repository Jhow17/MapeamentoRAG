# Kintone

Kintone is a cloud-based business application platform that enables organizations to build custom workflows and manage business data without extensive coding. By connecting Kintone with Securiti, organizations can efficiently locate and manage personal data for Data Subject Requests (DSR), helping streamline privacy request fulfillment and support compliance with data protection regulations.

Kintone fall under the category of [Monitored, Structured data systems](/latest/docs/getting-started-with-data-system-connectors).

### Supported connector types and modules

| Connector type | Modules supported |
| --- | --- |
| Kintone (Self-hosted) | DSR Automation using SQL queries |

### Supported authentication methods

Securiti supports supports basic authentication method for Kintone.

### Prerequisites for configuring the Kintone connector

#### 1. Admin access in Kintone

You must have admin access in Kintone to access all spaces, apps, and records

#### 2. Account in Kintone instance

Before proceeding with the connector authentication, you must have Kintone instance. If you don’t have an account yet, you can create a free trial account. For more information, see [Kintone free trial account](https://www.kintone.com/en-us/trial/).
