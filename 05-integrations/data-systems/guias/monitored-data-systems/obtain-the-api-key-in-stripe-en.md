# Obtain the API key in Stripe

1. Log in to Stripe with your admin credentials.
2. On the left sidebar, navigate to **Developers > API keys** as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/obtain-the-api-key-in-stripe-en-image-4tfauyw8.png)
3. On the API Keys page, toggle the “Viewing test data” slider to **Off**.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/obtain-the-api-key-in-stripe-en-image-1ofhzy8s.png)
4. In the Standard keys area, next to Secret Key, click **Reveal live key token** as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/obtain-the-api-key-in-stripe-en-image-qo3xconc.png)
5. Record the secret key to use later.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/obtain-the-api-key-in-stripe-en-image-8sub1gco.png)
6. Proceed to [Connect Stripe (Securiti Cloud) with Securiti](/latest/docs/connect-stripe-connector-with-securiti).
