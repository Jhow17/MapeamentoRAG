# Amplitude

Amplitude is a product analytics software suite for mobile and web-based applications. It relies on advanced behavioral analytics to let teams build products that fit customers' requirements.

Amplitude uses a User Privacy API that lets its customers manually put in requests for the purposes of opting out or deleting personal data collected within Amplitude and its downstream third-party partners. These may be automated using Securiti's automated workflows without requiring any user action.

Amplitude falls under the category of [Monitored, Scanless](/latest/docs/managing-data-system-connectors) data systems as shown in the table below.

To configure the Amplitude connector, perform the procedures in the following topics:

1. [Register a project in Amplitude](/v1/docs/register-a-project-in-amplitude)
2. [Connecting Amplitude with Securiti](/latest/docs/connecting-amplitude-with-securiti)

See [Fulfilling DSR requests for Amplitude](/v1/docs/fulfilling-dsr-requests-for-amplitude) for more information.
