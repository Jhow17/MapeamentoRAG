# Granting DB permissions for PostgreSQL

Do the following to grant PostgreSQL Connector Database Permissions.

> [!NOTE]
> **Note**
> 
> Connect Permissions on all databases that require scanning.

1. For usage permission, enable:
  - pg_catalog
  - information_scheme
  - all schemes on all databases that require scanning
2. To SELECT Permissions on tables in each Schema of every Database:

```plaintext
CREATE ROLE securiti WITH LOGIN PASSWORD '<some-strong-password>'

GRANT CONNECT ON DATABASE <<database>> TO securiti;
-- use <<database>> to connect to database
GRANT USAGE ON SCHEMA public TO securiti;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO securiti;
```
3. Proceed to [Obtain database credentials for your PostgreSQL configuration](/v1/docs/obtain-database-credentials-for-your-postgresql-configuration).
