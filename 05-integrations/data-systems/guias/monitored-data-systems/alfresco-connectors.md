# Alfresco

Alfresco data system falls under the [Monitored, Unstructured](/latest/docs/managing-data-system-connectors) data systems category.

## Steps to connect Alfresco with Securiti

To configure the Alfresco connector, perform the procedures in the following topics:

- If you haven't already done so, install and configure a Securiti pod as described in [Securiti pods](/v1/docs/pods-cluster-version-v128-and-later).
- Activate your Self-hosted data system's connector on the pod as described in [Securiti pods and elastic pods](/v1/docs/securiti-pods-and-elastic-pods).
- [Obtain permissions and authentication credentials in Alfresco](/latest/docs/obtain-permissions-and-authentication-credentials-in-alfresco).
- [Connecting Alfresco with Securiti](/latest/docs/new-ui-connecting-alfresco-with-securiti).
- [Configure discovery scans in Alfresco](/latest/docs/configure-discovery-scans-in-alfresco).

It becomes the responsibility of the organization to host, maintain, and manage the system or software.
