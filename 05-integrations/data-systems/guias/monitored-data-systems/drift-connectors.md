# Drift

The Drift connector lets you integrate your Drift conversational marketing platform with Securiti to support Data Subject Rights (DSR) requests. This is a scanless connector, meaning it does not support discovery scans or inventory ingestion. Instead, it enables you to search, retrieve, and manage personal data stored in Drift conversations and contact records in response to DSR requests.

Drift falls under the category of monitored, scanless data systems. For more information, see [data systems classification](/v1/docs/managing-data-system-connectors).

## Supported connector types and modules

| Connector type | Supported modules |
| --- | --- |
| Securiti Cloud | DSR Automation using APIs |

## Supported authentication methods

Drift uses OAuth authentication to connect to Securiti.
