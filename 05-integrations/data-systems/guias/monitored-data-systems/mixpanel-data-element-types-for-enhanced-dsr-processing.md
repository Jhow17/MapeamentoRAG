# MixPanel data element types for enhanced DSR processing

If you are using enhanced DSR processing, you can use the following MixPanel Data element types as identity PD for DSR requests:

- DISTINCT_ID

To learn more about enhanced DSR processing, see [Understanding enhanced DSR request processing](/v1/docs/understanding-identifiers-for-dsr-request-processing) (only available if you are subscribed to the Data Subject Rights module).
