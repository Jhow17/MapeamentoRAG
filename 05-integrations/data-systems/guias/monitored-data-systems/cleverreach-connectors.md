# CleverReach

CleverReach is an email marketing and automation platform for creating and managing marketing campaigns. By connecting CleverReach with Securiti, organizations can efficiently locate and manage personal data for Data Subject Requests (DSR), helping streamline privacy request fulfillment and support compliance with data protection regulations.

CleverReach falls under the category of [Monitored, Scanless data systems](/latest/docs/managing-data-system-connectors).

### Supported connector types and modules

| Connector type | Modules supported |
| --- | --- |
| CleverReach (Securiti-Cloud) | DSR Automation |

### Supported authentication methods

CleverReach supports OAuth authentication method using Client ID and Client Secret.

### Prerequisites for connecting CleverReach with Securiti

You must complete these prerequisites before connecting your CleverReach connector with Securiti

#### 1. Admin access in CleverReach

You must have Admin access in the CleverReach application to manage OAuth apps.

#### 2. Create and manage OAuth app

CleverReach admin must create and manage OAuth apps to get the credentials used for connector activation.

For more information on managing OAuth app, see [Acquire authentication credentials in CleverReach](/latest/docs/acquire-authentication-credentials-in-cleverreach).

See the sections below to connect your CleverReach connectors with Securiti.
