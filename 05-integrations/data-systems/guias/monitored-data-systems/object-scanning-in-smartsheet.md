# Object scanning in Smartsheet

The Smartsheet Connector scans multiple objects for both structured and unstructured data. The Connector scans the structured data in Smartsheet for the following objects:

- User
- Sheets

Structured data scanning requires [table training](/v1/docs/table-training-for-structured-and-hybrid-data-systems).

The following are scanned as unstructured data:

- Attachments of sheets
- Comments of sheets
- Attachments of proofs
- Comments of proofs
