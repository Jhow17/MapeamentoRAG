# Obtain database credentials for your BTrieve configuration

1. Open your database system client (in the figure below, it is DBL.Schema running on the MacOS operating system).

![BTRieve_DBDetails.jpg](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-d092c1b1-b565-e1fc-c1db-1f3df5c9d342.jpg)
2. Navigate to your networking database settings. In this example, it is called **Database Connection Dialog**.
3. Record the following details to use later:
  - Server Host or IP for example, `127.X.X.1`
  - Port number
  - Database username
  - Password
  - Name of the database for synchronization
