# Collect API information in ActiveCampaign

To integrate Securiti with ActiveCampaign for DSR automation, you obtain the account name and API key in ActiveCampaign so you can configure them in Securiti.

1. Log in to your ActiveCampaign account with your admin credentials at (https://www.activecampaign.com/login/)

You are redirected to your ActiveCampaign Dashboard.

![ActiveCamp_Login.jpg](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-bc1e1909-3a51-a542-e044-8e5bcf48401e.jpg)
2. On the left sidebar, click **Settings**.

![ActiveCamp_Dashboard.jpg](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-1f155363-8d95-9daf-45f0-27905f9106f5.jpg)
3. On the Account Settings screen, click **Developer**.

![ActiveCamp_Settings.jpg](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-c7606eee-dfa9-c0f7-0771-e998791bfc2a.jpg)
4. In the **API Access** area, record both the username portion of the display URL ("*securiti*" in this instance) and the **Key** to use later.

![ActiveCamp_Developer.jpg](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-b180db34-f003-6812-c26f-42347bf00572.jpg)
5. Proceed to [Activate the ActiveCampaign connector in Securiti](/v1/docs/activate-the-activecampaign-connector-in-securiti).
