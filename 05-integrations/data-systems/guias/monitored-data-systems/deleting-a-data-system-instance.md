# Deleting a data system instance

When you delete a Data system Instance, Securiti discards all Configuration information associated with the Instance. Securiti also automatically removes all tasks and subtasks for the Instance from all open DSR requests.

To delete a Data system Instance:

1. If you have not already done so, log in to Securiti with your admin Credentials.
2. To open the main menu, from the upper left corner of the left navigation bar, click the **Jewel** icon.
3. From the Platform Services section in new navigation, select **Settings**.
4. On the **System Settings** menu, choose **Integrations > Data Systems > Monitored & Unmonitored**.
5. On the **Data Systems** page, next to the Instance you want to delete, choose **More Actions** (three dots) **> Delete**.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Delete Instance(2).png)
6. On the confirmation popup, click **Delete** to confirm.

> [!NOTE]
> Note
> 
> You can delete a data system only once you have deactivated and purged the connector
