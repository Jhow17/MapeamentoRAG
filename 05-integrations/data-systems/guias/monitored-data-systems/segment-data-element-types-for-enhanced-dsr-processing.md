# Segment data element types for enhanced DSR processing

If you are using enhanced DSR processing, you can use the following Segment Data element types as identity PD for DSR requests:

- USER_ID

To learn more about enhanced DSR processing, see [Understanding enhanced DSR request processing](/v1/docs/understanding-identifiers-for-dsr-request-processing).
