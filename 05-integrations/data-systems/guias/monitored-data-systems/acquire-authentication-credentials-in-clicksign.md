# Acquire authentication credentials in Clicksign

1. Log in to your Clicksign account.

> [!NOTE]
> **Note**
> 
> This procedure has screenshots in the Portuguese language due to Clicksign's website default.
2. Clicksign uses URL (select Default or Sandbox from the menu) and Access Token during connector activation.

On the dashboard, select **Settings** in the left-hand menu.

![settings.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-cb4713c6-ca5d-2ed1-a914-cdb56d4488f9.png)
3. On the following page, select the API tab. Then click **Generate access Token**, as shown below.

![generate_access_token.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-8169c16d-7fd4-bff3-9d35-7300628403b3.png)
4. Record the Access Token to use later.
5. Proceed to [Connecting Clicksign with Securiti](/latest/docs/connecting-clicksign-with-securiti).
