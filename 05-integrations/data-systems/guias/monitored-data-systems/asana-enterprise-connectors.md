# Asana Enterprise

Asana Enterprise is a web and mobile work management platform similar to Jira, designed to help teams organize, track, and manage their work.

Asana Enterprise offers a set of Data Access, Management and Portability APIs that let data controllers easily access and manage their team member data through the Securiti platform. Using these APIs, Securiti bots execute DSR automation workflows to directly access, export, and delete data within the Asana Enterprise platform without any user intervention.

Asana Enterprise falls under the category of [Monitored, Unstructured](/latest/docs/managing-data-system-connectors) data systems.
