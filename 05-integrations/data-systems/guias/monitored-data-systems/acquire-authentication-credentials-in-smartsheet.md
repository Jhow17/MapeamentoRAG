# Acquire authentication credentials in Smartsheet

1. Log in to Smartsheet.
2. > [!WARNING]
> **Important**
> 
> You must create the application with your organization's admin account before Connector Activation, so user data is accessible.

On the Smartsheet homepage, select **Personal Settings > API Access**. Then click **Generate new access Token**, as shown below.

![Personal_Settings.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-0241d2c0-b87a-a86b-d84d-61289abb7699.png)

![API_Access.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-ba46529d-901b-0883-8adc-297921d8704c.png)
3. Enter a name in the API Access Token Name field.

![Enter_name.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-87dbffd8-336e-7350-692b-1cf4d12c2834.png)

Click **OK.**
4. Record Smartsheet API Token to use later.
5. Proceed to [Connecting Smartsheet with Securiti](/latest/docs/connecting-smartsheet-in-securiti).
