# Couchbase NoSQL erasure requests

When a data subject exercises their right to erasure, you must erase all personal data belonging to that user.

The copy of user data that Securiti automatically extracts and attaches to the subtask is exactly the same as the data extracted through an access request. See [Couchbase access requests](/v1/docs/couchbase-nosql-access-requests) for information about the data that is extracted and attached to the subtask.

Securiti does not implement any additional automated action within Couchbase for erasure requests. The erasure task owner must manually inspect the Couchbase object and erase the relevant personal data according to your organization's data erasure policies.
