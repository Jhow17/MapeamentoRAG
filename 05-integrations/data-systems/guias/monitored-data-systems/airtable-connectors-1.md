# Airtable

Airtable is a cloud-based collaboration platform that merges the simplicity of a spreadsheet with the power of a relational database, enabling teams to build custom applications and streamline workflows without writing code. Airtable (Securiti Cloud) falls under the category of monitored, structured data systems.

### Supported Connector types and modules

| Data system type | Modules supported |
| --- | --- |
| Securiti Cloud connector | DSR Automation using APIs |

### Supported authentication methods

- Securiti Cloud connector:
  - Personal Access Token

### Prerequisites for configuring Airtable connectors

#### 1. Airtable account access

You must have at least a trial account for Airtable to activate the connector.

#### 2. Private Cloud Storage (PCS) configuration

You must configure Private Cloud Storage (PCS) for your tenant to successfully authenticate Airtable Gencore data system connector. For more information on configuring PCS, see [Configuring Private Cloud Storage](/latest/docs/system-settings-configuring-private-cloud-storage).
