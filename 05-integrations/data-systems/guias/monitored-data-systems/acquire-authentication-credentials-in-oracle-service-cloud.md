# Acquire authentication credentials in Oracle Service Cloud

To acquire credentials for successful authentication of Oracle Service Cloud connector, perform the steps below:

1. Log in to Oracle Cloud.
2. Enable the minimum Permissions in Oracle Service Cloud for:

> [!WARNING]
> **Important**
> 
> The following isn't an exhaustive list for which you have to enable Permissions.
  - Custom objects
  - Incidents
  - Contacts
  - Accounts
3. Oracle Service Cloud uses Oracle **Instance Id**, **User Name**, and **Password** as Connector Activation params.

> [!NOTE]
> **Note**
> 
> This step assumes that the user has access to Authentication creds for Oracle Service Cloud before Connector Activation.
4. Proceed to [Connect Oracle Service Cloud connector with Securiti](/latest/docs/connect-oracle-service-cloud-connector-with-securiti).
