# Oracle Sales Cloud data element types for enhanced DSR processing

If you are using enhanced DSR processing, you can use the following Oracle Sales Cloud Data element types as identity PD for DSR requests:

- CONTACTS
- PARTNER_CONTACTS
- SALES_LEADS
- SELF_SERVICE_REGISTRATION_REQUESTS

To learn more about enhanced DSR processing, see [Understanding enhanced DSR request processing](https://helpcenter.securiti.ai/docs/understanding-identifiers-for-dsr-request-processing) (only available if you are subscribed to the Data Subject Rights module).
