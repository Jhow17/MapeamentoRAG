# Configuring the application secret

1. In the Manage area of the navigation pane for the connector page, click **Certificates and Secrets** as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/configuring-the-application-secret-en-image-xedb8630.png)
2. In the Client Secrets area, click **+ New client secret**.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/configuring-the-application-secret-en-image-9hrxnt5s.png)
3. Enter a description for the secret, for example “Securiti Connector for OneDrive”, and choose an expiration term. We recommend one year.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/configuring-the-application-secret-en-image-lkc52zj7.png)
4. Click **Add** to add the secret to the list.
5. Next to the new client secret, click **Copy to Clipboard** as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/configuring-the-application-secret-en-image-7ueytg8l.png)
6. Record the client secret so that you can use it when you create an Microsoft 365 Instance in Securiti.
7. Proceed to [Connecting Microsoft 365 Calendar with Securiti](/latest/docs/new-ui-connecting-microsoft-365-calendar-securiti-hosted-with-securiti).
