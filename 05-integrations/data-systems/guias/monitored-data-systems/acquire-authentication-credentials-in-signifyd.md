# Acquire authentication credentials in Signifyd

1. Log in to the Signifyd web app.
2. On the left hand side menu, under Settings, select **Teams**, then select **Add New**.
3. Give your team a name and save it.

![Team_Name_Signifyd.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-a2483390-1e98-c961-224f-454c0cbeaa67.png)

Below the "Name" field, you can see the **API Key** as shown.

![API_Key_Signifyd.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-5c352a0b-0b1a-cacd-dfc3-e4bb8d8998df.png)
4. Record the API Key to use later.
5. Proceed to [Connect Signifyd connector with Securiti](/latest/docs/connect-signifyd-connector-with-securiti).
