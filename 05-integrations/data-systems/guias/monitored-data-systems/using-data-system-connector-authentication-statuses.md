# Using the data system connector authentication statuses

The **Authentication** page displays the authentication and activation status of a connector after it has been activated. It helps you verify whether the connector is correctly configured and whether required permissions and features are functioning as expected.

The page contains the following sections:

- Connector authentication statuses
- Connector activation credentials

## Accessing the Authentication page

Once your data system is authenticated, you can access the Authentication page to view the authentication results.

To access the Authentication page:

1. On the left sidebar of the authenticated connector, click **Authentication**. ![Overview of authentication settings with connection test and feature permission status.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Authentication.png)

## Connector Authentication Statuses

This section shows the authentication and activation statuses generated by the diagnostic job during the authentication stage.

Use the table below to understand the status of module features.

| Authentication area | Description |
| --- | --- |
| Connection Test | Verifies that the connection to the data system was successful and authentication credentials were correct. |
| Feature Permission | Verifies whether the required permissions for platform features and modules are available. It also displays 100% when all required permissions are granted; otherwise, it shows the percentage of available permissions. |
| Connector Activation | Indicates whether the connector can successfully activate and establish a connection with the data source. |
| Discovery Scan | Indicates the status of advanced data discovery and scanning capabilities. |
| DSR | Indicates the status of Data Subject Rights (DSR) operations for the connector. |
| Metadata Scan | Indicates the status of metadata-only scanning. |
| Discovery Scan Metadata Sync | Indicates the status of metadata synchronization for discovery scans. |

## Status Indicators

### 

Each authentication area displays one of the following statuses:

| Status | Icon | Description |
| --- | --- | --- |
| Success | ✅(Green check) | The capability is fully configured and functioning as expected. |
| Partial | ⚠️ (Yellow warning) | The capability is partially configured. Some permissions or configurations are missing. |
| Failed | ❌(Red cross) | The capability is not configured correctly, or authentication has failed. |

> [!NOTE]
> Tip
> 
> You must hover over a status icon to view additional details about missing permissions or configuration issues.

## Connector credential details

This section displays the connector credentials used during connector authentication.

> [!NOTE]
> Note
> 
> - These values are read-only and are provided for reference and troubleshooting purposes.
> - Connector details vary according to data system connector type.

To view the connector credential details:

1. On the bottom of the **Authentication** page, under the **Connector details** section, click the **> (right arrow)** icon to open the connector authentication credential details.
  - If connector authentication details need modification:
    - On the bottom left of the page, click **Reconfigure** to update the connector details under the **Authentication** page.
  - If connector authentication details don’t need modification:
    - On the bottom right of the page, click **Continue to Configuration** to configure the supported scans settings under the **Configuration** page.
