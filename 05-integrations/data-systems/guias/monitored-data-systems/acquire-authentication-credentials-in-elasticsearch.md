# Acquire authentication credentials in Elasticsearch

1. Log in to Elasticsearch.

> [!NOTE]
> **Note**
> 
> This procedure assumes that you have a Database available prior to Connector Activation.
2. Record these parameters to use later:
  - Db **Host** is the address where the Database is hosted.
  - Db **Port** is on which the Database service is available.
  - Db **User** is the username authenticated by the Database. Here, the user should have correct Permissions to access the respective Database.
  - Db **Password** is the user password authenticated by the Database.
3. Proceed to [Connecting Elasticsearch with Securiti](/latest/docs/connecting-elasticsearch-with-securiti).
