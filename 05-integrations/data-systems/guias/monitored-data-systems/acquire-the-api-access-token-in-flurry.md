# Acquire the API access token in Flurry

The API Token is linked with the company data you are seeking access to. It authorizes data retrieval. Follow these steps to acquire API access Token:

1. Log in to **dev.flurry.com**.
2. On the left navigation bar, click **Admin** (wrench icon).
3. Select **Users**.

![Group_1.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-88ffe306-140b-cd67-77c7-0f2ed03d45a6.png)
4. Click **+ Programmatic User**.
5. Enter your Flurry Credentials i.e. email and password.

![flurry_api_2_1.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-e8bdf746-5dc5-2f53-d004-afc0d7fcd4ba.png)

> [!NOTE]
> **Note**
> 
> You must be an administrator to generate a Token.
6. The system suggests a default programmatic name for the Token tied to your company. Choose either to accept it or provide another name for it.

![flurry_api_3_1.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-1e21cae4-c2df-dfc3-2e2e-1736f6f20378.png)
7. Click **Create Account** to advance. When you create an account, Flurry generates an access Token.
8. Record the Token to use later. Be careful not to lose the Token because you cannot retrieve it from Flurry later on.

![flurry_api_4_1.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-8420fd6c-a43f-feaa-f7b8-f51c6b5881fd.png)
9. Click **Next** to declare the role for the programmatic user.
10. Make sure that Privacy Request API is **Enabled** as shown below, then click **Save**.

![Flurry_programmatic_access.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-cef1af83-58ca-1b2b-14df-4e043050d96e.png)
11. Proceed to [Connect the Flurry connector with Securiti](/latest/docs/connect-flurry-connector-with-securiti).
