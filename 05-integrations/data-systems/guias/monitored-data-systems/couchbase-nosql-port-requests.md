# Couchbase NoSQL port requests

When a data subject exercises their right to port data, you must provide the personal data concerning the data subject, in a structured, commonly used and machine-readable format.

The copy of user data that Securiti automatically extracts and attaches to the subtask is exactly the same as the data extracted through an access request. See [Couchbase access requests](/v1/docs/couchbase-nosql-access-requests) for information about the data that is extracted and attached to the subtask.

> [!NOTE]
> **Note:**
> 
> For port requests, regulations don't require you to provide the context around which the data is processed within your organization. Therefore port subtasks do not include a process record.

Securiti does not implement any additional automated action within Couchbase for port requests. The port task owner must manually inspect the Couchbase object, excerpt the relevant personal data, and attach the excerpted data to the subtask according to your organization's data port policies.
