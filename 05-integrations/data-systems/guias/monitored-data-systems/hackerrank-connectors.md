# HackerRank

HackerRank is a technical hiring and skills assessment platform that helps organizations evaluate and recruit talent. By connecting HackerRank with Securiti, organizations can efficiently locate and manage personal data for Data Subject Requests (DSR), helping streamline privacy request fulfillment and support compliance with data protection regulations.

### Supported connector types and modules

| Connector type | Modules supported |
| --- | --- |
| HackerRank (Securiti-Cloud) | DSR Automation |

### Supported authentication method

Securiti supports API Key authentication method for HackerRank.

### Prerequisites for configuring HackerRank connector

#### 1. Admin access in HackerRank

You must have admin access in HackerRank to provide the relevant permissions.

#### 2. Running HackerRank account

You must have HackerRank account. (Optional) If you haven't, you can create a trial account for HackerRank at [Start your free trial](https://www.hackerrank.com/work/free-trial).

#### 3. Use cases and permissions for HackerRank

| Use case | Constraints | Permissions | Explanation of use case |
| --- | --- | --- | --- |
| Data Subject Request (DSR) Automation Indexing | N/A | Assign **Access to Shared interviews (within teams)** permission to the team. | These permissions let Securiti read the file metadata in HackerRank to build the Personal Data Index for DSR Automation. |
