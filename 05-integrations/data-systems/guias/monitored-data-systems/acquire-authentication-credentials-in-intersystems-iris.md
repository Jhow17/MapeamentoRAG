# Acquire authentication credentials in InterSystems IRIS

1. Login to InterSystems IRIS instance.
2. Record the following parameters to use later:

> [!NOTE]
> **Note**
> 
> This procedure assumes that you have access to the IRIS database before connector activation.

You can change default JDBC Credentials from system administration.
  - **Host** - Where IRIS is deployed.
  - **Port** - SuperServer port (*51773*)
  - **User** - Default user (*_SYSTEM*)
  - **Password** - Default password (*SYS*)
  - **Namespace** - Default namespace (*User*)
  - **Database** - Db you're connecting to.
3. Proceed to [Connecting InterSystems IRIS with Securiti](/latest/docs/connecting-intersystems-iris-with-securiti).
