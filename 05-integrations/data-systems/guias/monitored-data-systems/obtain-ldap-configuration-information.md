# Obtain LDAP configuration information

Obtain the following information to use later when you activate the LDAP Connector:

- The IP Address or host name, and the port, for your LDAP Active Directory
- The username and password for the account that has administrative rights over your LDAP Active Directory
- The name of the server where the Active Directory is hosted

Once you have this information available, proceed to [Connecting LDAP Active Directory with Securiti](/latest/docs/connecting-ldap-active-directory-with-securiti).
