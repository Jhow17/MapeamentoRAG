# Authenticate the Mailchimp connector

You must fulfil the following prerequisites and authenticate your Mailchimp Data system to connect with Securiti.

### API key authentication for Mailchimp connector

Follow the procedure below to acquire API key Authentication Credentials for Mailchimp.

1. In your Mailchimp account, click on the profile icon and record the **Account Name**. You can also record it at the time of account creation.

![mailchimpOS_accountname.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-d8011096-2b5c-672b-0d95-ead979c35c0f.png)
2. Record the **Data Center** value from your account's URL in the browser. The data center value is the value right after the "https://" part of the URL.

![mailchimpOS_datacenter.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-3df0fe46-b816-254c-ea9a-bbf1988ceef3.png)
3. In your Profile section, from the top Row select **Extras** and click **API keys** from the menu.

![mailchimpOS_apikeysoption.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-abed4a5f-9bdc-4a1c-452c-5fda3f83aab9.png)
4. On the **API keys** page, click **Create a Key**.

![mailchimpOS_createakey.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-0f46e73c-100b-abbe-a603-93b548b1ab97.png)
5. Enter your API key name and click **Generate Key**. Record the API key to use later.

![mailchimpOS_generatekey.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-eb938ddd-2b42-f5eb-0c9f-dfe1ec4114a0.png)
6. Record your created key from the list of API keys, to use later.

![mailchimpOS_yourapikeys.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-28b6c3e4-090e-a8d5-0d03-011f0558c4b6.png)
7. Proceed to [Connecting Mailchimp with Securiti](/latest/docs/new-ui-connecting-mailchimp-with-securiti).
