# (Optional) Acquire Quarantine Policy parameters in OneDrive

You can configure the quarantine policy when activating the OneDrive Self-hosted Connector in Securiti.

> [!WARNING]
> **Important**
> 
> Before proceeding, ensure you are the admin with these privileges:
> 
> - Files.ReadWrite.All
> - Sites.ReadWrite.All

The Site URL parameter is required to configure the Quarantine Policy feature:

1. Log in to your Microsoft OneDrive account you want to use for file quarantine.

![unnamed.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-02679b15-bacb-636d-e6aa-79b520c429c4.png)
2. On the address bar, record the URL for later use.

![unnamed1.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-e5c56b37-e917-9cf8-5e13-90176960b367.png)

Proceed to [Connecting the OneDrive (Self-hosted) data system](/latest/docs/create-microsoft-365-onedrive-self-hosted-connector-instance-new-ui).
