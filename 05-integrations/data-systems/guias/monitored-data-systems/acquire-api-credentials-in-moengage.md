# Acquire API credentials in MoEngage

1. Log in to MoEngage with your admin Credentials.
2. On the left menu, navigate to **Settings > App Settings**.
3. On the General Settings tab, in the Account Settings area, record the App ID as shown below to use later.

![moengage_app_ID.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-c7d4ae5f-620e-372c-86ee-36a7caf81543.png)
4. Navigate to **Settings > APIs**.
5. On the General Settings tab, in the Data API Settings area, record both the Data API ID and the Data API Key as shown below to use later.

![Moengage_data_api_id_and_api_key.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-e6105bf1-c8ce-652e-671f-1d5b895834ca.png)
6. Proceed to [Connect MoEngage connector with Securiti](/latest/docs/connecting-the-moengage-connector-in-securiti).
