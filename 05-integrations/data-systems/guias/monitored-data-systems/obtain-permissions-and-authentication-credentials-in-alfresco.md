# Obtain permissions and authentication credentials in Alfresco

The Alfresco self-hosted data systems require an admin account username, password, and hostname for authentication.

> [!NOTE]
> **Important**
> 
> We assume you have an Alfresco instance running or you have access to the admin account with all required permissions enabled before activating the connector.

1. Record the following parameters for later use.
  - **User Id** - your admin account username (default is "admin").
  - **Password** - your admin account password (default is "admin").
  - **Host Name** - your Alfresco hostname with the port (default is "8080"), as shown in the example below.

*http://<ip or host>:port*

Where the "ip" or "host" displays the Alfresco domain setup.
2. Proceed to [Connecting Alfresco with Securiti](/latest/docs/new-ui-connecting-alfresco-with-securiti).
