# Twilio

Twilio is a cloud-based platform for programmable communications, providing developers with APIs to integrate messaging, voice, video, and authentication capabilities into applications. It enables businesses to build scalable communication solutions, such as SMS, email, phone calls, and video interactions, without the need for complex infrastructure. Twilio is a monitored, unstructured data system.

## Supported connector types and modules

| Connector type | Modules supported |
| --- | --- |
| Securiti Cloud connector | DSR Automation using APIs |

## Supported authentication methods

- Basic authentication using token

## Prerequisites for configuring Twilio connector

### 1. Twilio account access

You must have an active Twilio account to activate the connector.

### 2. Private Cloud Storage configuration

You must configure Private Cloud Storage (PCS) for your tenant to successfully authenticate Twilio data system connector. For more information on configuring PCS, see [Configuring Private Cloud Storage](/latest/docs/private-cloud-storage).

### 3. Connect Twilio with Securiti

To configure your Twilio connector, perform the procedures in the following topics:

1. [Authenticate the Twilio connector](/latest/docs/authenticate-the-twilio-connector)
2. [Connecting Twillo with Securiti](/latest/docs/connecting-twillo-with-securiti)
