# Couchbase NoSQL rectification requests

When a data subject exercises their right to rectify any (or all) portions of their personal data, you must comply with all such requests originating from that user.

The copy of user data that Securiti automatically extracts and attaches to the rectification subtask is exactly the same as the data extracted through an access request. See [Couchbase access requests](/v1/docs/couchbase-nosql-access-requests) for information about the data that is extracted and attached to the subtask.

Securiti does not implement any additional automated action within Couchbase for rectification requests. The rectification task owner must manually inspect the Couchbase object and take any rectification action required by your organization's data rectification policies.
