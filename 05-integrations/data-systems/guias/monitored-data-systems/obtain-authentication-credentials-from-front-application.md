# Obtain authentication credentials from Front application

> [!NOTE]
> **Note**
> 
> This procedure assumes you have an admin account in the Front application. Without admin access, you cannot see all Permissions required in this procedure.

1. Log in to the Front application through your admin account.
2. On the right upper corner, click the **Settings** icon.

![step2-final.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-63e0c7ed-e28f-ef2b-f830-9fd95d4a6172.png)
3. Under the **Company** tab on the left sidebar, click **Developers** > **API Tokens** > **Create API Token.**

![step3-front-final.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-af510606-d2ec-1803-9f8b-026499a81cd2.png)
4. On the Create API Token popup, do the following:

![Step-4-Front-Final.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-58138643-de4f-d232-776c-fd2b488f97d6.png)
  1. Enter the **API Token name**. See the example below.

*Front API Token*
  2. Mark the checkboxes for desired scopes from the **Select scopes** menu. You can choose Company resources and private resources.
  3. Click **Create.**
5. On the newly created API Token page, click **Copy** to save the API Token for Connector Activation in Securiti.

![step-5-front-app.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-1fad5152-9f8b-f27a-395b-8c4e9a0f5854.png)
6. Proceed to [Connect Front connector with Securiti](/latest/docs/connect-front-connector-with-securiti).
