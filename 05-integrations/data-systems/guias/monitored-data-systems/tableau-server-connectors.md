# Tableau Server

Tableau Server is an on-premise solution that requires organizations to manage their infrastructure. With Tableau Server, you get complete control and total flexibility. So, you can empower teams to use data to make better decisions.

Tableau Server is a combination of both Structured and Unstructured data systems.

> [!WARNING]
> **Important**
> 
> You must whitelist Tableau URLs for the connector to function correctly.

### Connect Tableau Server connectors with Securiti

To configure the Tableau Server connector, perform the procedures in the following topics:

1. [Acquire authentication credentials in Tableau Server](/latest/docs/acquire-authentication-credentials-in-tableau-server)
2. [Connecting Tableau Server with Securiti](/latest/docs/connecting-tableau-server-with-securiti)
