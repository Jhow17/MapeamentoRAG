# Alation

Alation is a [scanless](/latest/docs/managing-data-system-connectors) connector that works as a workflow node.

### Steps to connect Alation with Securiti

To configure the Alation connector, perform the procedures in the following topics:

- If you haven't already done so, install and configure a Securiti pod as described in [Securiti pods](/v1/docs/pods-cluster-version-v128-and-later).
- Activate your Self-hosted data system's connector on the pod as described in [Securiti pods and elastic pods](/v1/docs/securiti-pods-and-elastic-pods).

To use the Alation data system, you must link your structured on-premises database to Securiti.
- [Acquire authentication credentials in Alation](/latest/docs/acquire-authentication-credentials-in-alation).
- [Connecting Alation with Securiti](/latest/docs/new-ui-connecting-alation-with-securiti).
