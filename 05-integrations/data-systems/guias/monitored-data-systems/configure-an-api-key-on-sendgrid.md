# Configure an API Key on SendGrid

To integrate Securiti with SendGrid for DSR Automation, you obtain the API key for your account in SendGrid so you can configure it in Securiti.

1. Log in to your SendGrid account at <*https://app.sendgrid.com*>

SndfGrid opens your SendGrid Dashboard.

![SendGrid_Login_.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-2d447e10-ffef-2d9d-df40-904fa742a561.png)
2. Click **Settings** on the left sidebar on the dashboard.

![SendGrid_Dashboard_.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-49b42081-6d96-1af2-f70e-0c0d4e7f1175.png)
3. On the Settings menu, click **API Keys**.

SendGrid opens a page that lists all active API Keys.

![SendGrid_Dashboard-Settings_.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-d909be62-c2ed-113a-0514-0fb4f0c8585e.png)
4. Near the upper right corner, click **Create API Key**.

![SendGrid_EmptyAPIKEYList_.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-92444c2e-ce8a-de78-3e67-a1472f451060.png)
5. Create the API Key using the following settings, then click **Create & View**.

| API Key Name | Enter an appropriate name for the API Key |
| --- | --- |
| API Key Permission | Set as **Full Access** |

![SendGrid_APIKEYCreation_.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-619d5b04-797c-6b32-e1c2-b1e1d6c10651.png)
6. Copy the generated API Key to your notepad (as this will be used in the Connector Activation process) and click **Done**.

SendGrid redirects you to the list of API Keys.

![SendGrid_APIKEY_.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-7b300362-22c1-c52f-a9cf-0fb8145f7eac.png)

You can see the entry for your newly created API Key but not the API key itself.

![SendGrid_PostCreationAPIKEY_.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-fd03174b-192d-0b28-25d2-50b9f2b94ee7.png)
7. Proceed to [Connecting SendGrid with Securiti](/latest/docs/connecting-sendgrid-with-securiti).
