# Acquire authentication credentials in Oracle Sales Cloud

1. Log in to Oracle Cloud by selecting **Sales and Service Login** from the list of apps as shown.

![Oracle_selection.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-ab1ebb5f-63dc-4575-7c46-d2412f971362.png)

![Oracle_sign_in.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-a69e77a9-9b20-bff8-ace1-eb7962db4c1e.png)
2. From the address bar of your browser, record your base URL:

Since Oracle comes with a preconfigured environment, in this example the following is used as **Base URL**:

*https://adc4-zkaz-fa-ext.oracledemos.com*
3. Record the User Name and Password you used to access Sales Cloud (above).
4. Proceed to [Connect Oracle Sales Cloud connector with Securiti](/latest/docs/connect-oracle-sales-cloud-connector-with-securiti).
