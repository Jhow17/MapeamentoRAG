# Classification of scanning items for Shopify

Securiti supports different scanning activities for Self-hosted connectors.

#### Supported items for classification scans

Shopify (Self-hosted) Connector supports the following structured and unstructured items for classification scans:

| Data items | Data type |
| --- | --- |
| Draft orders | Structured |
| Locations | Structured |
| Customers | Structured |
| Orders | Structured |
| Pages | Unstructured |
| Articles | Unsructured |
| Comments on articles | Unsructured |
| Files | Unsructured |
