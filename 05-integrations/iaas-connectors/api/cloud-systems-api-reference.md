# IaaS Connectors API reference

The IaaS Connectors API documentation lets you create connector instances for supported IaaS clouds including AWS, Azure, GCP, and OCI, prepare templates, activate or deactivate IaaS connectors, and fetch their metadata details.

This API documentation includes operations such as:

- Fetch metadata details of IaaS connectors
- Activate or deactivate IaaS connectors
- Create instances of IaaS connectors
- Prepare Cloudformation (CF) or Terraform (TF) templates

Use the IaaS Connectors [REST API documentation](https://securiti-doc-router.securiti.ai/modules/cloud-systems/apidocs/index.html) to explore and test IaaS Connectors APIs, review HTTP endpoints, JSON request and response formats, query parameters, API schemas, authentication methods, and sample API requests, and access the Postman collection for supported AWS, Azure, GCP, and OCI cloud connectors.
