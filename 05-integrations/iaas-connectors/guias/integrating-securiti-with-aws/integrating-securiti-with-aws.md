# Integrating Securiti with AWS

**Scenario**

As a Data Security Officer, you must scan every AWS account before releasing a new app. Manually switching roles across dozens of accounts is slow and misses tagged test environments. Securiti lets you tag organizational units once, then run a single scan that sweeps data, volumes, and entitlements across all linked accounts — so you can quickly discover sensitive data, spot access gaps, and stay confident that every part of your AWS environment is secure.

Securiti offers extensive integration with AWS, allowing flexibility in scanning whether it’s a single AWS account, multiple accounts within an organizational unit, or all accounts across your organization. Organizational units can be defined and scanned using tags, which are fully configurable through the UI. This feature is particularly beneficial for large organizations with multiple accounts. After setup, Securiti ensures comprehensive coverage of AWS services, providing thorough asset discovery and scanning of data, volumes, access entitlements, and AI services.

For details on how the integration works and the permissions granted to Securiti, see the [policies and permissions required for AWS integration](/v1/docs/policies-and-permissions-required-for-aws-integration) section.
