# Integrating Securiti with Google Cloud Platform

**Scenario**

As a Data Security Officer, you must prove every GCP project is secure before board reviews. Manually logging into each project, checking assets and misconfigurations, and exporting findings costs days and misses hidden data. With Securiti, you onboard once; the platform creates service accounts, lets you scan all projects, fixes risks automatically, and flags sensitive data. You deliver a verified risk report in hours.

Securiti offers streamlined integration with Google Cloud Platform (GCP), offering flexibility in scanning a single GCP project, or multiple projects. Once set up, Securiti ensures comprehensive coverage of GCP services, providing thorough asset discovery, scanning of cloud assets, security posture misconfigurations with auto-remediation, and identifying sensitive data.

Securiti automatically creates the required service accounts in the first project it detects during the integration process. For details on these service accounts, see the [How it Works](/v1/docs/how-it-works) section.
