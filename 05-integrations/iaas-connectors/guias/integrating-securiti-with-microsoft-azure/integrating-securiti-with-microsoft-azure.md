# Integrating Securiti with Microsoft Azure

**Scenario**

As a Data Compliance Officer, you must review access controls and spot misconfigurations across dozens of Azure subscriptions every month. Manually compiling asset and access lists across resource groups drags on for days and still overlooks misconfigurations. After you set up Securiti’s Azure integration, it lets you run continuous asset discovery, posture scans, and policy enforcement across all subscriptions — ensuring every subscription meets security standards and freeing hours for higher‑priority work.

Securiti integrates with Microsoft Azure to automate asset discovery, security posture scans, and policy enforcement, strengthening cloud security and compliance. It lets you to identify misconfigurations, monitor access controls, and manage sensitive data across your Azure environment. The integration process includes setting up an Azure instance, configuring security scans, and managing discovered assets on the Securiti platform.
