# Integrating Securiti with Oracle Cloud Infrastructure

**Scenario**

As a Data Governance Officer, you must confirm that every OCI compartment and database meets internal security policies before governance reviews. Without automation, this means sifting through countless settings across ten accounts, making it easy to miss critical misconfigurations. After you onboard your OCI tenancy, Securiti automates asset discovery, posture assessments, and policy enforcement. You gain full visibility and governance control in minutes, ensuring consistent compliance and streamlined audits.

Securiti integrates with Oracle Cloud Infrastructure (OCI) to automate asset discovery, perform security posture assessments, and enforce policies, helping strengthen your cloud security and compliance efforts. The integration lets you detect misconfigurations, oversee access controls, and govern sensitive data across your OCI environment. The setup process involves creating an OCI instance, configuring security scans, and managing the discovered assets directly within the Securiti platform.
