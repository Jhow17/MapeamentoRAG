# IaaS Connectors RBAC permissions and roles

The new Role-Based Access Control (RBAC) framework provides fine-grained permissions for IaaS Connectors. It introduces a set of system-generated roles with predefined permissions, while also allowing you to create custom roles with IaaS Connectors specific permissions. Custom roles can include permissions that are linked to other related permissions, creating dependencies and ensuring consistent access control. In contrast, system-generated roles automatically inherit the specific permissions defined for them.

### Accessing IaaS Connectors permissions

To navigate to IaaS Connectors RBAC permissions in ​Securiti, follow the steps provided below:

1. From the upper left corner of the left navigation bar, click the ​**Jewel**​ icon, and choose ​**Settings**​​ from the left navigation bar. ![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image(992).png)
2. Under the **​Organizational**​, choose ​**Access Management** > **Roles**​. ![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image(994).png)
3. On the ​**Roles**​ page, select ​**+ Create Role​**.
4. Under the ​**Permissions**​ section, click the ​**IaaS Cloud** tab to access the permissions, as shown below.

![System settings interface showing permissions for IaaS Cloud role management options.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/iaas-cloud-rbac-update.png)

### IaaS Connectors permissions with custom roles

Securiti lets you select fine-grained permissions for each custom role you create in the Platform.

**Permission:** It is a parent permission that grants specific rights to perform certain actions within the system. For example, `Create Iaas Connector`, `Update Iaas Connector`, or `Read IaaS Connector`.

**Explanation:** Describes why the permission is needed and the context in which it is used. For example, the “Read IaaS Connector” permission is required to have read access to Iaas Connector resource.

**Dependent permissions:** These are a set of permissions that are automatically applied in the same or different modules when a parent permission is selected.
