# EDC Sources

EDC Sources are the integrations that bring metadata into the Enterprise Data Catalog. Each source connects to a system that Securiti's discovery scans do not cover natively, extracts its metadata, and registers those assets in the catalog so they are searchable and governable alongside everything else.

**EDC Source** and **EDC Ingestion**, available within the [Enterprise Data Catalog](/latest/docs/using-enterprise-data-catalog) module, serve the same purpose. Both let you configure and run metadata ingestion from the same set of sources. The difference is the experience: **EDC Source** uses the updated interface, where you configure setup, authentication, and filters through form fields, and monitor runs from a dedicated run history. **EDC Ingestion** uses the classic flow, where you define the ingestion recipe in YAML.

For more information, see [EDC Sources](/latest/docs/using-edc-sources).
