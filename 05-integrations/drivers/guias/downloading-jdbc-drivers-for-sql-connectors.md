# Downloading JDBC drivers for SQL connectors

The page summarizes (Java Database Connectivity) JDBC drivers and their location required to connect data systems to pods.

> [!NOTE]
> **Important**
> 
> We recommend that you consult with the DBA of the Database in question if you are provisioning the connector.

You can upload them from within Securiti as described in [Uploading JDBC driver files in Securiti](/latest/docs/uploading-jdbc-driver-files-in-securiti).

If Securiti finds the required drivers, you can proceed with Connector Activation. Otherwise, Securiti displays the error message reminding you to upload them first.
