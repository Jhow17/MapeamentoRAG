# What's New in 1.142

### Integrate your Microsoft Teams with Securiti’s Genia!

Securiti’s Genia is now available for Microsoft Teams! You can interact with it directly to ask questions, search your organization’s approved knowledge bases, and get quick responses - all without leaving the conversation.

[Explore Genia!](/latest/docs/configuring-messaging-app-integrations)

![User interface showcasing Microsoft Teams with a chat feature and Ask Genia option.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Integrate Your Microsoft Teams with Securiti’s Genia!.png)

### Smoother Azure Onboarding Experience

One-click activation works well for many Azure setups, but some teams prefer to review permissions before they proceed. With this update, Azure onboarding now includes a Download Template option. You can download the Terraform configuration and review it before moving forward. Moreover, the onboarding experience now uses a persistent preview page instead of a modal, which makes the setup flow smoother.

[Explore the documentation](/latest/docs/creating-a-microsoft-azure-instance)

![Connection between two logos with a download icon indicating a transfer process.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/[IaaS Cloud]Smoother Azure Onboarding Experience.jpg)

### Discover More Azure Assets: Disk Snapshot, Cosmos DB PostgreSQL, Cosmos DB Cassandra

As Azure environments scale, some resources may quietly slip off the radar. Disk snapshots and distributed databases are common examples. Asset Discovery now finds Azure Disk Snapshots along with Azure CosmosDB workloads that run on PostgreSQL and Cassandra APIs. These assets often support backups, restores, and high-volume data use. Once you run a scan, they show up alongside your existing Azure assets. This helps you understand where data copies are stored and where database workloads live, without having to search across multiple services.

[Read more about it](/latest/docs/data-security-posture-management-solution)

![Visual representation of data processing components connected to a central element.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/[IaaS Cloud] Discover More Azure Assets_ Disk Snapshot, Cosmos DB PostgreSQL, Cosmos DB Cassandra.jpg)

### Broader EDM Coverage: Jira, Teradata, and Google Cloud SQL

Exact Data Matching coverage for Securiti's structured data systems just got broader. You can now use EDM indexing and profiles with Teradata, Google Cloud SQL for PostgreSQL, and Google Cloud SQL for MySQL. Create precise data indexes and profiles across these platforms to detect, map, and match sensitive data consistently. Now you can improve match accuracy for your structured data with consistent indexing and profiling.

[Learn more about it](/latest/docs/supported-data-systems-for-exact-data-indexes)

![Illustration showing data flow between two platforms with a central connection point.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/[SDI] Broader EDM Coverage_ Now for Jira, Teradata, and Google Cloud SQL.jpg)

### Enhancing Google Workspace Gmail Scanning

Want your Gmail scans to go beyond attachments? You can now scan for sensitive data in both message body content and attachments using the Google Workspace Gmail connector. This simplifies setup and reduces the number of scans you need to manage. New discovery scans now include an option to scan the message body content. Older scans keep their current settings by default, to ensure backward compatibility.

[Learn how to configure the discovery scan](/latest/docs/g-suite-gmail-message-body-attachments-connectors)

![Google logo with user profiles and a link icon representing connection and collaboration.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/[Connectors]Enhancing G Suite Gmail Scanning.jpg)

### Redesigned Privacy Notice Management Interface

As the number of privacy notices grows, everyday updates can become harder to manage. The enhanced dashboard helps you stay organized by making it easier to search notices, reuse saved filters, and customize how information is displayed. You can review details and apply style changes in bulk. The redesigned editor then makes editing more straightforward. Content updates are easier to navigate, required fields are clearly structured, and translations are managed in one place, which helps keep notices accurate and consistent across regions.

[See how to use redesigned dashboard and editor](/latest/docs/creating-a-new-privacy-notice)

### Manage Privacy Notice Translations in One Place

When privacy notices need to work across countries, language control becomes critical. This update expands language support so you can apply translations in up to 135 languages. You manage everything from a central language view, where you add languages and set fonts for each one. Notices can adapt automatically using browser-based language detection, or let users choose their preferred language. Section titles can also be translated, helping notices stay readable and familiar no matter which language is shown.

[See language management in action](/latest/docs/managing-language-translations-for-privacy-notices)

### DPDPA-Ready Privacy Notices

Supporting users across India requires more than a single language. With this update, Privacy Notice Management broadens language support to better serve users across India. This covers both widely spoken and regional languages, including Assamese, Hindi, Tamil, and Maithili. You can host privacy notices in these languages to meet DPDPA requirements and improve access for end users. This makes it easier to communicate privacy information clearly and consistently across different linguistic groups.

[See how language management works](/latest/docs/managing-language-translations-for-privacy-notices)

### DSR Now Supports UAE DIFC DPL and Qatar QFC

Supporting regional privacy laws is a key part of managing DSR requests. Two more regulations are now supported in the DSR module. This includes:

United Arab Emirates DIFC DPL and Qatar QFC, along with notification extension templates tied to each regulation. You can review both the templates and the supporting regulatory research in the DSR module, helping you manage requests with confidence across these regions.

[View the list of supported regulations](/latest/docs/supported-jurisdictions-and-regulations-in-dsr-form)

### New Framework Coverage: RIIO-3 Data Best Practice Guidance & NYDFS Cybersecurity Regulation

If you manage security or data compliance, you’ve probably felt the pain of mapping rules to real controls. That’s now simpler. We’ve added support for NYDFS Cybersecurity Regulation and RIIO-3 Data Best Practice Guidance. NYDFS focuses on protecting nonpublic information and enforcing security practices. RIIO-3 focuses on how data is governed, shared, and maintained. For example, you can confirm MFA is enforced for external access under NYDFS, or check that data quality issues are logged and tracked through resolution under RIIO-3.

[See list of framework supported](/latest/docs/using-the-framework-dashboard)

![RIIO-3 Data Best Practice Guidance and NYDFS Cybersecurity Regulation overview.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/[Compliance] New Framework Coverage_ RIIO-3 Data Best Practice Guidance &amp; NYDFS Cybersecurity Regulation.jpg)

### Two Dashboards, Two Clear Purposes: A Clearer Way to Work with Consent Data

If you manage large volumes of consent data, finding what you need quickly can be challenging. Securiti now offers a new consent analytics experience that separates records from metrics into two focused dashboards.

- Use the Consent Records dashboard to review detailed consent entries with advanced filtering.
- Use the Consent Metrics dashboard to track trends, measure engagement, and understand banner effectiveness over time.

Each dashboard serves a distinct purpose, helping you move from raw consent data to meaningful insights without jumping between views.

[See more details about the new dashboards](/latest/docs/using-the-cookie-consent-dashboard-and-metrics)

![Overview of a Cookie Consent Dashboard displaying various data visualizations.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/[Cookie consent] New Cookie Consent Dashboard &amp; Analytics.jpg)

### Compare Cookie Scans to Spot What's Changed

Cookie scans can change often, and it’s not always easy to know what's different from one scan to the next. Securiti now lets you compare results across recent cookie scans for the same domain. You can view a quick summary of new, missing, or changed trackers right after a scan completes, or open View All Scans to compare any two scans from the most recent five. The comparison includes multiple analysis views, so you can quickly spot updates across trackers, scanned pages, and cookie categories. This makes it easier to monitor compliance-impacting changes and ensure your consent setup stays accurate over time. You can also download a CSV report for validation or audits.

[Learn how to compare cookie scan results](/latest/docs/scanning-your-website-for-cookies)

![Comparison of tracker analysis between Scan A and Scan B with download option.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/[Cookie Consent] Allow customers to compare 2 cookie domain scans directly w_in management portal UI (2).png)

### AI-assisted SDK and Permission Detection

If you rely on mobile app scans to set up consent, missing SDKs or permissions can lead to gaps in tracking and compliance. To reduce this risk, Securiti now adds AI-based suggestions to the mobile app scanner. The scanner uses AI to surface additional SDKs and Permissions that may not be detected during a standard scan, helping you improve coverage. After reviewing the suggestions, you can choose what to keep and add them directly to your app's consent setup and SDK & Permissions Library. This makes it easier to validate scan results and reduce manual follow-ups.

[Learn more about scanning mobile apps for SDKs and permissions](/latest/docs/scanning-your-mobile-application-for-sdks-and-permissions)
