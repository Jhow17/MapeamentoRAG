# Getting Started

**Scenario**

As a data security analyst, data protection officer, or someone responsible for protecting your organization and its consumers’ data and ensuring compliance, if you have identified the modules you plan to use, this page is a great starting point. From the left navigation menu, click on the relevant module’s Getting Started page to see the end-to-end journey and follow a guided path to understand what the Securiti Platform can do for you.
