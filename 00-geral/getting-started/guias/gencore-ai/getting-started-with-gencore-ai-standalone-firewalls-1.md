# Getting started with Gencore AI Standalone firewalls

Enterprises adopting large language models (LLMs) must ensure that these systems handle unstructured data responsibly while upholding security, preserving privacy, and respecting consumption agreements such as licensing. The integration of LLMs into business applications introduces new challenges in data security, making it essential to implement strategies that protect sensitive information.

Organizations can use firewalls for the following purposes:

- **​​Prohibiting or Restricting LLM Usage**​​: Enforce bans or limitations on LLM usage to mitigate the risk of data leaks.
- **​​Implementing Foundational Controls**​​: Employ basic security controls provided by AI vendors to fortify defenses against potential data breaches.
- **​​Leveraging Data Security Solutions**​​: Integrate services like content scanning and LLM-specific firewalls to prevent the input or leakage of sensitive data through LLMs.

Securiti’s Gencore AI offers configurable and easy-to-monitor firewalls, along with built-in testing capabilities. A firewall profile consists of policies that define how the firewall evaluates and manages data. With these profiles, you can

- Assess incoming content.
- Evaluate prompts and access patterns for suspicious or prohibited content.
- Inspect responses to prevent the release of restricted information.

### Using Standalone firewall profiles

You can create and configure Standalone profiles as independent firewall profiles in external applications. You can access standalone profiles as follows:

- **Securiti platform**: You can [generate API keys](/v1/docs/configuring-firewall-apis) to apply firewall profiles directly to messages generated by your application.
- **Self-hosted**: You can deploy firewalls in your [user portal custom deployment](/v1/docs/configuring-user-portal#gencore-ai-self-hosted-deployment-configuration). You can use self-hosted firewall profiles as follows:
  - AWS Sagemaker
  - On-premises

### Creating standalone firewall profiles

Gencore AI gives you the flexibility to create custom firewall profiles tailored to your organization’s needs. You can either:

- **Build from existing policies**: Start with predefined policies that include built-in exemplar topics and rules, and quickly assemble firewall profiles based on them.
- **Build from scratch**: To build your firewall profile from the beginning:
  - Define new [exemplars](/v1/docs/using-exemplars)
  - Configure created exemplars in [rules](/v1/docs/using-firewall-rules-1)
  - Group those rules into [policies](/latest/docs/using-llm-firewall-policies)
  - Create firewall [profiles](/v1/docs/creating-firewall-profiles) from the policies.

For more information on creating ​standalone firewall profiles​​, see ​[Creating firewall profiles​​](/v1/docs/creating-firewall-profiles).
