# Getting Started with Vendor Assessments

### Getting Started flow

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Vendor%20Assessment-design%201.drawio(1).svg)

> [!NOTE]
> **Note**
> 
> Any vendor you add and use for assessment appears as a data mapping item in the Vendors list under Data Maps.

### Step 1 - Publish a template

| **Prerequisites** You can create a new template or choose from the pre-configured templates list. You can also select from the list of system-provided templates, such as GDPR, CCPA, NIST, etc. Edit or import sections. Configure required questions and add question logic. Save a template or publish the version that looks good. [Learn more](/v1/docs/working-with-assessment-templates) | [Embedded content](https://player.vimeo.com/video/1010898204) |
| --- | --- |

### Step 2 - Launch an Assessment

| **Configure launch settings** Select which template to use. Determine who is responsible for what, then assign assessment reviewers and respondents. Set email notification template and define timelines (due dates/reminders). Optionally, assign section(s) or question(s) [Learn more](/v1/docs/launching-a-new-assessment-in-securiti) | [Embedded content](https://player.vimeo.com/video/1010888261) |
| --- | --- |

### Step 3 - Answer an Assessment

| ![Screenshot_2024-09-23_at_7_40_07_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-afc4651a-5ee3-2e3c-6953-102c736aec61(1).png) | **Enter responses** Respond to assigned questions. Upload attachments and collaborate on messages. Submit responses so the responsible team can review [Learn more](/v1/docs/answering-assessment-questions-in-securiti) |
| --- | --- |

### Step 4 - Review the Responses

| **Assess responses** Ensure submitted responses are complete and accurate. Approve any responses good to go. **Flag answers and assign risk** You can create a flag for responses containing a security vulnerability or incomplete information, such as assigning risk, specifying the owner, and setting a timeline for resolution. Once you're done, send the assessment back to the respondent. **Address Open Flags** The respondent must address Open Flags and resubmit. If everything's in order, approve the assessment. [Learn more](/v1/docs/understanding-workflow-stages-and-assessment-use-cases) | ![Screenshot_2024-09-23_at_7_44_59_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-4a4194e0-118d-65d5-83ab-168ccdf21cd8(1).png) ![Screenshot_2024-09-23_at_8_07_00_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-2699e295-5b48-5906-3bd6-994f094d20b5(1).png) ![Screenshot_2024-09-23_at_8_34_28_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-79ca6185-2bad-1a01-29e1-3cc573ce071b(1).png) |

### Vendor Assessments API Documentation

Securiti offers a set of APIs that let you integrate your preferred platform with ours. The Vendor Assessments API documentation provides detailed descriptions for each API, including information on endpoints and parameters, examples, and usage guidelines. See the table below for more details.

| **Run APIs directly from the doc** With our interactive API documentation, you can execute API requests directly within the document. This lets you quickly test endpoints and view API responses without setting up a separate environment. [Learn more](https://securiti-doc-router.securiti.ai/modules/vendor-assessments/apidocs/index.html#section/Getting-Started) | [Embedded content](https://player.vimeo.com/video/1012313059) |
| --- | --- |
| **Download the Postman collection** We also provide a Postman collection for customers who prefer to execute APIs using it. This collection contains a set of pre-configured requests that let you quickly test and explore the functionalities of our APIs. [Learn more](https://securiti-doc-router.securiti.ai/modules/vendor-assessments/apidocs/index.html#section/Getting-Started/Import-Postman-Collection) | ![Screenshot_from_2024-10-25_16-10-10.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-3e03be74-f29c-14ae-6eb0-e65bca2480c9.png) |
