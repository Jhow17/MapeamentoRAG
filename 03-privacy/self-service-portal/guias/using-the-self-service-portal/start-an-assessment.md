# Start an assessment

Using the Securiti’s Self Service Portal you can initiate assessments from published assessment templates.

To start a new assessment as a system guest user:

1. Login to the self-service portal and click the **Assessments** tab.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2026-07-09 at 2.29.28 PM.png)

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2026-07-15 at 1.39.41 PM.png)
  1. The list supports a search bar and uses Due Date as the default sort but you can also sort by assessment ID.
  2. Use the “Overdue” and “Template” filters on the page to narrow assessments.
  3. A default filter is in place for Not Started and In Progress stages which you can modify it to suit.
2. Near the upper right corner of the page, click **New Assessment**.
3. The Assessment Templates List shows you templates frequently used. Toggling on “List all templates” shows all available templates.

Click **Use Template**

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2026-07-09 at 2.42.31 PM.png)
4. Review the launch popup and apply settings to suit.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2026-07-09 at 2.44.08 PM.png)

> [!NOTE]
> **Note**
> 
> Observe these caveats:
> 
> - As a Securiti user, you're automatically assigned the respondent role on the launch popup. You can assign the reviewers you want. The respondent field is disabled for editing.
> - If default reviewers are configured in the system, they're preselected on the launch popup. Both reviewer and respondent fields are disabled.
5. Click **Launch New Assessment**.
