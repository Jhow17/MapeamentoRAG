# Installing the browser plugin

You use the Securiti browser extension to extract the form fields and buttons and compile them into a JSON object that you upload to Securiti. You can then use Securiti to generate a code snippet that you add to the code for the web form.

> [!NOTE]
> **Note**
> 
> Observe the following extension limitations:
> 
> - It does not support:
> 
> In some cases, you can enter these fields manually in the portal or edit the generated code to capture consent.
>   - CAPTCHAs
>   - Forms lacking standard `&lt;form&gt;` tags
>   - Dynamic attributes
>   - Embedded within another iframe
>   - Multiple forms with the same identifiers on the same page
>   - Mandatory checkboxes
>   - Uploads/attachments

First, install the **Veeam (Securiti.AI) Form Extractor** extension from the **Chrome Web Store**.

To install the extension:

1. Access the [**Veeam (Securiti.AI) Form Extractor**](https://chrome.google.com/webstore/detail/djilfdbabbdlbbceebcaiipgfidkapjm) extension on the **Chrome Web store**.

> [!WARNING]
> Important
> 
> This extension is not publicly available. You can install it only using the link provided in **Step 1** of this procedure.
2. Near the upper right corner of the extension page, click **Add to Chrome**, as shown below.

![Veeam (Securiti.AI) Form Extractor extension details and permissions displayed on Chrome.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/form_extractor_installation_1(2).png)
3. On the **Add** **Veeam (Securiti.AI) Form Extractor** popup, click **Add extension** to confirm the installation, as shown below.

![Prompt to add the Veeam Form Extractor extension in the Chrome Web Store.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/form_extractor_installation_2(1).png)
4. View the browser toolbar to make sure the extension icon appears, as shown below.

![Veeam Form Extractor extension added to Chrome with permissions displayed.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/form_extractor_installation_3(1).png)
5. After installing the extension, proceed to [Extracting the form JSON](/v1/docs/extracting-the-form-json).
