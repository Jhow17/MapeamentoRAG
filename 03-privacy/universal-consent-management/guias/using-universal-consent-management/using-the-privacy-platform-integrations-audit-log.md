# Using the Privacy Platform Integrations Audit Log

The audit log for the Privacy Platform Integration records all activities, including creating, deleting, updating, disabling, and enabling integrations. Use this log to monitor actions and maintain visibility over privacy platform integration in management.

![PPI-Audit_log-dashboard.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-b74b238c-62c1-3bd6-f20d-d45d92cef201.png)

From the **Audit Log** page, you can:

- Filter audit log values by data subjects' email addresses, as shown below.

![Search_by_username.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-4dbd6a09-1057-5462-3d19-ab502f8f57a5.png)
- Filter audit log values by integration name, as shown below.

![Search_by_integration-name.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-d5246591-0374-92c5-3364-c2486727f770.png)
- Filter audit log values by data subjects' following activity types, as shown below.

![Search_by_integration-type.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-e47045d3-5aac-f781-7bb2-2622b5918514.png)

![Search-results.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-822147f3-ee7e-299b-680e-a234d101d11d.png)
  - Created
  - Deleted
  - Updated
  - Disabled
  - Enabled
- View detailed metadata of any integration, as shown below.

![PPI-metadata.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-99f4c3fb-29c4-dd94-4ff6-517cb461b95b.png)
