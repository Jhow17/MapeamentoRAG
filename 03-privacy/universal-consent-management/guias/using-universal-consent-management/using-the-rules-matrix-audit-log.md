# Using the Rules Matrix Audit Log

The audit log for the Rules Matrix records all activities, including adding, editing, restoring, and deleting rules. It also tracks when rules are activated, deactivated, shared, or exported. Use this log to monitor actions and maintain visibility over rule management.

![Audit_log_intro.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-05118239-84ea-efd4-5767-7440360532a2.png)

From the **Audit Log** page, you can:

- Filter audit log values by data subjects' email addresses, as shown below.

![Apply_filter_audit_log1-a.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-d7925204-0ed0-979e-1aa5-3e324c48cb0f.png)
- Filter audit log values by data subjects' following activities, as shown below.

![Apply_filter_audit_log1-b.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-a44524d7-ffff-a0c4-8623-ab3b57056d22.png)

![Apply_filter_audit_log2.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-c90802e1-6d26-3153-6ff5-b0994bd84147.png)
  - Add
  - Edit
  - Sync
  - Delete
  - Activate
  - Deactivate
  - Restore
  - Share
- View detailed metadata of any rule, as shown below.

![Audit_log_metadata.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-de85b678-6a33-05b1-2f85-a2bb564c06e3.png)
