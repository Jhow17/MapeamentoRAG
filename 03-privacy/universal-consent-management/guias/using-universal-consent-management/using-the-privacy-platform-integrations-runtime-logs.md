# Using the Privacy Platform Integrations Runtime Logs

The runtime logs for Privacy Platform Integrations ensure transparency by tracking all runtime activities you perform with integrations. The logs record and display details such as status, integration name, data system, instance name, object name, integration type, and time. This visibility helps you monitor integration performance quickly and maintain operational reliability.

![Runtimes log.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-8120b322-f001-d501-42ed-82eacc055b60.png)

From the **Runtime Logs** page, you can:

- Search runtime log values by **Integration Name**, **Data System**, or **Instance Name** as shown below.

![Search_integrations.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-3df65e45-3e07-0e23-558d-12dc392ddad8.png)
- Filter runtime log values by integration **Status**, as shown below.

![Search_by_status.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-d59a58bf-a7b1-9612-f830-2b13f6197ba0.png)
- Filter runtime log values by **Integration Name**, as shown below.

![Search_by_integration_name.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-f8b78677-a796-153d-20ea-548b199e1986.png)
- Filter runtime log values by **Integration Type**, as shown below.

![Search_by_integration_type.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-edcbf61f-f205-96d6-b504-79e619b97051.png)
