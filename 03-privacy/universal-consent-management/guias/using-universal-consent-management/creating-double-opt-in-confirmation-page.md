# Creating double opt-in confirmation page

You can create a double opt-in confirmation page to notify data subjects after they confirm their preferences through the double opt-in email.

To create a double opt-in confirmation message:

1. In Securiti, open Universal Consent Management, and choose **Explorers > Consent Confirmation Page Manager**.
2. Near the upper right corner, click **+ Create New**, as shown below.

![Consent Confirmation Page Manager interface displaying options for managing consent messages.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/doi_message_1.png)
3. From the **New Consent Confirmation Page** popup, select **Type** as **Double Opt-in**, give **Confirmation Page Name**, and click **Create** as shown below.

![Creating a new consent confirmation page with options for type and name.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/doi_message_2.png)
4. In the page **Configuration** section, click **Upload Image**. In the **Upload** popup, browse to the file containing your organization’s logo, and then click **Upload** to upload the logo, as shown below.

![Upload image section for double opt-in confirmation message configuration settings.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/doi_message_3.png)
5. In the page text box, update the text as needed or customize it using the toolbar, as shown below.

![Confirmation message indicating successful choice confirmation in a user interface.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/doi_message_4.png)
6. To map translations, mark the **Enable Translation Mapping**, and provide the translation for the selected language, as shown below.

![Settings for double opt-in confirmation message with translation mapping enabled.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/doi_message_5.png)
7. From the **Preview** panel, select the desired preview option to preview your confirmation page, as shown below.

![Double opt-in confirmation message with options for web, tablet, and mobile views.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/doi_message_6.png)
8. To rename your message, near the upper right corner, next to **Save** click **Options** (three dots) and select **Rename** from the menu.

From the **Rename** popup, modify the name and click **Update** as shown below.

![Configuration settings for a double opt-in confirmation message with options to update.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/doi_message_7.png)

## Using top-level filter

The top-level filter lets you combine different properties of the export jobs and apply filters accordingly. It works from the top down and determines the result values in the grid view.

To use the top-level filter:

1. Near the upper left corner of the **Consent Confirmation Page Manager** dashboard, click **+**, as shown below.

![Consent Confirmation Page Manager interface displaying options for managing user consent pages.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/doi_message_filter_1.png)
2. From the filters panel, apply one or more filters using the following properties.

| Property | Description |
| --- | --- |
| Date Created | Filters confirmation pages by the date range in which they are created. You can filter pages using the following operator: - **between** to select a date range |
| Name | Filters confirmation pages by their names. You can filter pages using the following operator: - **contains** to specify the characters or words included in the confirmation page name. |
| Owner | Filters confirmation pages by the owner. You can filter export jobs using the following operator: - is one of to select one or more owners |

For instance, to filter confirmation pages by **Date Created** (property), from the left pane of the filter panel select **Date Created**, then from the right pane select the dates using the date pickers, as shown below.

![Date filter options for consent confirmation page, selecting between specific dates.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/doi_message_filter_2.png)
3. Repeat the same step for other properties to suit your search needs. Once you apply all required properties, near the bottom of the filter panel, click **Apply**, as shown below.

![Filter options for date range selection in the Consent Confirmation Page Manager interface.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/doi_message_filter_3.png)
4. To clear the top-level filter, from the upper right corner, click **Clear Search**, as shown below.

![Consent Confirmation Page Manager interface showing search and configuration options.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/doi_message_filter_4.png)
