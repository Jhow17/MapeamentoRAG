# Organization-level access in Universal Consent

Organization-level access lets you create multiple organizations within your tenant. Each organization acts as a standalone unit that is entirely independent and isolated from the rest of the organization units.

> [!NOTE]
> **Note**
> 
> If this feature is not available in your Securiti tenant, contact your Customer Success Manager or Account Representative to confirm whether it is included in your plan.

The Universal Consent module also lets you clone the following things from one organization to another:

- Processing Purpose
- Consent Purpose
- Custom Parameters
- API Consent Sources
- Form-Based Consents
- Preference Center
- Consent Success Pages
- Processing Purpose Categories

For instance, when you clone a processing purpose from one organization to another, it makes a duplicate processing purpose with the same name and description in the other organization.

For more information on organizations, see [Managing organizations](/v1/docs/system-settings-managing-organizations).

### Cloning a processing purpose

To clone a processing purpose:

1. In Securiti, open **Universal Consent Management** and choose **Universal Consent Configurations > Processing Purposes**.
2. Go to the processing purpose you want to clone, click **Options** (three dots), and choose **Clone**.

![clone_processing_purpose_1.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-533ee174-46f7-eff9-6f63-196e3ce5ea2f.png)
3. On the popup, select the organization from the **Select Destination Org** menu where you want to clone your processing purpose and click **Clone Processing Purpose** as shown below.

![clone_processing_purpose_2.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-2a918778-7306-9740-2a31-3d3a87de233b.png)
