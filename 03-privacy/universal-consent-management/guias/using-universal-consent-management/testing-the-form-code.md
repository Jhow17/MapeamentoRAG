# Testing the form code

After you add the form consent code to the form web page, test the form to make sure it reports consent events to Securiti.

> [!NOTE]
> **Important**
> 
> You must redeploy your form consent code after making any changes in the form configuration.

1. Open the form page in your browser, fill it out with example information, and submit the form.
2. In Securiti, open **Universal Consent Management**.

![form_consent_test_code.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-7c80a825-36f8-4e2f-cc99-0aea79f665ef.png)
3. Scroll down to the **Consent Records** table and make sure that it contains an entry for the form you just submitted. If so, click the entry.
4. Near the upper right corner of the Consent Records table, click **Details** (eye icon) to open the **Identifier Details** panel as shown below.

![form_consent_test_form.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-4f02a190-344a-c76b-802e-30369147f9cb.png)
5. Inspect the information on the panel and make sure that it is complete and correct.
