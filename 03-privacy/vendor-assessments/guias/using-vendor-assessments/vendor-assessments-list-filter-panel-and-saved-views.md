# Vendor Assessments list Filter panel and Saved Views

**Scenario**

As a Data Compliance Officer supporting procurement, you're tasked with ensuring vendors complete their assessments on time. Manually tracking responses is tedious and prone to oversight. By using filters, you quickly identify vendors with incomplete assessments and send targeted follow-ups. This keeps onboarding timelines on track and ensures no vendor moves forward without completing due diligence.

> [!NOTE]
> **Important**
> 
> Before selecting a property from the Filter panel, ensure you're applying the filter while logged in to Securiti. For example, if you choose the property Awaiting Question Approval as *true*, the list refreshes to show any assessments with questions that a reviewer is yet to approve. Securiti shows the said information based on the tenant you're logged in.
> 
> If you're logged in with the credentials of, say, a support user instead, the Awaiting Question Approval filter may not return the correct assessments list. To prevent errors, we recommend accessing filters with the same account you use for answering or reviewing the assessment.

Securiti lets you apply filters to sort assessments you want. Also, you can save those filters and group them under different categories for easy access later.

Use the following procedure for filtering options:

1. On the Securiti Dashboard view, click the card for **Vendor Assessments**.
2. On the Vendor Assessments list view, in the upper left corner, click the **+** icon to open the Filter panel.
3. Under **Properties**, choose your desired property that you want to filter by and on the right side, mark the checkbox for the views you want included.

For example, select "Assessment Category > Data Maps." The page refreshes to show you information on data mapping assessments. The filter properties include:

> [!NOTE]
> **Note**
> 
> Securiti shows you operator chips as dropdown in the Filter panel.
  - Submitted for Review
  - Approved Progress
  - Assessment Category
  - Assessment ID
  - Assessment Title
  - Attachments
  - Awaiting Question Approval
  - Created By
  - Created Date
  - Custom Risk Score
  - Due date
  - Flag Owner
  - Last Modified By
  - Last Modified Date
  - Published date
  - Readiness
  - Reassessment Date
  - Respondents
  - Reviewers
  - Risk Count
  - Risk Owner
  - Stage
  - Template Version
  - Vendor

![Screenshot_2024-06-25_at_6_15_51_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-23d72bfe-8250-db47-4dde-c9054d7d57c6.png)
4. Click **Apply**

> [!NOTE]
> **Note**
> 
> If you exit without clicking Apply, Securiti notifies you that you unapplied filters.

To create and manage Saved Views:

1. On the Vendor Assessments list view, near the upper right corner, click **Save View**.
2. Securiti opens up the Save View pane. Create a group, for example, *Vendor*, and enter a name for your view. Optionally, add some description if you want.

![Screenshot_2024-06-03_at_3_44_38_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-a2b05000-2305-475a-a228-fbd5c0ab308a.png)
3. Click **Save**
4. (Optional) If you previously had a filter applied and you modified it, clicking Save View asks whether to:
  1. **Save with Changes**
  2. **Save as a New View**
  3. **Revert Changes**

![Screenshot_2024-06-03_at_3_48_45_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-0d4e16ba-2a60-fc97-dc5e-c8e31b15a1e9.png)
5. Similarly, near the upper right corner, click **Saved Views** which opens up a list showing your saved filters on the left.

![Screenshot_2024-06-03_at_3_45_10_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-f2deb41c-cba0-2bf5-9e32-6b489e9a9a2a.png)

To clear your selections, in the upper right corner, click **Clear Search**.
