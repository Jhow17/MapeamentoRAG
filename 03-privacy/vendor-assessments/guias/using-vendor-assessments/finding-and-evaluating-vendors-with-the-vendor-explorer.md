# Finding and evaluating vendors with the Vendor Explorer

The Securiti Vendor Explorer is a library of personal data processors. It includes both those that have been investigated and rated by the Securiti research team, and those you have imported as described in [Importing vendors with the Import Manager](/v1/docs/importing-vendors-with-the-import-manager) . Use this tool to locate vendors by name and by their Securiti Rating. You can also use the Vendor Explorer to quickly request that a vendor submit an assessment for you to evaluate.

> [!NOTE]
> **Note**
> 
> The vendors you have import as described in [Importing vendors with the Import Manager](/v1/docs/importing-vendors-with-the-import-manager) don't have Securiti Ratings, because they have not been investigated by the Securiti research team. On the Vendor Explorer page, their Securiti Ratings are shown as "N/A".

To view data processing vendors:

1. In Securiti, open **Vendor Assessments** and choose **Vendor Assessments > Vendor Ratings**.

Securiti shows you the Vendor Explorer page as shown below.

![A00053.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-b7abf230-f4ef-f586-f5d2-f03cffcd9fd3.png)
2. If you only want to view vendors you use, enable the **View our Vendors only** slider.

The vendors on the "our vendors" list are ones that you have interacted with, and those you have imported as described in [Importing vendors with the Import Manager](/v1/docs/importing-vendors-with-the-import-manager).

![A00054.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-cfdb57da-3166-89fd-de8c-61f288ea64e4.png)
3. Use the search box to filter the page on vendors with names containing specific strings.
4. Use the sort box to sort the vendors alphabetically or by Securiti Rating.
5. Click the tile for a vendor to view information for the vendor, including:
  - The number of assessments you have shared with them
  - The number of assessments they have shared with you

![A00055.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-daaae35c-1456-bb92-decc-554639c91f26.png)
6. To view detailed information about the vendor, click the tabs just below the header:
  - The **Ratings** tab (open by default) shows you the breakdown of their Securiti rating by category and attribute.
  - The **Security** tab shows you security information such as DNS health, TLS posture, and mobile security.
  - The **Certifications** tab shows you the security and privacy certifications held by the service.
  - The **Details** tab shows you detailed information about the organization offering the service, including their domain, privacy-related email contact, and other contact information as applicable.
7. If you want to request an assessment from the vendor, on the ratings page click **Request Assessment**. Securiti opens the Invite Vendor panel as described in [Inviting vendors to submit assessments](/v1/docs/inviting-vendors-to-submit-assessments).

A library of personal data processors maintained by Securiti that gives you a bird's eye view of the vendors present. These include vendors with a Securiti Rating and vendors you've imported with information on their performance and assessments requested.
