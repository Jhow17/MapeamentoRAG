# Using the Vendor Assessments list view

To get started, click **Vendor Assessments** on your Securiti Dashboard, and choose **Vendor Assessments > Vendor Assessments**.

- On the following page, Securiti shows you the Vendor Assessments list view.
- In the upper right corner of the page, choose to suit:

  1. Invite

![Vendor assessment interface showing options to invite a vendor and view assessments.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2025-08-28 at 12.08.57 PM.png)
  2. Import

![Import vendors list interface showing total assessments and vendor details for selection.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2025-08-28 at 12.09.31 PM.png)
  3. Add Vendor

![Creating a new vendor with organization and vendor name fields filled in.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2025-08-28 at 12.10.05 PM.png)
- Also, the page shows you options to configure filters and create saved views. See [Vendor Assessments list Filter panel and Saved Views](/v1/docs/vendor-assessments-list-filter-panel-and-saved-views) for more information.
- The list shows you the following information:

  1. Vendors list you can sort by last modified, alphabetically, etc.
  2. Once you select a vendor, corresponding tabs include:

    1. Assessment
    2. Files from Vendor
    3. Risks

In the Assessment tab, Securiti shows the following columns by default (scroll to the right to see more):

  1. ID
  2. Assessment Title
  3. Stage

The Stage column on hover reveals the following information:

    - **Stage type -** The default assessment stages such as In Progress, In Review, Canceled, etc.
    - **Stage -** The stage label you've configured in [Workflow Settings](/v1/docs/configuring-workflow-settings-custom-stages-in-assessments).
  4. Associated Workflow

The Associated Workflow column two types of workflows:

    - **Base Workflow -** Default workflow for most users.
    - **Two Step Review Workflow -** When Custom Workflow Stages is enabled.
  5. Submission %
  6. Review %
  7. Due Date
  8. Reviewers
  9. Respondents
  10. Completion Date
  11. Assessment Version

![Overview of vendor assessments, including total assessments and risk status for vendors.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2025-08-28 at 12.22.11 PM.png)
- To configure grid columns:

  1. In the right most corner, click the **Column Selector** icon.
  2. Mark or clear the checkbox for items such as Published Date, Due Date, Submission %, Review %, Version, Risk Rating, Reassessment Date, and Associated Template to suit.

Click **Apply** to update the grid.

![Overview of vendor assessments, showing total assessments and vendor risk status.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2025-08-28 at 12.26.54 PM.png)
  3. Click **Restore Defaults** to reset and return to the default view.

Also, you can use drag and drop in column configuration to reorder. For example, if you want Assessment Title to come before ID.

See [Assessments list (Grid search and Exports)](/v1/docs/assessments-list-search-and-exports) for general information on how to perform grid search and use the assessment export feature.
