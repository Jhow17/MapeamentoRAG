# Importing vendors with the Import Manager

You can quickly import your current and prospective vendors into Securiti. Doing so makes it easier to request assessments from them and monitor their performance. The vendors that you import are the ones shown when you activate the "View our Vendors only" slider on the Securiti Vendor Explorer.

> [!NOTE]
> **Note**
> 
> The vendors you import aren't given Securiti Ratings, because they have not been investigated by the Securiti research team. On the Vendor Explorer page, their Securiti Ratings are shown as "N/A".

1. In Securiti, open Vendor Assessments and choose **Vendor Assessments > Vendor Import Manager**.
2. Near the upper left corner of the All Imports list along the left edge of the page, click **+** to open the import panel.
3. On the panel, click **Download CSV Template** as shown below.

![A00059.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-1ff57a65-85a2-776f-73a3-c5a8b9125b28.png)
4. Use the template to make a .csv-formatted list of vendors.
5. Drag the .csv file into the drag&drop box, or click the **Select File to Import** link and navigate to the file.

The Import Manager imports the vendors in your file, and creates an entry for the file in the All Imports panel along the left edge of the page.

After loading your .csv file, Securiti validates the entries to make sure that the vendor names and DPO names and email addresses are at least nominally valid. Securiti then creates an entry for the .csv file in the All Imports panel at the left edge of the Import Manager.
6. On the Import Manager page, click the entry for the .csv file to view the results of the import operation and the status of each vendor as shown below.

> [!NOTE]
> **Note**
> 
> The list of vendors on the left start showing only after you have used the vendors to initiate assessments. The same applies to the vendor assessments count/number on the Vendor Assessment Dashboard.
> 
> Also, vendors only appear in Data Mapping when you have initiated assessments with them.

![A00060.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-5260b937-71b4-0c7b-3dff-8450c17887c3.png)

After importing vendors, you can edit them if you find any errors or omissions. To edit a vendor on the Third-Parties list:

1. At the right edge of the card for a vendor, click **Options > Edit**.
2. Make your changes on the Edit Vendor Information panel, then click **Save**.

A tool you can use in Securiti to quickly import a vendor. It enables you to request assessments from the vendor and monitor their performance. The vendors you import, if they don't exist in Securiti's curated list of vendors, will not have Securiti Ratings because they have not been investigated by the Securiti Research team.
