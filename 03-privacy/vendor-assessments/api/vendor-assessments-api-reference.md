# Vendor Assessments API reference

The Vendor Assessments API documentation lets you manage vendor assessment workflows, distribute questionnaires to third-party vendors and guest users, track response status, and export completed assessments with custom fields.

This API documentation includes operations such as:

- Launch vendor assessments from published templates
- Assign reviewers and respondents to vendor assessments
- Distribute questionnaires to third-party vendors and guest users
- Track submission and review status, and export completed assessments

Use the Vendor Assessments [REST API documentation](https://securiti-doc-router.securiti.ai/modules/vendor-assessments/apidocs/index.html) to explore and test Vendor Assessments APIs, review HTTP endpoints, JSON request and response formats, query parameters, API schemas, authentication methods, and sample API requests, and access the Postman collection for vendor assessment operations.
