# Create risks using risk register

Securiti’s Risk Register lets you create risks from the list page.

## Create risk

To create a risk:

1. Near the upper right corner, click **+ Add New Risk**.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2026-03-31 at 12.51.08 PM.png)
2. On the “Add New Risk” page, use the following fields to configure risk:
  1. “Risk Level” - currently, the Risk Matrix risk is shown with Likelihood and Severity on y and x axes, respectively. Click a box to reveal the pre-configured risk value and set the value to suit. Light colored boxes carry less risk value when compared to boxes in dark colors to illustrate higher scores.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2026-03-31 at 11.09.17 AM.png)
  2. “Risk Description” - enter a description around the risk you’re trying to create.
  3. “Recommendation” - enter comments related to any recommendation.
  4. “Set Risk Owner(s)” - you must assign a risk owner(s) from the list. You can choose a user on the assessment or invite a guest user.
  5. “Set Risk Reviewer(s)” - select reviewers if you want.
  6. “Set Deadline” \ “Set Workflow” - set a deadline and choose any existing workflow you have.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2026-03-31 at 11.10.10 AM.png)
  7. “Assign Tags” - select and apply any assessment tags you want. For more information, see [here](/latest/docs/managing-assessment-tags).

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2026-03-31 at 11.28.18 AM.png)
3. Click **Continue to Link Objects**.

On the Add New Risk page, Securiti shows you all existing objects in your organization.

### Add risk to object

To link a risk:

1. From the list of objects, for example, select “Assessments” and mark the checkbox next to the assessment you want to link.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2026-03-31 at 11.31.40 AM(1).png)
2. Click **Add Risk**, or if you have multiple selections, click **Clear Selections** to start over.

For more information, see [Linking objects](/latest/docs/enriching-existing-data-mapping-objects-with-assessments#link-assessment).

Proceed to [Navigating risk details](/latest/docs/navigating-the-risk-details-page).
