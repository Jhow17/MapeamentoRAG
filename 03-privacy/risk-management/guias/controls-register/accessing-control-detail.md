# Accessing Control Detail

After you add a control, Securiti shows you the details page. Clicking a control in the register list view also brings up its details.

The Control Detail page has a persistent header showing the control's name and description, followed by a row of key fields that stay visible no matter which tab you're viewing: Control ID, Severity Effectiveness, Likelihood Effectiveness, Tags, Linked Framework, Deadline, Expiry Date, Owners, and Reviewers.

Below the header, four tabs organize the control's information:

- Basic Information
- Linked Risks
- Associated Evidences
- Audit Logs

### Top action buttons

- Edit - edit the control's fields. Click **Save** when done.
- Link Risks - open the Linked Object window to link one or more risks to this control.
- Status dropdown - change the control's status.
- Comments - open the comments panel for this control.
- Options (three vertical dots) - click **Delete Control** to delete the control.

### Basic Information

Shows the control's Name, Description, Linked Compliance Control, Owners, Reviewers, Organization, Created By, Created On, Expiry Date, and Deadline.

### Linked Risks

Shows the risks this control is linked to. Use the search bar to search by Risk ID, Description, or Recommendation. The table shows Risk ID, Risk Description, Risk Status, Inherent Risk Level, Residual Risk Level, and Risk Owner for each linked risk.

### Associated Evidences

Shows the control's supporting evidence across three sub-tabs:

- Attachments
- Links
- Comment Attachments.

Click **+ Add New** to add evidence.

### Audit Logs

Shows a history of changes made to the control, such as Control Created, Owner Added, Compliance Frameworks Added, and Tags Added. Each entry shows who made the change, what changed, and when.
