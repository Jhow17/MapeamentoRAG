# Risk API reference

The Risk Management API documentation lets you create and manage risks using the Risk Register, link risks to data mapping objects and assessments, configure inherent risk details, and retrieve residual risk levels and scores after remediation workflows.

This API documentation includes operations such as:

- Create, import, and export risks via the Risk Register
- Link risks to object types including Assessments, Assets, Processes, Vendors, and Institutions
- Configure inherent risk, risk owner, reviewer, and tags
- Retrieve residual risk levels and scores after remediation approval

Use the Risk Management [REST API documentation](https://securiti-doc-router.securiti.ai/modules/risk-register/apidocs/index.html) to explore and test Risk Management APIs, review HTTP endpoints, JSON request and response formats, query parameters, API schemas, authentication methods, and sample API requests, and access the Postman collection for risk management operations.
