# Using the operating system features

Based on the platform of your mobile application, Securiti lets you utilize the following operating system (OS) level features to enhance user privacy and consent management:

- [Google Advertising ID Framework](/v1/docs/using-the-google-advertising-id-framework): This feature lets applications on Android access a unique identifier for advertising, facilitating targeted advertising while enabling data subjects to manage their privacy preferences.
- [Apple's App Tracking Transparency Framework](/v1/docs/using-the-apples-app-tracking-transparency-framework): This feature prompts data subjects on iOS devices to grant or deny permission for applications to track their activities across other organizations' applications and websites, promoting transparency and data subject control over personal data.
