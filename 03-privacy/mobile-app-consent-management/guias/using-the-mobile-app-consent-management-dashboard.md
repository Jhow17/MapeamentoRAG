# Using the Mobile App Consent Management Dashboard

With Securiti's Mobile App Consent Management module, you can navigate app consent with precision right from your dashboard. You can seamlessly track and manage consent of your data subjects, ensuring compliance with global privacy laws.

The Mobile App Consent Dashboard shows your mobile app consent posture at a glance. To open the dashboard, in Securiti, open Cookie Consent Management. The dashboard opens by default.

Using the Mobile App Consent Dashboard, you can:

- Construct search queries to filter out consent data.
- Save the search queries as **Saved Views** for future use.
- Download consent records from the dasboard in a report.

> [!NOTE]
> **Note**
> 
> To prevent multiple report requests and reduce system strain, the **Download Report** button on the Mobile App Consent Dashboard disables after a single click and only re-enables when you change the filters. Additionally, Securiti enforces a limit of **5 report requests per hour** for each Securiti user role.
- Visualize the consent statistics using the metric tiles:

| Metric | Description |
| --- | --- |
| Consent Records | Displays the total number of consent records that exist in the dashboard. |
| Granted | Displays the total number of **granted** consent records from your data subjects. |
| Declined | Displays the total number of **declined** consent records from your data subjects. |
| Implicit | Displays the total number of implicit consent records from your data subjects. |
| Geolocation | Displays the number of geolocations from which your data subjects have given or declined consent. |
