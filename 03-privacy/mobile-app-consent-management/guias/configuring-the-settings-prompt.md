# Configuring the Settings Prompt

**Scenario**

As a Data Privacy Officer, you need to let mobile app users to update previously denied Permissions for the app. For instance, a user who earlier denied location access may later want to enable it to use certain app features such as navigation or maps. Without in-app guidance, users often struggle to locate the correct device settings. With Securiti’s Settings Prompt, mobile app users are redirected directly to their device settings to re-enable access. This empowers mobile app users with greater control over their privacy while helping the app function as intended.

Securiti's Settings Prompt functionality enhances data subject engagement by requesting necessary permissions that were previously denied. If a data subject wishes to update their preferences for a previously denied permission, the Settings Prompt guides them back to the device settings, where they can adjust their preferences. By directing data subjects back to device settings, this functionality enhances the user experience and empowers them to control their device permissions, ensuring that the application operates as intended.

To enable Settings Prompt for your mobile application:

1. In Securiti, open Mobile App Consent Management and choose **Mobile Consent > Mobile Apps**.
2. On the Mobile Apps page, click the mobile application.
3. From the left sidebar, navigate to the **ADD-ON FEATURES** section, and select the **Settings Prompt**.
4. Enable the **Enable Settings Prompt** toggle, as shown below.

5. To customize the Settings Prompt:

  1. In **Prompt Heading** text field, add an appropriate heading.
  2. In **Prompt Message** text field, add a messags that shows to data subjects on the Settings Prompt.
  3. In **Settings Button Text** text field, add appropriate button name.

> [!NOTE]

6. From the **Applicable Permissions** section, enable the permissions for which you want to show the Settings Prompt to data subjects, as shown below. These permissions were previously declined by the data subject.
