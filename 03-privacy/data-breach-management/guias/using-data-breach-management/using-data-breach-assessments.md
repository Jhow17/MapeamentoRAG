# Using data breach assessments

**Scenario**

As a Data Privacy Officer, you need to assess whether a reported incident qualifies as a data breach and decide if regulators must be notified. Without guidance, this process is slow and uncertain. Using Securiti’s jurisdiction-specific assessment templates, you can quickly gather key incident details, evaluate risks, and determine notification requirements. This ensures timely, consistent decisions and reduces compliance risks.

## Overview

Securiti offers a series of jurisdiction-specific assessment templates in the template library. These templates help incident owners determine if an incident qualifies as a data breach and assess the need for notification by evaluating potential risks. You can use assessments to quickly collect all available information about a reported incident.

> [!NOTE]
> **Note**
> 
> To initiate an assessment in the Data Breach module, you must have a subscription to Securiti’s Assessment Automation module.

### Initiating an assessment for a data breach incident

You can initiate one or more assessments for a data breach incident.

1. In Securiti, open **Data Breach Management**.
2. On the workbench page, click an incident for which you are a co-owner.
3. Near the upper right corner of the **Data Breach Workbench**, click **Initiate Assessment** to start a new assessment.

![Assessments_Tab.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-b8e3a880-1c72-9791-532a-3ad93bbf2fec.png)
4. Use the Initiate Assessment popup to choose the assessment category, template, and owner as shown below.

![data_breach_assessment_2.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-2354c075-1a2b-5217-7ac0-9375e52de172.png)

> [!TIP]
> **Tip**
> 
> To assess the risk severity of a data breach for GDPR, for the category choose **GDPR**, and for the template choose **Data Breach Risk Severity Assessment**. After conducting and publishing this assessment, click **Show Recommendation** to view recommendations for notification and mitigation.
> 
> ![DBM_assessment_recommendation.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-458c3252-084b-01f6-f322-d6f7ebf2fc7b.png)
5. Click the new assessment to open it in the Securiti Assessments module and assign assessment co-owners, question owners, and other typical settings for an assessment.
6. Conduct the assessment.

For more information, see the [Assessment Automation](/latest/docs/getting-started-with-assessment-automation) documentation.

> [!NOTE]
> **Note**
> 
> 1. In case an incident is processed using enhanced breach analysis, near the upper right corner of the **Data Breach Workbench**, click **Assessments** to start a new assessment.
> 
> ![Screenshot_2024-01-17_at_8_44_01_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-5dc386c0-11ca-81e7-f0eb-f567decffa37.png)
> 2. On the Assessments page, at the upper right corner click **Initiate Assessment**.

### Associating an existing assessment with a data breach incident

You can associate one or more existing assessments with data breach incidents.

You must be a co-owner of the assessment you want to associate with the incident. The assessment can only be associated with a single incident, and cannot be associated with any data catalog elements.

1. If you have not already done so, in Securiti, open Assessment Automation and initiate an assessment.
2. Open Data Breach Management, and on the workbench page, click an incident for which you are a co-owner.
3. Near the upper right corner of the page, click **Initiate Assessment** to start a new assessment.

![Assessments_Tab.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-b8e3a880-1c72-9791-532a-3ad93bbf2fec.png)
4. On the Initiate Assessment popup, for Select Option choose **Associate Assessment**. Then use the Assessment Category and Select Assessment menus to locate the assessment you want to associate with the incident as shown below.

![Screenshot_2024-01-29_at_1_33_41_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-46158822-a958-f939-39f6-0203dadce5df.png)
5. When you are done, click **Associate**.

Securiti associates the assessment with the incident and adds it to the table on the Assessments tab.

> [!NOTE]
> **Note**
> 
> 1. In case an incident is processed using enhanced breach analysis, near the upper right corner of the Data Breach Workbench, click **Assessments** to associate an existing assessment.
> 
> ![Screenshot_2024-01-17_at_8_44_01_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-5dc386c0-11ca-81e7-f0eb-f567decffa37.png)
> 2. On the Assessments page, at the upper right corner click **Associate Assessment**.

### Viewing assessments for a data breach incident

1. In Securiti, open **Data Breach Management**.
2. On the workbench page, click an incident for which you are a co-owner, then click the new **Assessment** tab as shown below.

![assessment_initiation.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-f0d6c9ff-b00c-c690-71b0-b5c785642a44.png)
3. Use the Assessments tab to view and open assessments as shown below.

![assessment.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-ace700d4-110e-7c8f-bb6a-b01eee28d30d.png)

To open an assessment, click on its entry on the tab.
