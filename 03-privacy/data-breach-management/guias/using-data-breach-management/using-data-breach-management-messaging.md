# Using Data Breach Management messaging

Data Breach Management has a communication side panel that lets incident owners and data breach reporters communicate with each other.

In Securiti, open **Data Breach Management** , and click an incident for which you are a co-owner or the reporter. Near the upper right corner of the page, click the new **Messages** icon as shown below. The messaging side panel opens from the right.

You can only read or write messages if you are the breach reporter or a co-owner of the incident.

To communicate with the breach reporter and all incident co-owners:

1. If you have not already done so, open the incident in the data breach workbench.
2. Near the upper right corner of the incident header, click the **Messages** icon as shown below.

![messsage_panel.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-962b3db7-d9e0-5d76-b54f-c06b50de9c7f.png)

> [!NOTE]
> **Note**
> 
> If the messaging icon is absent, it is probably because you are not the reporter or a co-owner of the incident.
3. Use the messages panel to view or send messages to the reporter and incident co-owners.

![send_messages_.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-227ce5df-bbb3-e65e-eebe-a0b105ee6106.png)

### Export messages with the incident report

You can extract all messages sent and received by the incident owner and the data breach reporter.

To export messages with the respective incident report:

1. In Securiti open **Data Breach Management** module, and on the **Reported Incidents** dashboard, go to the incident whose report you want to export, click **Options** (three dots), and select **Export**.
2. On the **Export Incident** popup, select the report **Format** and the suitable **Language** from the menu.
3. Enable the **Include messages** toggle to extract messages with the incident report and then click **Export**.

Securiti sends you an email that contains a link to the incident report.
4. Click the link you receive in the email to download the incident report in a zip folder.

The message file in the downloaded zip folder shows the name of the sender who sent the message.
