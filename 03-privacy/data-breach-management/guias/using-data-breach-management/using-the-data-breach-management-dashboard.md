# Using the Data Breach Management Dashboard

The Data Breach Management Dashboard shows your data breach posture at a glance. It is made up of several widgets. Each widget depicts specific statistics related to data breach rates.

The **Incidents Due** widget has a calendar that shows all approaching deadlines for breach incidents. The small blue dots in the figure below show the upcoming deadlines for reported incidents.

![Calender_breach.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-68c228d5-be3f-4c62-7a25-1a066927cce8.png)

This widget below shows the categorization of reported incidents by their type.

![incident_type_breach.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-6bfaf74f-6b56-9ed1-93e3-bc340381461b.png)

The **Incident Closure Trend** widget shows the ratio of open to close incidents and a trendline indicating the status of reported incidents in the last 30 days.

![3rd_widget.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-8605d40a-395c-96dd-afd4-97ee42d9e2b7.png)

The **Incidents by Region** widget illustrates the distribution of reported breaches across different regions. By simply hovering over each region, you can easily access the specific number of incidents that were reported in that particular area.

![4rth_widget.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-523822d6-e9b3-6d74-71b6-b74fd35fbc4f.png)

Below the widgets is a table of current and past breach incidents.

![incident_list.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-fee7023c-9f04-3ba6-6406-55682a7c2686.png)

On the list of incidents, click any entry to open it for processing in the Data Breach Workbench. See [Processing a data breach report](/v1/docs/processing-a-data-breach-report) for more information.

To filter incidents on the workbench page, click the Filters icon near the upper right corner of the page and use the tools on the Filters panel as shown below.

![filters_.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-f4eaa9f2-c52a-aa87-e62f-5bbc5f430813.png)
