# Moving a data breach incident between organizations

You can move data breach incidents that you own between organizations you belong to.

1. At the right end of the tile for the incident, choose **Options > Edit Org**.

If the Edit Org option is not available, it is probably because you are not a co-owner of the incident.
2. On the Edit Org popup, choose the destination org and the data asset with which to associate the incident, then click **Confirm**.
