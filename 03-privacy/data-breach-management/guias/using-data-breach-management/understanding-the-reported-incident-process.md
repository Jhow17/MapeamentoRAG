# Understanding the reported incident process

This topic describes the overall process that Securiti uses to respond to a reported incident.

- The process usually starts with the reporter submitting a breach incident. Securiti offers you two ways to report an incident. Securiti admins and DPOs can report incidents directly from Data Breach Dashboard. Additionally, Securiti also publishes a breach intake form on your self-service portal that anyone with an email address in your company domain can use to report an incident. For more information on reporting an incident, see [Reporting a data breach](/v1/docs/reporting-a-data-breach).
- In either case, the breach intake form collects basic information about the breach, its timeline, and contacts that the incident manager can use to investigate and manage it.
- Once an incident is reported, Securiti automatically assigns it to the DPOs of the corresponding tenant. DPOs can further delegate it to other Securiti users. In case, no DPOs are available, the incident is assigned to the admins of the tenant. See [Managing data breach incident ownership](/v1/docs/managing-data-breach-incident-ownership) for more information.
- On the list of incidents on the Data Breach Dashboard, click any entry to open it for processing in the Data Breach Workbench. Securiti provides you with two ways to process a reported incident:
  - [Manually Processing the Breach Incident](/v1/docs/processing-a-data-breach-report)
  - [Using an enhanced breach analysis](/v1/docs/using-the-enhanced-breach-impact-analysis-dashboard)
- Incident owners can also coordinate with the breach reporter using the message panel from within the Data Breach Workbench. For more information, see [Using Data Breach Management messaging](/v1/docs/using-data-breach-management-messaging)
- In **Data Breach Workbench**, you can process reported incidents, progressing through various stages to comply with notification regulations and reduce costs and remediation time.
- You can also initiate an assessment to gather details about a reported incident to assess whether it qualifies as a breach or not. For more information, see [Using data breach assessments](/v1/docs/using-data-breach-assessments)
- Once completed, export the incident details report in PDF or JSON format. For more information, see [Exporting data breach incident details](/v1/docs/exporting-data-breach-incident-details).

> [!NOTE]
> **Note**
> 
> The functionality to export incident details reports is only available for manually processed breach incidents.
