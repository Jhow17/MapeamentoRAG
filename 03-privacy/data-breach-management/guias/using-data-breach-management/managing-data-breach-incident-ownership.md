# Managing data breach incident ownership

When a member of your organization submits a data breach incident, Securiti assigns as incident owners all Securiti users with DPO role. If there are no DPOs, Securiti assigns incidents to all admins. If the breach report is submitted by a Securiti admin, that admin is also a co-owner of the incident. If you are a Securiti admin, you can remove any of these default owners and add any Securiti Super Admin or Organization Admin as an owner.

1. In Securiti, open the data breach incident.
2. On the page for the data breach incident, near the upper right corner next to the row of owner avatars, click **Change Owner** (pencil icon).
3. Use the tools on the Owners popup to remove existing owners or add new ones as shown below. You can search the breach incident owners by their first name, last name or full name.
