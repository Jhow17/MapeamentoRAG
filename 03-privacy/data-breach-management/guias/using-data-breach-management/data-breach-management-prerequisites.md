# Data Breach Management Prerequisites

Observe the following prerequisites when you use the Data Breach Management module:

- You must deploy pods to connect your on-premises or private data systems. For more information, see [pods documentation](/v1/docs/securiti-pods-and-elastic-pods).
- You must configure connectors for the data systems that you want to include in data breach processing. For more information, see [configuring connectors for data systems](/v1/docs/configuring-connectors-for-monitored-data-systems).
- For automated breach analysis, you must have a subscription for the Sensitive Data Intelligence module to perform discovery scans on monitored data systems affected as a result of a breach. For more information, see [Discovery scans for unstructured data systems](/v1/docs/discovery-scans).
- To initiate data breach severity assessments to collect more information on reported incidents, you must have a subscription for the Assessment Automation module. For more information on assessments, see [Using the Assessment Automation dashboard](/v1/docs/using-the-assessment-automation-dashboard).
- If you want someone outside of your organization to be able to report an incident, you must configure the self-service portal. You can publish the self-service portal’s link on your website or share it via email with users who want to report a breach incident. For more information, see [Configuring Securiti Self-Service Portal](/v1/docs/configuring-the-securiti-self-service-portal).
