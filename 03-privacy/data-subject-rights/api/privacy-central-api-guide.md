# Privacy Central API guide

Privacy Central is a unified portal that provides data subjects with a seamless way of raising and tracking Data subject Rights requests.

These topics describe how enterprises use the Securiti Privacy Central REST API. It is intended mainly for developers and other engineering personnel.
