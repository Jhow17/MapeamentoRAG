# Data Subject Rights API reference

The Data Subject Rights API documentation lets you submit and manage DSR requests, including internal DSR requests and external ones submitted by data subjects through published forms, process subtasks, manage DSR forms, handle appeal flows, and integrate your preferred platforms with Securiti's DSR workflow.

This API documentation includes operations such as:

- Create, update, and publish DSR forms
- Submit internal and external DSR requests
- Create, list, update, and delete DSR subtasks and manage their owners
- Approve or reject DSR requests with custom approval or rejection reasons and notification templates
- Publish DSR reports with custom notification templates
- Manage appeal flows including approving and declining data subject appeals
- Manage DSR configurations including retention policies, request types, and email notification templates
- Create and manage task templates with subtask templates, assignees, deadlines, and data system associations

Use the Data Subject Rights [**REST API documentation**](https://securiti-doc-router.securiti.ai/modules/data-subject-rights/apidocs/index.html) to explore and test DSR APIs, review HTTP endpoints, JSON request and response formats, query parameters, API schemas, authentication methods, and sample API requests, and access the Postman collection for supported DSR operations.
