# Deleting DSR requests

You can delete the following DSR requests:

- Those you manually opened using an internal DSR request form.

> [!NOTE]
> **Important**
> 
> Only delete manually-opened DSR requests that you are certain are not legitimate.
- Those submitted by data subjects through an external DSR request form, but only after you have completed and published the reports.

1. On the [DSR dashboard](/v1/docs/using-the-data-subject-rights-dashboard), locate the card for the DSR request you want to delete.
2. At the right end of the card, choose **Options** (three dots) **> Delete**.

Securiti opens a confirmation box.
3. Click **Yes, Continue** to confirm and delete the DSR request.

Securiti displays a banner showing the results of the deletion.

> [!NOTE]
> **Note**
> 
> Only the DSR owner can delete a DSR request.
