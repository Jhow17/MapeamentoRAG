# Understanding the DSR request center

The DSR request center is where data subjects log in to monitor the status of their requests, and to get the final reports for Access and Port requests. The request center also lets them exchange messages with the owners of their DSR requests in Securiti.

After a data subject validates their identity as described in [How Securiti verifies data subject identity](/v1/docs/how-securiti-verifies-data-subject-identity), Securiti creates an account for them on the request center, and emails them an invitation to log in as shown below.

![Portal_email_invitation_to_login.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-0e33cb3f-7bea-ad10-ee67-af333c5b5dc1.png)

The data subject logs in as shown below. If they never had a password, or if they had one from an earlier DSR request and forgot it, they can click Forgot Password to set a new password.

![Portal_login_page.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-8e6f30e9-b9f3-9746-e65d-5fd56db55bea.png)

Once the data subject logs in, they see a list of the organizations to which they have submitted DSR requests through Securiti, as shown below.

![portal_list_of_companies.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-4fe63939-8181-48d7-bbe2-c7032e4a6b6f.png)

When the data subject clicks Details for an organization, they see a list of all their active and completed requests. If there are unread messages for any of the requests, they are highlighted as shown below.

![portal_list_of_companies_with_unread_messages.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-93e76f22-81f9-5d9c-e90e-944ca37af266.png)

Each request has an option menu that lets them view a list of related messages as shown below. If the report has been published, they can also view or delete it.

For each message, they can immediately reply, and even add attachments, as shown below.

![portal_message_and_reply.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-c67cdf9e-0a22-dc08-d212-1c5be1d4cb9c.png)

See [Communicating with DSR and subtask owners](/v1/docs/communicating-with-dsr-and-subtask-owners) for more information about using Securiti messaging features to communicate with data subjects.
