# Duplicating DSR requests

You can create duplicate copies of DSR requests. You would most likely use this feature in the case that you have already closed a DSR request for which an additional response is required.

1. In the [DSR dashboard](/v1/docs/using-the-data-subject-rights-dashboard), locate the card for the DSR request.
2. In the Actions column on the card, choose **Options** (three dots) **> Duplicate**.

Securiti opens the Create DSR request box as described in [Opening DSR requests on behalf of data subjects](/v1/docs/opening-dsr-requests-on-behalf-of-data-subjects), with the first and last name of the Data Subject filled in but all other fields blank.
3. Choose the request type for the DSR request.
4. Fill in at least the email address box, and other Data Subject information as applicable.
5. Near the bottom of the panel, click **Create DSR Request**.
