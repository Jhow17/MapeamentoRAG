# Communicating with DSR and subtask owners

The DSR module messaging features let owners of DSR requests and subtasks communicate easily.

There are two levels of messages; DSR request messages and Subtask messages:

- DSR request messages let the DSR request owner broadcast messages about the request to all Subtask owners.
- Subtask messages let Subtask owners communicate with the owners of other subtasks of the same DSR request.

Securiti has two communication features to support DSR request and Subtask messages:

- The [chatroom tab](/v1/docs/using-the-chatroom-tab) for a DSR request shows all DSR request and Subtask messages in cascaded view with DSR request messages at the top, followed by Subtask messages.
- The [messages panel](/v1/docs/using-the-dsr-request-and-subtask-messaging-side-panels) for the DSR request, and the messages panel for each Subtask, show just the messages for that DSR request or Subtask.

Securiti also has a separate set of features that let DSR request owners communicate with the data subjects who submitted the requests. See [Communicating with data subjects](/v1/docs/communicating-with-data-subjects).

### Communicating with DSR owners or subtask owners via Messages & Notifications panel

You can also respond to your messages via the **Messages & Notifications** panel directly from the Securiti dashboard. The **Messages & Notifications** panel also lets you view DSR-related notifications. You can use the search box from the upper right corner to search for the exact message(s).

> [!NOTE]
> **Note**
> 
> Securiti does not let you initiate a conversation over DSR requests with the co-owners from this **Messages & Notifications** panel. You can only converse back and forth with the co-owner(s) of your DSR requests on which you have already initiated conversations.

To communicate with your co-owners using this panel:

1. In Securiti, near the bottom of the left navigation bar, click the **Messages & Notifications** (message) icon.
2. From the left messages navigation bar, click the title of your DSR requests in which you are already engaged in communication with co-owners
3. Type your reply and if you want, also tag your co-owner in the message as shown below.
