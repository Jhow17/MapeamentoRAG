# Searching and filtering Request Types

On the Request Types page, you can use the search bar to search for a particular request type by entering its label, value or description.

You can select various filter options to specify the criteria by which you want to filter the request types list . Clicking any of the filter options opens its respective menu, displaying values that you can choose from. Once the filter is applied, the Request types list updates to display only the requests that meet the specified criteria. The available filters are as follows:

- **Category:** Filter request types by category, distinguishing between “System” and “Custom” types.
- **Automation:** Filter request types by their DSR Automation status, selecting from Enabled or Disabled.
- **Task per Data System**: Filter request types by their task creation status, choosing between Enabled and Disabled.
- **Created:** Narrow down custom request types by their creation date, pinpointing specific timeframes. System request types have a blank (-) creation date field, so they cannot be included in the

#### Customize Request Types list view

You can customize the request types table view according to your preferences. You can select the columns you want to see and rearrange them by dragging and dropping.

1. On the **Request Types** page, near the upper right side of the table, click **Column Selector** (window icon).
2. Select columns from the list that you want to display in the table and click **Apply**.

![Screenshot_2024-12-10_at_2_17_55_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-1846436e-7540-4f85-9d0a-2b3ef171b44e.png)

Click **Restore Default** option to revert the DSR requests table to its default view whenever needed.

#### Pagination on request types list

At the bottom left corner, use the **Showing [number] per page** menu to select your desired display quantity. Choose from the available options to showcase 10, 25, 50, or 100 request types in the list at a time.
