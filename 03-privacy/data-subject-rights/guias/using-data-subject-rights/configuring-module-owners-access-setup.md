# Configuring module owners access setup

Module Owner Access Setup gives you flexibility to restrict module owners to view only:

- The DSR requests assigned to them.
- The DSR requests for which they are subtask owners.

This ensures that module owners can only access the data relevant to their responsibilities.

> [!NOTE]
> Note
> 
> Securiti lets only super admins in your Securiti tenant restrict module owner view.

To access the Module Owner Access Setup:

1. In the **Data Subject Rights** module, choose **Settings > DSR Settings**.
2. Scroll to the DSR Module Owner Access Setup section, Click **Edit** (pencil icon) on the right side to open the access setup in edit mode as shown below.

![Module Owner Access Setup details explaining DSR visibility restrictions for owners.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2026-08-12 at 12.44.08 PM.png)
3. Mark the checkbox and click **Save** to limit module owners to only see requests assigned to them.

![Settings for Data Subject Rights, including access limitations for module owners.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2026-08-12 at 12.45.25 PM.png)

> [!NOTE]
> **Note**
> 
> If the module owner is only the subtask owner of a DSR request, they cannot add themselves or others as a DSR owner in the DSR Workbench. Additionally, under this setting, module owners cannot migrate DSR requests from one organization to another.
