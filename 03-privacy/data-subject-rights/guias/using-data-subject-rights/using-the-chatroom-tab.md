# Using the chatroom tab

Use the Chatroom tab to view messages for a DSR request and its subtasks on a cascaded chatroom-style page:

1. If you haven’t already done so, open the DSR request in the [DSR workspace](/v1/docs/opening-dsr-requests-in-the-dsr-workbench-1).
2. In the DSR workbench click the **Chatroom** tab.

The Chatroom tab shows messages for the DSR request, followed by the messages for each subtask for which you have access, as shown below. What you see on the tab depends on your Securiti role and your DSR request ownership role:

- If you own the DSR request or any of its subtasks, you see the DSR request messages and all subtask messages.
- If you are a Securiti Super Admin or DPO but don’t own the DSR request or any subtask, you can only see the DSR request messages.
- If you are a Securiti user but don’t own the DSR request or any of its subtasks, the Chatroom tab is blank.

![Screenshot_2025-03-24_at_3_28_47_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-a37a16bf-6d1d-bddf-a377-4abbdd854441.png)

For the DSR request and each subtask, the tab shows the messages along with information about who sent them, and when. The tab also shows you a member list, composed of the DSR request owner and all subtask owners.

To add a message to the DSR request or any subtask, simply enter your message in the text box near the bottom of the group of messages, then click **Send**. Your message can be seen by the owners of all DSR request subtasks, as well as by the DSR request owner.
