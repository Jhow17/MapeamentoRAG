# Using the DSR requests list

Use the DSR requests list along the left panel of the [DSR workbench](/v1/docs/opening-dsr-requests-in-the-dsr-workbench-1) to quickly switch DSR requests for processing while you are already in the workbench. By default, the list shows all DSR requests from the dashboard. You can also carry forward filter results from the DSR dashboard to the workbench and navigate through all DSR requests in the Workbench. Applying a filter on the dashboard and opening a DSR request in the workbench displays the **Search Results** count based on the applied filter.

In the **DSR Workbench**, you have an option to use navigation arrows to move through your requests. These arrows allow you to easily switch between previous and next requests.

> [!NOTE]
> **Note**
> 
> If the filter fetches zero results on the **DSR Dashboard**, Securiti sets "All DSR '' as the default option for the sort menu in the DSR Workbench.

You can sort the list using the tools at its top.

- **All DSRs**: You can sort by DSR ID in descending order.
- **Ending Soon**: You can sort by deadline.
- **Activity**: You can sort by the latest modified order.
- **Date Added**: You can sort by the created date.
- **Search Results**: You can sort by deadline.

> [!NOTE]
> **Important**
> 
> When you carry filtered results from the DSR Dashboard to the Workbench, Securiti retains the original search result count. For instance, if you filter and carry three requests from the DSR Dashboard to the Workbench, the list on the left side indicates search results as three. Should you subsequently open a new request from a notification in the **Messaging & Notification panel** or an email, Securiti continues to display the initial count of three, despite the addition of a fourth request to the list.
> 
> ![Screenshot_2025-08-05_at_11_19_02_AM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-caf08cf9-9a91-2fcd-a91a-65030654c167.png)

If you don’t need the DSR request list, you can collapse it to conserve screen area by clicking **Expand Sidebar** at its upper left corner.

You can also manually open new DSR requests from within the DSR workbench by clicking **Create DSR** near the upper right corner of the page. For more information, see [Opening DSR requests on behalf of data subjects](/v1/docs/opening-dsr-requests-on-behalf-of-data-subjects).
