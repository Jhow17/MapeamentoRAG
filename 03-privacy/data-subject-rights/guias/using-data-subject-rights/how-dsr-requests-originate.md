# How DSR requests originate

DSR requests come into the Securiti system through any of these paths:

- Data subjects create DSR requests using the customizable Securiti DSR forms that you create and publish through the Securiti solution, and submit them through your website. For each such request, Securiti requires the subject to verify their email address. Each verified request creates an account for the requester on the Data Subject Portal. For more information, see [Creating and publishing DSR request forms](/v1/docs/creating-and-publishing-dsr-request-forms).
- Securiti users with admin or DPO profiles can manually create DSR requests in response to requests submitted verbally or in writing. For more information, see [Opening DSR requests on behalf of data subjects](/v1/docs/opening-dsr-requests-on-behalf-of-data-subjects).
- Data subjects create Non-digital DSRs using primary identifiers other than an email address, for instance their Brazil CPF. The Data Subject uses a special DSR form to submit a DSR request, perhaps from an in-store kiosk, and later return to the kiosk to view or print their report. For more information, see [Accepting non-digital DSR requests](/v1/docs/accepting-non-digital-dsr-requests).

A non-digital DSR is when people, who either don't have or don't want to use email, ask for their information or make requests. Securiti can handle these requests and even provide reports in a physical (non-digital) format for those who prefer it.
