# Using the DSR request and subtask messaging side panels

You can use messaging side panels to communicate with your colleagues who are working on parts of the same DSR request.

You can only read or write messages if you are the owner of the Subtask or the owner of the DSR request.

> [!NOTE]
> **Note**
> 
> In addition to the procedure described here, you can also use the chatroom tab as described in [Using the chatroom tab](/v1/docs/using-the-chatroom-tab).

To communicate with the DSR request owner and the owners of all subtasks regarding the DSR request;

1. If you haven’t already done so, open the DSR request in the DSR workbench.
2. From the top row of options, click **Messages** as shown below.

![DSR_request_messages.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-4f4a0fe6-e8b9-922f-75fc-d2a277ade9a0.png)
3. On the side panel, click the **Messages** tab
4. Use the messages panel to view or send messages to Securiti users working on the DSR.

To communicate with the owners of other subtasks of the same DSR request:

1. If you haven’t already done so, open the DSR request in the DSR workspace.
2. Click the **Worklist** tab and then click one of the DSR request subtasks to open it in the Subtask panel.
3. From the Subtask action panel, click **Subtask Messages** as shown below, to communicate with the owners of other subtasks of the same DSR request.

![DSR_subtask_messages.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-ecd9867f-a435-8e28-1258-909180548cf0.png)
4. Use the messages panel to view or send messages to Securiti users working on the DSR request Subtask.
