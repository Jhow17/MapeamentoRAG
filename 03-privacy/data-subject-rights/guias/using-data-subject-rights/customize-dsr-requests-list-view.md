# Customize DSR Requests list view

You can customize the DSR requests table view according to your preferences. You can select the columns you want to see and rearrange them by dragging and dropping.

1. On the **DSR Dashboard**, near the upper right side of the **DSR Requests** table, click **Column Selector** (window icon).
2. Select columns from the list that you want to display in the table and click **Apply**.

![Screenshot_2023-10-04_at_8_37_12_AM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-c1f042b0-8c3c-8e71-85b3-5d899d876153.png)

> [!NOTE]
> **Note**
> 
> Click **Restore Default** option to revert the DSR requests table to its default view whenever needed.
