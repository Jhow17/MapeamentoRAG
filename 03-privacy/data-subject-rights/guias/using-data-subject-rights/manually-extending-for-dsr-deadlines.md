# Manually extending for DSR deadlines

You can manually extend the DSR request or appeal deadline from the DSR dashboard. Manual extension is useful when a request is complex and needs more time to process, when clarification from the Data Subject is pending, or when a high volume of requests is causing delays. It also applies if the request involves sensitive data that requires further internal review, includes multiple third-party processors needing coordination, or if unexpected operational disruptions affect timely response.

You can configure the manual extension while configuring the DSR form. For more information, see [Creating and publishing DSR forms](/v1/docs/creating-and-publishing-dsr-request-forms). Once done you can extend the deadline from the DSR dashboard.

1. On the DSR dashboard, locate the row for the DSR request you want to extend the deadline for.
2. At the right end of the row, choose **Options** (three dots) > **Manual Extension**.

Or open the request in the DSR Workbench, from the top of the page click **Manual Extension**.

> [!NOTE]
> **Note**
> 
> The option may be disabled for the following reasons:
> 
> - The DSR request is already extended automatically or manually.
> - The form through which the DSR request was raised has only automatic extension enabled, so manual extension is not available.
> - The DSR request is in an overdue state.
> - The DSR request is closed.
3. If extension is allowed, on the **Manual Extension** popup, select a notification template from the **Email Notification Template** menu. The template notifies the Data Subject about the extension.

This sends a notification to the Data Subject and DSR owners regarding the extension in the DSR deadline.

For non-digital or internal DSR requests where the Privacy Central account is not linked to the Data Subject, you must select a reason for extension. Then notify data subjects through their preferred communication channel.
