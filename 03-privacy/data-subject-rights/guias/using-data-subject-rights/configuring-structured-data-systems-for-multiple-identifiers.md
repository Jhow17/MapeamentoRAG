# Configuring structured data systems for multiple identifiers

To use a structured data system for multiple personal identifiers, you must mark as primary identifiers any identity PDs that you accept on your DSR request forms. For each structured Data System for which you want to process DSR requests:

1. In Securiti, click **Settings** and choose **Integrations > Data Systems > Monitored**, then click the tile for the data system.
2. At the right end, click the **Table Training**.
3. On the Table Training page, at the upper right corner, click **Edit Mode** and for each column that corresponds to the personal identifier on your DSR request form, mark the **PI** checkbox as shown below.

![Screenshot_2025-08-25_at_3_18_12_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-d65b21ce-8eee-3006-d185-fa6e7ded76fb.png)
4. If the respective column shows **No match found**, click the **+** icon next to it and map it to the respective data element that you configured on the DSR form for that personal identifier.

![Screenshot_2025-08-25_at_3_18_42_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-b339aa57-fb0b-1df0-e86c-1fb7bacf2201.png)
5. Securiti saves the changes automatically, near the upper right corner of the page, click **Leave Edit Mode**.

For more information, see [Table training for structured and hybrid data systems](/v1/docs/table-training-for-structured-and-hybrid-data-systems)
