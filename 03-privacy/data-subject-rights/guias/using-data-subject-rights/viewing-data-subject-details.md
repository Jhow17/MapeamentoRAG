# Viewing data subject details

Use the Data Subject Details tab to view detailed information about the Data Subject and their DSR request.

You can also use the Data Subject Details tab to reset the login credentials that they use to log in to the Data Subject portal.

### Opening the Data Subject Details tab

1. In Securiti, open **Data Subject Rights**, and on the DSR Dashboard page click a DSR request to open it.
2. From the top of the page, click **Subject Details**.

The Data Subject details panel opens from the right. By default it opens to the Data Subject Details tab. The top of the tab shows basic information about the Data Subject, including:
  - Name
  - Email address
  - Data and time they submitted the request
  - Language in which they submitted the request
  - Whether there are any new messages from them

> [!NOTE]
> **Note**
> 
> You can only see the fields the Data Subject fills in when submitting the DSR request. If the Data Subject does not fill in additional fields on the DSR form, the Data Subject details tab does not display them.

### Viewing regulatory information

On the Data Subject Details tab, expand the Regulatory Information area, then click one or more of the entries in that area.

Each entry shows you details about the data privacy and data security regulations that might apply to the Data Subject, based on where they submitted their DSR request and the information in that request.

### Viewing data subject request details and attachments

- On the Data Subject Details tab, expand the **Data Subject Request Details** area. This area shows:
  - Whether the Data Subject agreed to the terms and conditions of the DSR request
  - Their Data Subject type (user, customer, etc.)
  - The ID number of their DSR request
  - A list of the files they attached to the request, if any

To view a file using the native Securiti file viewer, click the entry for an attachment. The DSR Workbench supports previewing of the following file types: jpeg, jpg, png, txt, json, csv, and pdf.

To download a file, click the **Download** icon at the right end of an attachment.

### Viewing email messages exchanged with the data subject

- On the Data Subject Details tab, expand the **Email Messages with Data Subject** area. This area shows a list of the messages, and has tools that let you compose and send messages. For more information, see [Communicating with data subjects](/v1/docs/communicating-with-data-subjects).

> [!NOTE]
> **Note**
> 
> This feature is not available for DSR requests submitted using internal DSR request forms.

### Resetting data subject login credentials

If the Data Subject has lost the login credentials they use to access the Data Subject portal, you can reset their credentials. Doing so either triggers an email to the Data Subject containing a new link to access the portal or a reset password link, allowing them to reset their credentials and access the portal. This depends on whether you permit data subjects to access the DSR report with or without an account on Privacy Central. For more information, see [Setting up Privacy Central account](/v1/docs/setting-up-privacy-central-account)

If you process a non-digital DSR request, the reset credentials option generates a new password that you can share with the data subjects for accessing their report. For more information, see [Accepting non-digital DSR requests](/v1/docs/accepting-non-digital-dsr-requests).

- On the Data Subject Details tab, expand the **Reset Data Subject Login Credentials** area, then click **Reset Credentials**.

> [!NOTE]
> **Note**
> 
> This feature is not available for DSR requests submitted with internal DSR request forms.
