# Communicating with data subjects

The Securiti Data Subject messaging features let DSR request owners communicate easily with the Data Subject who submitted the request.

1. In Securiti, choose **Data Subject Rights > DSR Workbench**, then click the card for a DSR request for which you are the owner.
2. From the top of the page, click **Subject Details** as shown below.

![Screenshot_2025-03-24_at_1_38_33_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-92f5937e-4dd6-8e51-7fb4-ec46917f45ea.png)
3. On the Data Subject Details tab, Expand the **Email Messages with Data Subject** area as shown below.

![Screenshot_2025-03-24_at_1_40_04_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-849361a9-08d1-afdf-6ca8-497ab1daa4d0.png)

> [!NOTE]
> **Note**
> 
> If there is no Email Messages with Data Subject area on the panel, it is probably because you are not the request owner. Data Subject messaging features are only available for DSR request owners.
4. Use the messaging tools to view any previous messages sent to or received from the Data Subject.
5. To send a new message to the Data Subject:

Securiti alerts the Data Subject with an email that directs them to log in to the Securiti DSR Request Center to view and respond to the message. The email also contains the body of the message.
  1. Click **Compose Message**.
  2. Use the Category menu to choose a template category, then choose one of the available templates and click its **Use** button.

See [Creating and editing messaging templates](/v1/docs/creating-and-editing-messaging-templates) for more information about customer messaging templates.
  3. (Optional) To send a modified message based on the template, click the **Detach from Template** link, then edit the message to suit.

You can also send attachments to data subjects while messaging them from the DSR workbench. This lets you share screenshots, PDF instructions, or request-related details during ongoing communication.

> [!NOTE]
> **Note**
> 
> You can attach an unlimited number of files. Each file must not exceed 100 MB.
  4. Click **Send Message**.

Securiti also has a separate set of features that let DSR request and Subtask owners communicate among themselves. See [Communicating with DSR and subtask owners](/v1/docs/communicating-with-dsr-and-subtask-owners).
