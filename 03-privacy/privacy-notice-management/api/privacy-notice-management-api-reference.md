# Privacy Notice Management API reference

The [Privacy Notice Management APIs](https://securiti-doc-router.securiti.ai/modules/privacy-notice-management/apidocs/index.html) let you create, retrieve, update, approve, publish, and manage privacy notices through API-based operations. The APIs also support privacy notice wizards, DSR processing workflows, cookie scan imports, notice templates, approver management, co-owner management, messaging, and notice reminders.

This API documentation includes operations such as:

- Privacy notice management:
  - Create privacy notices
  - Fetch all privacy notices
  - Fetch privacy notice by ID
  - Update privacy notice
  - Clone privacy notices
  - Delete privacy notices
  - Approve notices
  - Publish notices
- Privacy notice wizards:
  - Fetch all privacy notice wizards
  - Fetch privacy notice wizard by ID
  - Fetch DSR stats for privacy notice wizards
  - Fetch processing purpose details for privacy notice wizards
  - Import cookie scan results into privacy notice wizards
- Collaboration and governance:
  - Manage approvers
  - Manager co-owners
  - Manage notice reminder
  - Send, fetch, edit and delete messages

Use the [Privacy Notice Management REST API documentation](https://securiti-doc-router.securiti.ai/modules/privacy-notice-management/apidocs/index.html) to explore and test the APIs, review `HTTP` endpoints, sample API request and response body schemas, query parameters, path parameters, and authentication methods. You can also access Postman Collection to review and test API responses before integration.
