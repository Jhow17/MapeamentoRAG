# Managing the Font Repository

You can use the **Font Repository** to centrally manage fonts, including uploading, storing, and maintaining font assets such as language-specific and brand-specific fonts. This ensures consistent typography across privacy notices.

> [!WARNING]
> Important
> 
> This feature is available in Securiti SaaS deployments but is not currently available in Securiti Sovereign deployments. Contact your Customer Success Manager or Account Representative for updates on its availability in your tenant.

> [!CAUTION]
> Caution
> 
> It is your responsibility to ensure that any custom fonts you upload are properly licensed. Before uploading a custom font, you must:
> 
> - Verify that you have the necessary rights or licenses to use the font for your intended purpose.
> - Review and comply with the font's **End User License Agreement (EULA)** or any applicable usage terms.

1. In Securiti, open Privacy Notice Management.
2. On the left side bar menu, click the **Settings** (gear icon) and then **Font Repository,** as shown below.

![Settings menu displaying Font Repository and options for managing fonts.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/module_settings(1).png)
3. Near the upper right corner, click **+ Upload a new font**, as shown below.

![Font repository interface displaying available fonts and an upload button for new fonts.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/managing_font_repository_1.png)

> [!NOTE]
> Note
> 
> - Securiti currently supports only the **.woff2** font files.
> - You can set fonts separately for each tenant; however, colors and styling apply at the organization level.
4. In the **Upload New Font** popup, enter a name for the font.

Select the appropriate font **Type** and **Weight,** and next to it click the **[Font Name].woff2** to upload the font file, as shown below.

![Uploading a new font named AppleGaramondReg with specified type and weight settings.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/managing_font_repository_2.png)
5. To upload different weights and styles of the same font, click **+ Add Font Face**, as shown below.

![Uploading a new font with name, type, weight, and language options in the repository.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/managing_font_repository_3.png)
6. (Optional) To assign a font to a specific language, select a language from the **Assign Languages** menu, as shown below.

![Upload new font settings with options for name, type, weight, and languages.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/managing_font_repository_4.png)
7. At the bottom of the popup, click the **Upload Font** to upload the font file, as shown below.

![Upload new font interface showing font name, type, weight, and upload button.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/managing_font_repository_4 copy.png)
8. At the far right of the font entry row, click **Options** (three dots), and from the menu, select **Edit** or **Delete** to edit or delete the font, as shown below.

![Font repository displaying available fonts with options to edit or delete.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/font_repository_1.png)
