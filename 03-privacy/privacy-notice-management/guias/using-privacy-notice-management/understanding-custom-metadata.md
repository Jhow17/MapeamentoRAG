# Understanding Custom Metadata

**Scenario**

As a Data Privacy Officer, you manage privacy notices across multiple business units, each tracking different details such as business owner, product line, approval documents, and region. Without a standardized way to capture this information, notices can be difficult to find, review, and govern. With **Custom Metadata**, you can create custom metadata fields, mark **Business Owner** and **Region** as required, and enable **Auto-Assign** so every new notice includes these fields. For example, you can assign Online Banking as the Product Line and attach the relevant approval document to applicable notices. You can then filter notices by metadata, keep records organized, and maintain consistent governance across your organization.

Custom Metadata lets you add structured, customizable information to privacy notices and templates, making it easier to organize, manage, search, and govern them. You can create custom metadata fields, assign them to privacy notices and templates, apply them in bulk, and use different data types to capture the information you need.

> [!WARNING]
> Important
> 
> This feature is available in Securiti SaaS deployments but is not currently available in Securiti Sovereign deployments. Contact your Customer Success Manager or Account Representative for updates on its availability in your tenant.

## Understanding the custom metadata dashboard

Custom Metadata dashboard gives you an overview of all the custom metadata, as shown below.

![Custom metadata fields for privacy notice management, highlighting required and optional data types.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/custom_metadata_dashboard.png)

You can view the following details about custom metadata:

| Field | Description |
| --- | --- |
| Name | Displays the name of the custom metadata. |
| Data Type | Shows the assigned data type to custom metadata, such as **Text**, **Paragraph**, **Select**, or **Attachment**. |
| Requirement | Shows whether the custom metadata is **Required** or **Optional**. Required custom metadata must have a value before you publish the notice or link a template to a notice. |
| Value | Shows the given value to custom metadata. |
| Usage | Shows the total number of privacy notices and templates that use the custom metadata. Hover over the number to view the number of notices and templates separately, as shown below. ![Custom metadata management interface showing required and optional fields for data entry.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/notice_template_usage.png) |
| Auto-Assign | Indicates the auto-assigned custom metadata to privacy notices and templates. > [!NOTE] > Note > > Securiti automatically assigns auto-assigned custom metadata to all new privacy notices and templates. |
| Organization | Displays the organization attached to custom metadata. |
| Last Modified | Displays the last modified date of custom metadata. |
| Owner | Displays the custom metadata owner details. |
| Metadata | Shows details such as custom metadata name, data type, and usage in a card, as shown below. ![Custom metadata settings with required fields and options for approval process and region.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/custom_metadata_icon.png) |

## Customizing the custom metadata dashboard

To customize the Custom Metadata dashboard:

1. Open Privacy Notice Management, and choose **Dashboards > Custom Metadata**.
2. Near the upper left corner of the custom metadata list, click the **Column Selector** icon, as shown below.

![Custom metadata settings for privacy notice management with required fields highlighted.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/custom_metadata_column_selector_1.png)
3. Mark the checkbox next to a column name in the menu to enable or disable the column on the dashboard, as shown below.

![Custom metadata management interface displaying required fields and options for data entry.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/custom_metadata_column_selector_2.png)
4. To change the position of the column, move the drag handle up or down in the list, as shown below.

![Custom metadata management interface showing required fields and options for data types.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/custom_metadata_column_selector_3.png)
5. To restore to the default column view, near the upper left corner of the menu, click **Restore Defaults**, as shown below.

![Custom metadata settings for privacy notice management with various data types and options.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/custom_metadata_column_selector_4.png)
6. After making the desired changes, click **Apply**, to apply the changes.
