# Creating a new custom metadata

You can create custom metadata by defining its name, data type, default value, and assignment settings. This lets you add structured information to privacy notices and templates and manage it based on your requirements.

To create a new custom metadata:

1. Open Privacy Notice Management, and choose **Dashboards > Custom Metadata**.
2. Near the upper right corner of the page, click **+ New Custom Metadata**, as shown below.

![Custom metadata settings for privacy notice management with required fields highlighted.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/create_custom_metadata_1.png)

On the **Create Custom Metadata** popup, provide the custom metadata details.
  1. In the **Metadata Name** field, give an appropriate name to the custom metadata.
  2. (Optional) Provide description for metadata.
  3. Select metadata data type from the **Data Type** menu.

Securiti lets you select four data types, **Text**, **Paragraph**, **Select**, or **Attachment**, as shown below.

![Creating custom metadata with fields for jurisdiction, description, and data type selection.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/create_custom_metadata_2.png)

| Data type | Description |
| --- | --- |
| Text | Lets you specify a short text value, such as a business unit name. |
| Paragraph | Lets you specify a longer text, such as internal notes or review comments. |
| Select | Lets you specify one or more predefined values, such as applicable regions. You can also enable **Allow Multi-select** to select multiple values, as shown below. ![Creating custom metadata with options for jurisdiction and multi-select values.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/create_custom_metadata_3.png) |
| Attachment | Lets you add a file, such as a supporting document, or signature image. |
  4. (Optional) Enter the default values for the **Text** and **Paragraph** data types in the **Default Value** field, as shown below.

![Creating custom metadata with jurisdiction details and default value for California.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/create_custom_metadata_4.png)

(Optional) For the **Attachment** data type, upload the file using the **Choose File** upload control, as shown below.

![Form for creating custom metadata with fields for name, description, and data type.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/attchement_data_type.png)

> [!NOTE]
> Note
> 
> The **Attachment** data type supports **PNG**, **JPEG**, **PDF**, and **DOCX** file formats, with a maximum file size limit of **2 MB**.

> [!WARNING]
> Important
> 
> You can also specify or update the **Default Value** when applying custom metadata to privacy notices or templates.

You must provide at least one value if the data type is **Select**, as shown below.

![Form for creating custom metadata with fields for jurisdiction and possible values.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/create_custom_metadata_33.png)
  5. Provide the **Organization** details. You can search organizations and add it to your custom metadata.

> [!NOTE]
> Note
> 
> - Securiti selects the current organization by default. You can add other organizations to share this custom metadata with them.
> - Securiti does not let you change the organization selection after you create the custom metadata.
  6. To make custom metadata required, mark the **Mark as required** checkbox.

> [!NOTE]
> Note
> 
> The required custom metadata appears with an asterisk, indicating that you must provide a value for the field before publishing the notice or linking the template.
  7. To make it auto-assigned for all new notices and templates, mark the **Auto-Assign this to future notices and templates** checkbox, as shown below.

![Creating custom metadata with required fields and default values for organizations.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/create_custom_metadata_6.png)
  8. Near the bottom of the **Create Metadata** popup, click **Create** to create custom metadata, as shown below.

![Creating custom metadata with fields for jurisdiction, description, and organization sharing options.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/create_custom_metadata_7.png)

You can view or modify the created metadata from the **Custom Metadata** dashboard.
