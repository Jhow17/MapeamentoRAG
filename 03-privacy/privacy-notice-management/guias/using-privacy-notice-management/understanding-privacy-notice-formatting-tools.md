# Understanding privacy notice formatting tools

The toolbar in the privacy notice editor provides formatting tools that help you create structured and organized privacy notices. You can use text formatting options to adjust the appearance of content for better clarity, and you can add content blocks to insert structured elements such as headings, lists, tables, links, quotes, dividers, and code snippets. These tools help you organize notice information clearly and consistently, making privacy notices easier to read and manage.

## Editing notice text

The text modification tools let you format and style content within the privacy notice using headings, fonts, text emphasis, colors, alignment, and lists.

### Adding headings and paragraphs

You can use the **Paragraph** menu to insert structured content such as headings (H1 to H5) and paragraphs to your privacy notice.

1. To add a heading, click **Paragraph**, and from the menu select heading level from **Heading 1** to **Heading 5**, as shown below.

![Document editing interface showing headings and sections for privacy notice content.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-1781509833925.png)
2. To add heading content, press **Enter,** and type or paste notice content.
3. To change a heading to a paragraph, select the heading text, click **Paragraph** in the toolbar, and then select **Paragraph** from the menu, as shown below.

![Document section explaining data usage, sharing, and disclosure in privacy management.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/paragraph_2.png)

### Applying fonts

You can use the font menu to change the text style and apply different fonts to notice text. The font menu displays the name of the currently applied font at the cursor position.

1. To change the font, click the font menu, and from the menu select the desired font style, as shown below.

![Privacy notice document outlining information collection, usage, and data sharing policies.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-1781509883209.png)
2. To change the font of a specific sentence, paragraph, or word, first select the content and then use the font menu to choose a font, as shown below.

![Document editing interface showing font selection and highlighted information usage section.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/font_menu_2.png)

To maintain consistent branding and use typography that is not available in the default font library, you can upload a custom font to use in the notice editor. For more information, see [Managing the font repository](/latest/docs/managing-the-font-repository).

### Formatting text

You can use text formatting options to style your privacy notice content and emphasize key information.

1. To make text bold or italic, select the text, and click **B** (Bold) or ***I*** (Italic).
2. To apply strikethrough, select the text, click **More** (three dots), and then from the menu, click **~~S~~** **Strike Through**.
3. To underline text, select the text, click **More** (three dots), and then from the menu, select **U Text Underline**, as shown below.

![Privacy notice document outlining data collection and usage information for users.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/bold_italic.png)

You can customize text appearance by changing the font color and applying highlight color to emphasize important content.

![Privacy notice document showing sections on information collection and data sharing.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/text_color_2.png)

Custom color option opens a color picker with sliders for fine-tuned selection, as shown below.

![Privacy notice document showing sections on information collection and data sharing.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/text_color_3.png)
3. To change the highlight color, select the text and click **Highlight** (highlighter icon) from the toolbar, and select a color from the color palette panel of predefined colors, as shown below.

![Privacy notice sections detailing information collection, usage, and data sharing practices.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/highlight_text_1.png)
4. To choose a custom color, from the color pallet panel, below the **Custom**, click **+** (plus icon), as shown below.

![Privacy notice document outlining information collection, usage, and data sharing policies.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/highlight_text_2.png)

### Aligning text

You can use the text alignment menu to control the alignment of privacy notice content.

To change alignment, select the text, and click the alignment menu from the toolbar, as shown below.

![Privacy notice document with sections on information collection and data sharing highlighted.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-1781510015752.png)

Choose one of the available options:

- Align Left
- Align Center
- Align Right
- Justify

You can apply this alignment to both headings and paragraphs.

## Undo and redo changes

You can undo and redo actions to revert recent changes or reapply previously undone edits.

To undo or redo:

1. On the left side of the toolbar, click **Undo** (left arrow icon) to reverse the last action.
2. To restore an action, click **Redo** (right arrow icon), as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/undo_redo(1).png)

## Managing notice formatting and structure

You can organize the privacy notice content in a clear and structured format using options like indentation and bullet listing.

### Adding ordered or unordered lists

You can use bullet and numbered lists to organize content in a clear and structured way.

1. To create a bullet list, click the bullet list icon from the toolbar, as shown below.

![Privacy notice outlining data usage, sharing, and disclosure information for users.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/bullet_list.png)

You can also convert existing text into a bullet list by selecting the text and applying the bullet list option.
2. To create a numbered list, click the bullet list icon from the toolbar, as shown below.

![Privacy notice document outlining data usage and sharing policies for users.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/numbered_list.png)

You can also convert existing text into a bullet list by selecting the text, and applying the numbered list option.

### Applying indentations

You can use the indentation options to adjust the structure and hierarchy of the privacy notice content.

1. To change indentation, select the text and click the **Increase Indent** icon from the toolbar to move the content to the right, as shown below.

![Overview of data usage, processing, and sharing in a privacy notice document.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-1781510070617.png)

Click **Increase Indent** again to apply additional indentation as needed.
2. To reduce indentation, click the **Decrease Indent** icon from the formatting toolbar to move the content to the left, as shown below.

![Privacy notice detailing data usage, sharing, and processing information for users.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-1781510123447.png)

Click **Decrease Indent** again to reduce the indentation level further, as needed.

These indentation options apply to both headings and paragraphs in the privacy notice.

### Linking notice sections and web addresses

You can link sections within the privacy notice or to web addresses to connect related content.

To link a web address:

1. Select the text and click **Link** (chain icon) from the toolbar, as shown below.

![Privacy notice sections detailing information collection, usage, and data sharing practices.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-1781510177151.png)
2. From the **Add Link** popup, select the preferred option.

For the external link, choose how you want the link to be opened. The **New Tab** card lets you open the link in the new tab while the **Same Tab** card lets you open the link in the same tab, as shown below.

![Instructions for adding links with options for new tab, same tab, and anchor link.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/link_2.png)
3. Type or paste the URL in the **Web Address** field, and click **Submit**, as shown below.

![Interface for adding a link with options for tab preferences and a web address.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/link_3.png)

To link a privacy notice section:

1. Select the text and then click **Link** (chain icon) from the toolbar.
2. From the **Add Link** popup, select **Anchor Link** card.
3. Choose the privacy notice section from the **Select Section** menu, and click **Submit**, as shown below.

![Interface for adding links in a privacy notice, highlighting sections and options.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/link_4(1).png)

To modify the linking such as web address or notice section:

1. Select the linked text and click **Link** (chain icon) again.
2. From the **Add Link** popup, make changes as needed, and click **Submit**.

## Adding and managing tables

You can insert a table to organize notice content into rows and columns within the privacy notice.

To add a table in your privacy notice:

1. From the toolbar, click the **Grid** (table icon) icon, as shown below.

![Dashboard view showing privacy notice sections and options for publishing content.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/table_1.png)

A grid panel opens, displaying rows and columns for selection, as shown below.

![Privacy notice sections on information collection, usage, and data sharing outlined clearly.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/table_2(1).png)
2. Move the cursor over the grid to select the required number of rows and columns, as shown below.

![Privacy notice document outlining information collection, usage, and data sharing sections.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/table_3.png)
3. Click the highlighted cell to insert the table into the notice workspace, as shown below.

![Privacy notice section detailing data sharing and disclosure with third parties.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/table_4.png)
4. To manage a table, click anywhere on the table. A **Table options** menu appears below the table, as shown below.

![Privacy notice section detailing data sharing and disclosure with third parties.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/table_5.png)
5. Click on **Table options** to enable or disable the following options:

| Option | Description |
| --- | --- |
| Remove borders | Remove borders from the table. |
| Header row | Enable or disable the header row. |
| Header column | Enable or disable the header column. |
6. To copy or delete tables, click on the **Copy** (clipboard icon) or **Delete** (trash can icon) respectively, as shown below.

![Privacy notice section detailing data sharing and disclosure with third parties.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/table_6.png)

To paste the table, use **Ctrl + V** or **CMD + V**.

### Managing table cells

![Privacy notice section detailing data sharing and disclosure with third parties.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/table_7.png)

A menu appears with cell options, including:

| Action | Description |
| --- | --- |
| Background Color | Change the background color of a cell. |
| Merge Cell | Merge two or more cells into one. |
| Split Cell | Split a single cell into multiple cells. |
| Add column right | Add a column to the right of the current column. |
| Add row below | Add a row below the current row. |
| Distribute columns | Distribute column widths evenly. |
| Clear cell | Remove the content of a cell. |
| Delete Column | Delete the selected column. |
| Delete Row | Delete the selected row. |

## Inserting blocks

You can use the **+ Insert Block** option to enhance content by adding structured elements to your privacy notice such as quotes, code snippets, images, and dividers.

To add a block to your privacy notice:

1. Click **+ Insert Block** from the toolbar, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/insert_block(1).png)
2. From the menu choose the required block.

You can select the following blocks from the **+ Insert Block** menu:

| Block | Description |
| --- | --- |
| Quote | Insert a block to highlight external references or important statements within the privacy notice to distinguish them from the main text. |
| Divider | Add a horizontal line to separate different sections of the privacy notice. |
| Code Snippet | Insert a formatted block for displaying short pieces of code. |
| Code | Insert a larger code block area for writing and viewing multi-line code with proper formatting and structure. |
| Add Attachment | Insert images into the privacy notice to include diagrams, screenshots, or other relevant visuals. |
| Column Layout | Insert 1 - 5 column layouts to organize privacy notice content side-by-side, such as separating descriptions, categories, or data processing details. |

You can also add a block from notice workspace.
3. To add blocks from the notice workspace, hover over the heading of content blocks and to the left of the block, click **+** (plus icon), as shown below.

![Overview of information collection section in privacy notice management interface.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/add_block_1(1).png)
4. Select the block from the menu, as shown below.

![Dashboard view showing privacy notice editing with content blocks and search options.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/add_block_2(1).png)
5. You can search the block or click **View More** to all the blocks, as shown below.

![Privacy notice section detailing information collection and content block options available.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/add_block_3(1).png)
