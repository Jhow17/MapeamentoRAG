# Filtering custom metadata

The top-level filter in **Custom Metadata** dashboard lets you combine different properties of the custom metadata and apply filters accordingly. It takes precedence over other filters, working from the top down and determining the result values in the grid view.

To use the top-level filter in **Custom Metadata**:

1. Near the upper left corner of the **Custom Metadata** dashboard, click **+** (plus icon) to open the filter panel, as shown below.

![Custom Metadata management interface displaying filters, metadata options, and selection features.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/filter_custom_metadata_1.png)
2. From the left pane of the filter panel, search for custom metadata using the following properties:

| Property | Purpose |
| --- | --- |
| Organization | Filters custom metadata by organization, such as Default Organization or a user-defined organization. |
| Owner | Filters custom metadata by owner, such as `sam@democo.com `or `bob@democo.com`. |
| Data Type | Filters custom metadata by **Data Type**, such as **Text**, **Paragraph**, **Select**, or **Attachment**. |
| Requirement | Filters custom metadata by required status, such as **Required** or **Optional**. |
| Auto Assign | Filters custom metadata by Auto-Assign status, such as **Yes** or **No**. |

You can use the **is one of** operator to select one or more values from the right filter pane of the filter panel, as shown below.

![Custom metadata settings for data types including text, select, paragraph, and attachment options.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/filter_custom_metadata_2.png)

For instance, if you want to filter custom metadata by **Data Type** (property), from the left pane of the filter panel, select **Data Type**, then from the right pane mark the checkboxes next to the **Data Type** names, as shown below.

![Custom metadata settings with options for data type, requirement, and auto assign features.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/filter_custom_metadata_3X.png)

![Custom metadata settings showing data type, requirement, and auto-assign options.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/filter_custom_metadata_3.png)
3. Repeat the same step for other properties according to your search needs. Once you apply all required properties, near the bottom of the filter panel, click **Apply**, as shown below.

![User interface for managing custom metadata with filter options and apply button.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/filter_custom_metadata_4.png)

Securiti builds a query also known as **View** based on your selected properties and displays the filtered results, as shown below.

![Custom metadata settings with options for data type, auto-assign, and requirements displayed.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/filter_custom_metadata_5.png)
4. To clear the top-level filter or **View**, from the upper right corner, click **Clear Search**, as shown below.

![Custom metadata settings with options for data type, auto-assign, and requirements displayed.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/filter_custom_metadata_6.png)

## Saving views

To save a view for your set filters and search results:

1. On the **Custom Metadata** dashboard, near the upper right corner of the page, click **Options** (three dots), and choose **Save View** from the menu, as shown below.

![Custom metadata settings with options for data type, auto-assign, and requirements displayed.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/filter_custom_metadata_7.png)
2. On the **Save View** panel, enter a name and description, and select a group of views or add a new one. Then, near the bottom of the panel, click **Save View** to save your view, as shown below.

![Custom metadata settings for privacy notices, including options for region and approval process.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/filter_custom_metadata_8.png)

## Using the saved views

You can access and apply your saved views at any time through the Saved View panel.

1. Near the upper right corner of the **Custom Metadata** dashboard, click **Options** (three dots), and choose **Saved View** from the menu, as shown below.

![Custom metadata management interface displaying required and optional fields for data entry.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/filter_custom_metadata_9.png)

Clicking **Saved View** opens a panel for saved filters on the left side. The panel displays saved groups and views, as shown below.

![Custom metadata settings for Privacy Notices in a business application interface.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/filter_custom_metadata_10.png)
2. Click any group to view the list of saved views for that group.
3. Click the view name, or next to the view name click **Options** (three dots), and choose **View** from the menu to apply the saved filter, as shown below.

![Custom views section showing options to view, edit, and delete privacy notices.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/filter_custom_metadata_12(1).png)

## Managing the saved views

To update a saved filters, their group, or the names and descriptions associated with them:

1. Near the upper right corner of the **Custom Metadata** dashboard, click **Options** (three dots), and from the menu, select **Saved View**.

Clicking **Saved View** opens up a panel for saved views on the left side of the page. The panel displays custom groups of saved views.
2. Next to the group name, click **Options** (three dots), and choose **Rename** or **Delete** from the menu to perform the desired action, as shown below.

![Custom views section showing options to rename or delete saved views in a dashboard.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/filter_custom_metadata_11.png)
3. Similarly, click any group to view the list of saved views. Next to the view name, click **Options** (three dots), and choose **Edit** or **Delete** from the menu to perform the desired action, as shown below.

![Custom views section showing options to view, edit, and delete privacy notices.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/filter_custom_metadata_12(1).png)
