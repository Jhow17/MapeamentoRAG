# Managing language translations for privacy notices

Securiti lets you apply translations within Privacy Notice Management for supported languages so you meet regional requirements and website visitors or data subjects clearly understand your data handling practices.

## Adding a translation to privacy notice

To add a language translation to a privacy notice:

1. In Securiti, open Privacy Notice Management, and the select **Dashboards > Privacy Notices**.
2. From the **Privacy Notice Dashboard**, create or open the notice to which you want to add a translation.
3. Near the upper right corner of the editor, to the left of the **Details,** click **English** (language menu), and from the menu, select **Manage Languages**, as shown below.

![Privacy notice management dashboard displaying company information and language options.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/manage_language_1.png)

> [!NOTE]
> Note
> 
> The language menu displays the notice's default language. For instance, if the default language is set to **German**, the menu shows **German** instead of **English**, as shown below.
> 
> ![Privacy notice section detailing information collection and usage guidelines for users.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-1782907075991.png)

Or, near the upper right corner of the notice editor, next to **Preview**, click **More** (three dots) and from the menu select **Settings,** as shown below.

![Privacy notice dashboard displaying sections for information collection and usage details.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/notice_settings_languages.png)

From the **Notice** **Settings**, click **Manage Languages**.
4. Click **Add a Language** search box to open a language selection menu, as shown below.

![Manage languages settings with options to add and select various languages.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/manage_language_translations_2.png)

You can choose from two types of language options in the menu:

| Language type | Description |
| --- | --- |
| System Generated | Automatically translates the default language. |
| User Generated | Lets you add translations manually. |

If you select a **System Generated** language, Securiti automatically translates the default language into the selected language. A **User Generated** language, on the other hand, lets you add translations manually.
5. After selecting a language, near the bottom of the menu, click **Add**, as shown below.

![Settings page for managing languages with options to add and save changes.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/add_language.png)

The selected languages appear in the language configuration table, as shown below.

![Settings for managing languages and public language preferences in a notice configuration.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/manage_language_translations_3.png)
6. You can also modify the **System Generated** translation. Switch the **Translation Source** from **System** to **User** within the language configuration table, as shown below.

![Settings page for managing languages and translation preferences in a user interface.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/manage_language_translations_4.png)

Switching the **Translation Source** from **System** to **User** lets you modify the notice content based on your specific requirements and manage the translations manually.

> [!NOTE]
> Note
> 
> If you make changes without switching the **Translation Source** from **System** to **User**, Securiti prompts you to synchronize the translations. For more information, see [Synchronizing translation updates](/latest/docs/managing-language-translations-for-privacy-notices#updating-translations).
7. To assign a specific font to a selected language, in the language configuration table, click the **Fonts** menu and select a font, as shown below.

![Settings page for managing languages and font preferences in a web application.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/manage_language_translations_5.png)

You can search for a font or click **Manage Fonts** to open the **Font Repository**. For more information on managing fonts, see [Managing the Font Repository](/latest/docs/managing-the-font-repository).
8. To set a language as the default, hover over the language in the language configuration table, next to **Fonts** menu, click **Options** (three dots), and select **Set as Default**, as shown below.

![Settings page for managing languages and preferences in a web application interface.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/set_default_language.png)
9. To delete a translation, hover over the language in the language configuration table, next to the **Fonts** menu, click the **Delete** (trash icon), as shown below.

![Settings page for managing languages and preferences in a web application interface.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/delete_translation.png)
10. You can also manage language preferences from the **Public Language Preferences** section:
  - Mark the **Language Intelligence (Browser language detection)** checkbox to enable or disable automatic detection of a visitor’s language based on their browser settings and display the privacy notice in the detected language.
  - Mark the **Language Selection for Visitors** checkbox to enable or disable a language selector on the privacy notice that lets visitors to manually choose their preferred language.
  - Mark the **Enable Section Title Translation** checkbox to enable or disable translation of privacy notice section titles for each configured language.

> [!NOTE]
> Note
> 
> To let website visitors to view the privacy notice in their preferred language, enable either **Language Intelligence** or **Language Selection for Visitors**. If you disable both options, Securiti displays the privacy notice only in the default language.
11. Click **Save Changes** to apply the translation and language preferences, as shown below.

![Settings page showing language management options and save changes button.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/manage_language_translations_6.png)

> [!NOTE]
> Note
> 
> - The **System Generated** translation takes up to one hour to sync.
> - For all published and draft notices, the status updates to **Syncing Translations** when additional languages are added to the notice.
12. Once the translation syncs, next to **Co-owners**, click **English** (language menu) and select the translated language to view or edit it in the editor, as shown below.

![Privacy policy document with language selection options and content sections displayed.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/pnm_language_switch.png)

## Comparing language translations

You can use the **Compare Translations** feature within the notice editor to view the original and translated text side by side, making it easier to compare and edit translations inline.

To compare translations:

1. From the **Privacy Notices** dashboard, create or open a notice.
2. Configure the desired language for translation and wait for its completion.
3. Once Securiti finishes the translation process, next to the **Co-owners** option, click **English** and from the menu select **Compare Translations**, as shown below.

![Privacy notice document with company information and data protection details displayed.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/compare_languages_1.png)

On the **Compare Translations** page, you can review, and make the desired changes to the translation, as shown below.

![Comparison of English and French privacy policy information for PNM website.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/compare_languages_2.png)
4. After making the necessary changes, near the top right corner of the page click **Save**.

## Synchronizing translation updates

When you update privacy notice content in any **System Generated** language, the notice editor detects the changes and prompts you to synchronize the automatic translations. You can synchronize the translations or skip synchronization to retain your changes.

> [!NOTE]
> Note
> 
> Synchronization does not apply to **User Generated** languages.

To apply the synchronization:

1. Near the upper right corner of the notice editor, next to **Co-owners**, click **Translation Updates Available**, as shown below.

![Privacy notice dashboard displaying information collection and usage sections for translations.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/translation_update.png)
2. In the **Translation Updates Available** popup, mark the **Select All** checkbox, and click **Update Selected Translations**, as shown below.

![Translation updates available for selected languages, including French, with options to update.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/update_translations.png)

To update a specific language, mark the checkbox for that language.

If you do not want automatic translation synchronization, you can skip it.
3. In the **Translation Updates Available** popup, select all languages or choose the specific language for which you want to skip the update, and then click **Skip**, as shown below.

![Translation updates available for selected languages, including French, with options to skip or update.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/skip_translation.png)

**Skip** lets you retain the current translated content and defer translation synchronization

> [!NOTE]
> Note
> 
> The notice status changes from **Pending Translation** to **Ready to Publish** only after you skip translation updates for all languages.

## Configuring language preferences

You can configure language preferences for the notice header title, including browser language detection and a language selector.

To configure language preference:

1. From the **Privacy Notices** dashboard, create or open a notice.
2. Near the upper right corner of the notice editor, next to **Preview,** click More and select **Settings** from the menu. From the **Notice Settings** pop-up, click **Manage Languages**.
3. From the **Manage Languages** tab, configure the following settings:

| Setting | Description |
| --- | --- |
| Public Language Preferences | Manage language preferences through the following settings: - Mark the **Language Intelligence (Browser Language Detection)** checkbox to enable or disable automatic detection of a website visitor’s language based on browser settings. - Mark the **Language Selection for Visitors** checkbox to enable or disable a language selector that lets website visitors to manually choose their preferred language. - Mark the **Enable Section Title Translation** to enable or disable translation of privacy notice section titles for each configured language, as shown below. ![Settings page for managing languages and preferences in a web application interface.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/create_new_privayc_notice_1_4.png) |
