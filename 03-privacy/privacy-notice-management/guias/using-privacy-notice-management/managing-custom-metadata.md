# Managing custom metadata

You can manage and modify your existing custom metadata from the **Custom Metadata** dashboard.

## Modifying the custom metadata

To modify a custom metadata:

1. Open Privacy Notice Management, and choose **Dashboards > Custom Metadata**.
2. Near the far right of the custom metadata row, click **Options** (three dots), and from the menu, select **Edit**.

![Custom metadata management interface showing selected items and options for assignment.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/modifying_custom_metadata_1.png)

From the **Edit Custom Metadata** popup, you can change metadata name, description, value, required and auto-assigned checkboxes.

> [!NOTE]
> Note
> 
> Securiti does not let you modify the **Data Type** or add organizations while editing existing custom metadata. The **Organizations** section does not appear in the **Edit Custom Metadata** popup.

You can also edit the custom metadata from the **View Details** option.
  1. Near the far right of the custom metadata row, click **Options** (three dots). From the menu, select **View Details**, as shown below.

![Custom metadata management interface showing required and optional fields for data entry.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/view_details_custom_metadata_1.png)
  2. From the custom metadata **View Details** popup, click **Edit** to open the **Edit Custom Metadata** popup, as shown below.

![Metadata details for Sam Carter, including data type, requirement, and organization information.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/view_details_custom_metadata_3.png)
3. After making the desired changes, near the bottom of the **Edit Custom Metadata** popup, click **Save**.

![Editing custom metadata fields for jurisdiction selection in a software interface.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/modifying_custom_metadata_2.png)

## Deleting custom metadata

To delete custom metadata:

1. Near the far right of the custom metadata row in the custom metadata list, next to the metadata icon, click **Options** (three dots).
2. From the menu, select **Delete** to delete the custom metadata, as shown below.

![Custom metadata management interface displaying required and optional fields for data entry.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/deleting_custom_metadata_1.png)

## Deleting custom metadata in bulk

To delete custom metadata in bulk:

1. Select custom metadata in bulk:
  1. Near the upper left corner of the custom metadata list, next to the **Name** column, click the checkbox, as shown below.

![Custom metadata management interface displaying required and optional fields for data entry.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/checkbox_menu.png)
  2. From the menu, choose either **Select all across all pages**, or **Select all on this page**, as shown below.

![Custom metadata management interface showing options for selecting data types and jurisdictions.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/deleting_custom_metadata_bulk_1.png)
2. Near top of the custom metadata list, from the custom metadata action bar, click **Delete**, as shown below.

![Custom metadata management interface showing selected items and options for assignment.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/deleting_custom_metadata_bulk_2.png)
3. On the confirmation popup, click **Delete Custom Metadata**, as shown below.

![Confirmation dialog for deleting three custom metadata fields from the workspace.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/deleting_custom_metadata_bulk_3.png)
