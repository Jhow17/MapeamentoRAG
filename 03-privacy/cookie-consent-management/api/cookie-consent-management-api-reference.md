# Cookie Consent Management API reference

The Cookie Consent Management API documentation lets you manage cookie consent workflows across domains and subdomains, including domain configuration, scans, cookie and tracker categorization, consent experiences, consent status, IAB EU GDPR consent configurations, auto-blocking, CSP, and reporting.

Use this API documentation to perform operations such as:

- Generate OAuth 2.0 access tokens for API authentication.
- Manage organization units, domain groups, domains, domain versions, and supporting metadata.
- Start domain scans, enable subdomain scans, manage scan configurations, and upload offline scanner results.
- Configure strict CSP headers and auto-blocking settings for a domain.
- Manage cookie drafts, published cookie categories, cookie banners, and preference centers.
- Fetch latest published cookies, trackers, categories, scan details, and policy versions.
- Manage IAB EU GDPR consent configurations, drafts, deletion, and publishing.
- Upload cookie consent, retrieve consent status, fetch consent status reports, and review user agent details.
- Schedule, export, delete, and download raw record reports, `CSV` consent reports, consent dashboard records, and dashboard reporting data.
- Fetch countries, locations, users, and other reference data used across cookie consent workflows.

Use the Cookie Consent Management [REST API documentation](https://securiti-doc-router.securiti.ai/modules/cookie-consent/apidocs/index.html) to explore and test Cookie Consent Management APIs, review `HTTP` endpoints, `JSON` request and response formats, query parameters, API schemas, authentication methods, and sample API requests. You can also download the **Postman collection** for the supported Cookie Consent Management workflows.
