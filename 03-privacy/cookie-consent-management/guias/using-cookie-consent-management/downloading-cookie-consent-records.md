# Downloading cookie consent records

You can download the current contents of the **Consent Records** table on the Cookie Consent Dashboard as a **CSV** file.

> [!NOTE]
> **Note**
> 
> The contents of the file reflects the filters applied at the time of the download.

1. In Securiti, open **Cookie Consent Management**.
2. Near the upper right corner of the page, click **Filter** and apply filters to suit. For more information, see [Filtering Securiti pages and dashboards](/v1/docs/filtering-securiti-pages-and-dashboards).
3. From the upper right corner of the Consent Records table, click **Download**, as shown below.

![RN_consent_download.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-420adfe6-9307-6907-16ed-0ac8fd9e5882.png)

Securiti sends you an email with a link you can use to download the contents of the filtered table in CSV format.

> [!NOTE]
> **Note**
> 
> To prevent multiple report requests and reduce system strain, the **Download Records** button on the Cookie Consent Dashboard disables after a single click and only re-enables when you change the filters. Additionally, Securiti enforces a limit of **5 report requests per hour** for each Securiti user role.

A small text file that is stored on a data subject's or website visitor's device (computer, smartphone, or tablet) by a domain (website). Cookies are used to collect information about the user's interactions with the website, such as preferences, login status, and browsing history. This information helps domains enhance user experience, perform analytics, and deliver personalized content and advertisements. Cookies can be categorized into various types, including Essential, Performance, Functionality, and targeting cookies, each serving different purposes in managing user consent and data privacy.
