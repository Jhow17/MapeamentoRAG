# Filtering the cookie consent records

You can use filters in the **Cookie Consent Dashboard** and **Cookie Consent Metrics** tabs to narrow down and analyze consent data based on specific attributes such as time period, consent status, location, device details, and more. Filters help you quickly focus on the consent records or metrics data most relevant to your audit, investigation, or reporting needs.

To view the filters, click the **+** icon near the upper left corner, as shown below. The filters panel opens, showing a searchable list of available filter properties.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Dashboard-filters.png)

> [!NOTE]
> Tip
> 
> You can apply multiple filters at the same time to further refine the results.

Use the following table to understand the filters available:

| Filter | Description |
| --- | --- |
| Country | Filters consent records by the country from which the consent interaction originated. |
| Consent Given Date | Filters records based on when consent was given. You can either select a predefined range such as the last 24 hours, 30 days, 6 months or 1 year, or choose a custom date range. |
| Consent Stored Date | Filters records based on when the consent record was stored in Securiti. This is useful when reviewing ingestion or processing timelines. |
| Consent Status | Filters records by consent outcome. Available values include **Granted**, **Declined**, **Withdrawn**, and **No Action**. For instance, you can filter only Withdrawn consents to investigate changes in user preferences. |
| Consent Captured On | Filters records by the source or method through which consent was captured. |
| Cookie Category | Filters records based on the cookie category involved, such as **Unclassified** or specific consent categories. |
| Device Type | Filters records based on the device used, such as desktop or mobile. |
| Domain URL | Filters records by the domain on which the cookie banner or preference center was displayed. You can match exact URLs or URLs that start with a specific value. |
| GPC | Filters records based on Global Privacy Control (GPC) signals. For instance, you can show only records where GPC was enabled. |
| Implicit Consent | Filters records based on whether consent was inferred implicitly. Available values are **Enabled** and **Disabled**. |
| IP Address | Filters records by the IP address of the data subject. You can include or exclude specific IPs. |
| Operating System | Filters records based on the operating system used by the visitor, such as Windows, macOS, or Linux. |
| Subject Identity | Filters records using the Subject Identity value associated with the consent event. This is useful when searching for a specific individual’s consent history. |
| User Agent | Filters records based on the user agent string. For instance, you can identify records generated by a specific browser or bot signature. |

## Applying and managing filters

When you apply one or more filters, the Cookie Consents table refreshes automatically to display only the records that match your selected criteria. To remove all active filters and return to the default view, from the upper right corner, click **Clear Search**.

To reuse a specific filter combination:

1. From the top right corner, click **Save View**, as shown below. ![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Click-Save-View.png)
2. From the **Save View** popup, enter the following details, as shown below:
  1. Group
  2. Name
  3. (Optional) Description ![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Save-View.png)
3. From the bottom of the popup, click **Save View** to save the filter configuration.
4. To reuse the saved filter combination later, click **Saved Views** and select the view you saved, as shown below. ![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2026-02-06 at 10.06.13 AM.png)

The Global Privacy Control (GPC) is a browser-based global opt-out tool that lets the Internet users signal their opt-out consent settings to websites, advertisers, and publishers on the world wide web. Some global privacy laws, such as the CPRA, require covered entities to mandatorily detect and honor users’ GPC signal. The Cookie Consent Management module lets you configure cookie banners and preference centers with GPC to ensure detection of the GPC signals on the web browsers of your data subjects to honor their opt-out cookie preferences
