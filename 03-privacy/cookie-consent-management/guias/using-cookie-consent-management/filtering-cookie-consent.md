# Filtering cookie consent records from the Legacy dashboard

You can use these filters on the Cookie Consent Legacy Dashboard to quickly focus your view of the current data based on various criteria. Where available, the filter tools are always located in the upper right corner of the page, as shown below.

![Screen_Shot_2022-09-27_at_1_08_54_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-82eb2a25-1e47-9cbe-c558-b6d227983a04.png)

You can save the filters once you apply them and later load them as described in [Using saved filters](/v1/docs/filtering-securiti-pages-and-dashboards-using-saved-filters).

## Cookie Consent Management filters

The following filters are available in the Cookie Consent Dashboard:

| Filter | Purpose |
| --- | --- |
| Subject Identity | Add the Subject Identity value in this filter from the Consent Records table, as shown below. ![Screen_Shot_2022-09-27_at_1_22_54_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-03d7f788-5b1d-17cb-7ad0-1bc300431842.png) |
| Location Code | You can use the Location Code filter by passing it the value given in the Location Code column of the Consent Records table, as shown below. ![Screen_Shot_2022-09-27_at_1_26_46_PM.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-949c5ce9-0ceb-3cfb-c29f-5f16d1a5f881.png) > [!NOTE] > **Note** > > Location Code is the URL of the website where the data subject gave their consent through the cookie consent banner. |
| Country | Select one or more country names from the menu. |
| Browser | Select one or more web browser names from the menu. This filter fetches consents that were recorded after **December 17, 2020 (UTC)**. |
| Global Privacy Control | Toggle on this switch to filter records of data subjects who gave consent via an enabled GPC signal from their web browsers. |
| Operating System | Select one or more operating systems from the menu. This filter fetches consents that were recorded after **December 17, 2020 (UTC)**. |
| User Agent | Filters consent records based on the name of the user agent. This filter fetches consents that were recorded before **December 17, 2020 (UTC)**. |
| Device Type | Select one or more device types from the menu. |

For more information, see [Filtering Securiti pages and dashboards](/v1/docs/filtering-securiti-pages-and-dashboards).

The Global Privacy Control (GPC) is a browser-based global opt-out tool that lets the Internet users signal their opt-out consent settings to websites, advertisers, and publishers on the world wide web. Some global privacy laws, such as the CPRA, require covered entities to mandatorily detect and honor users’ GPC signal. The Cookie Consent Management module lets you configure cookie banners and preference centers with GPC to ensure detection of the GPC signals on the web browsers of your data subjects to honor their opt-out cookie preferences
