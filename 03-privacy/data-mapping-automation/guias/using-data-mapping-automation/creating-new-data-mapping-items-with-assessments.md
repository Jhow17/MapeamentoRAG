# Creating new data mapping items with assessments

You can use assessments to quickly create new data mapping items by collecting the necessary information from those who know the most about the item in question. When the assessment owner publishes the assessment, Securiti creates a new data mapping item based on the information collected in the assessment.

1. In Securiti, open Assessment Automation, then choose Assessments > Templates.
2. On the Assessment Templates page, find the template category "Data Maps," and within it find the template that best matches the type of data mapping item you want to create.
3. On the card for the template, choose **Options > Start an Assessment**.
4. On the Select / Add New [item type] popup, mark the radio button for **Add New**, then click **Create**.
5. Use the Assessment Owners & Collaborators popup to choose owners and collaborators, then click **Done**.

Securiti creates the new assessment and alerts the owner, who can then proceed to conduct the assessment.

When the assessment owner publishes the assessment, Securiti creates a new data mapping item based on the information collected in the assessment.

See the [Assessment Automation help center](/v1/docs/assessment-v2) for more information about starting and conducting assessments.

Assessments answer different questions related to an entity, such as purpose, etc. Also, with each assessment, you can associate risks.
