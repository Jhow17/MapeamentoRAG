# Editing basic attributes for multiple catalog items

You can select multiple data mapping items of the same definition type and apply the same update to basic attributes for all selected items:

1. In Securiti, open **Data Mapping Automation** then click the **Catalog** menu and choose the type of assets you want to edit.
2. Near the upper right corner of the page, click **Filters** and apply a Definition Type filter.
3. On the filtered list of catalog items, mark the checkboxes at the left edge of one or more items, then click the **Edit** button (pencil icon) just to the right of the search box.
4. Use the Quick Edit popup to make the change to the items as shown below, then click **Update**.
