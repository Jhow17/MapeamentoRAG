# Collaborating using process message channels

Each Process has its own messaging channel. When you are working on a process, you can use the channel to collaborate with process owners and other Securiti users in your organization to build the process.

Initially, only the process owners are on the channel. They can add other Securiti users by including @ references to them in channel messages. Once added to the channel, those users can send messages to the channel, and also add other users.

To use the message channel:

1. In Securiti, open the process.
2. Near the upper right corner of the page, click **Messages** as shown below.

![DMA_process_message1.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-875fa760-2bd9-4909-8eba-a5ff85c5c6a7.png)

Securiti opens the Messages side panel.
3. Use the tools on the message panel to collaborate with your colleagues as shown below.

![DMA_process_message2.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-5c0e5fd2-02ef-c544-03f4-c7914a2cb461.png)

Messages appear on the Conversations panel of each Securiti user on the channel.

> [!NOTE]
> **Note**
> 
> - By default, owners and co-owners of the corresponding process can message each other in the messaging panel.
> - Commenting @ non-co-owners within your organization automatically adds them to the messaging channel.
> - Non-co-owners who you add to the channel can respond in the messaging panel, and can view but not edit the data map.
> - When you comment @ a Securiti user, they receive an email.

A process defines the flow of data between entities and processes.
