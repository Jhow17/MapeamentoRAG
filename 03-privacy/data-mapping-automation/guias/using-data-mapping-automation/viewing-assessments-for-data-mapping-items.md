# Viewing assessments for data mapping items

#### Viewing assessments for data mapping items

To view all Data Maps assessments that you used to create or enrich data mapping items with information from the assessment responses:

- In Securiti, open **Data Mapping Automation** and choose **Data Mapping > Assessments**.

Securiti opens the Internal Assessments module, and filters it for assessments in the category Data Maps.
