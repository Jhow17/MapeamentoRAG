# Configuring attribute properties for data elements

You can configure attribute properties for the data elements for an asset, and also for those of data subjects and data sets for an asset. The available properties come from the catalog definitions for the template used to create and maintain the catalog item.

1. In Securiti, choose **Data Mapping > Catalog > Assets**, then click the entry for an asset.
2. On the Asset Details tab, near the upper right corner of the page click **Edit**, then scroll down to the Data Elements and Types area.
3. Enable the toggle for **Edit Attribute Properties**, mark the data elements or data element types you want to configure properties for, then click **Edit [x] Selected Element Types**.
4. Use the Editing Properties For... side panel to edit properties for the selected elements or element types as shown below.

![RN_element_properties.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-376879e9-2520-0c30-8b88-9215754fd30a.png)
5. After editing properties for each marked item, at the bottom of the side panel click **Save**, then page forward to the next to edit it in the same manner.

An asset records data for any application or store. You can use It to record an asset's name, description, purpose, etc. Also, you can use an asset in processes.
