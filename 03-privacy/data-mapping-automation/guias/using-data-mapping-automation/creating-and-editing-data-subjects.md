# Creating and editing data subjects

To create a new data subject:

1. If you haven't already done so, open the asset for which you want to create a data set. See [Creating and editing data assets](/v1/docs/creating-and-editing-data-assets) for more information.
2. If you haven't already, near the upper right corner of the page click **Edit**.
3. Expand the Data Sets area and click **Add Data Subjects**.

To edit a new or existing data subject:

1. If you haven't already, open the asset, click **Edit**, and expand the Data Subjects area.
2. Next to the data subject name, click **Edit** (pencil icon) and edit the data set name so that it indicates the function of the data subject. The default name is a set of random characters. Click the checkmark when you are done.
3. Click the data subject name to expand the data set.
4. Apply the following settings (may vary):

| Volume | Enter a value for the total volume of data subjects. |
| --- | --- |
| Type | Enter the type of data subject to which the information applies. |

> [!NOTE]
> **Note**
> 
> The actual settings available is determined by the reference lists used by the template you chose when creating the asset. See [Creating and customizing Data Mapping Automation reference lists](/v1/docs/creating-and-customizing-data-mapping-automation-reference-lists) for more information.
5. Click **Add Data Elements or Types** and choose from among the data elements and types on the data system those that apply to the data subject.

The types and elements available are limited to those you configured for the data system when you added it to the catalog.
6. (Optional) Configure data element attribute properties as described in [Configuring attribute properties for data elements](/v1/docs/configuring-attribute-properties-for-data-elements).
7. When you are done adding data elements and types, click **Update**.
8. When you are done, check to make sure the **Save** button near the upper right corner of the page is disabled, showing you that Securiti has already autosaved your changes. If the button is active, click it to manually save your changes.
