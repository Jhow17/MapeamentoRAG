# Data Mapping Automation API reference

The Data Mapping Automation API documentation lets you manage data catalog items including assets, processes, vendors, and institutions, associate data mapping entities with assessments, and generate RoPA reports for regulatory compliance.

This API documentation includes operations such as:

- Create, update, and retrieve data catalog items (assets, processes, vendors, institutions)
- Associate data mapping entities with assessments for enrichment
- Initiate data maps assessments to identify risks linked to catalog items
- Export RoPA reports for GDPR Article 30 and similar regulations

Use the Data Mapping Automation [REST API documentation](https://securiti-doc-router.securiti.ai/modules/data-mapping-automation/apidocs/index.html) to explore and test Data Mapping Automation APIs, review HTTP endpoints, JSON request and response formats, query parameters, API schemas, authentication methods, and sample API requests, and access the Postman collection for data mapping operations.
