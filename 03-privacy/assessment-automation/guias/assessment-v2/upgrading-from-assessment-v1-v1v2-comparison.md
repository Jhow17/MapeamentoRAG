# Upgrading from Assessment V1 (V1/V2 Comparison)

The following serves as a comparison document for both assessment versions.

| Before (V1) | After (V2) |
| --- | --- |
| - Collaborator/Owner Assignments - Domain restrictions on guest users | - Respondent/Reviewer/Viewer Assignments - No domain restriction on guest invites |
| - Continual submission/submit per question - Submission Progress based on user submission | - Assessment Stages - Dynamic Response Progress based on answers to questions - One-time submit/review |
| - Question Flags - Reject Questions - Individual emails notifications per change | - Need more info flags w/ ability to jump to flags - Send back assessment for more info - Consolidated email notifications |
| - No default reviewers/due date/reminders - No custom invite templates | - Default reviewers/due date/reminders - Default custom invite templates |
| - Re-assessments create new version ins same assessment - Unable to extract data from older versions | - Re-assessments created a distinct assessment - Different versions can be exported - Ability to view linked assessments |
| - V1 APIs | - V2 APIs - V1 API Support through June 2026 |

For more information, see [Understanding assignment in Reviewer Respondent](/v1/docs/understanding-assignment-in-reviewer-respondent) on role mapping and Data Conversion in Assessment V2.
