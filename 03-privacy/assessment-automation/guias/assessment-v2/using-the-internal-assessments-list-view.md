# Using the Assessments list view

To get started, from the Securiti tile, select **Assessment Automation.**

1. On the following page, Securiti shows you the Assessments list view.
2. Near the upper right corner of the page, click **+ Launch Assessment** to launch a new assessment.

See [Launching a new assessment](/latest/docs/launching-a-new-assessment-in-securiti) in Securiti for more information.
3. Also, the page shows you options to configure filters and create saved views. See [Assessments list Filter panel and Saved Views](/v1/docs/assessments-list-filter-panel-and-saved-views) for more information.

### Deleting assessment

To delete an assessment.
  1. ID
  2. Assessment Title
  3. Stage

The stage (In Review, Complete) on hover reveals the following information:
    - **Stage type -** The default assessment stages such as In Progress, In Review, Canceled, etc.
    - **Stage -** The stage label you've configured in [Workflow Settings](/v1/docs/configuring-workflow-settings-custom-stages-in-assessments).
  4. Reason
  5. Associated Workflow

The Associated Workflow comprises of two workflows:
    - **Base Workflow -** Default workflow for most users.
    - **Two Step Review Workflow -** When Custom Workflow Stages is enabled.
  6. Related Object Type
  7. Submission %
  8. Review %
  9. Due Date
  10. Reviewers
  11. Respondents
  12. Completion Date
  13. Assessment Version
  14. Managing Organization

*Scroll right to view all available columns*.
  1. In the right most corner, click the **Column Selector** icon.
  2. Mark or clear the checkbox for items such as Published Date, Due Date, Inherent Risk Level/Score, Residual Risk Level/Score, Risk Rating, Reassessment Date, Associated Template, and so on.

Click **Apply** to update the view.
  3. To reset, click **Restore Defaults**.
  4. Use drag and drop to reorder columns if you want. For example, if you want the Assessment Title to show before ID column.
  1. From the assessment options menu, select **Linked Objects**, then click **Linked New Objects**.

  2. On the Link New Object popup, mark the checkbox for different object items.

Once done, click **Link Objects** or **Clear Selections** to reset
  1. From the assessment options menu, select **Delete Assessment**.
  2. On the Delete Privacy Assessment popup, click **Delete Assessment** or **Never Mind** to cancel deletion.

> [!WARNING]
> Important
> 
> You can perform object linking or assessment deletion for assessments you own. Deleting an assessment is irreversible so only proceed when you’re sure.
