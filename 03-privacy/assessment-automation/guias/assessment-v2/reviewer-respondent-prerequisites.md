# Reviewer Respondent prerequisites

To conduct an assessment, a reviewer or respondent's role must be eligible for that assignment, and the person must have access to the assessment organization.

## Reviewer eligibility

| Role | Can be reviewer |
| --- | --- |
| Super Admin | Yes |
| Org Admin | Yes |
| Operator | Yes |
| DPO | Yes |
| Module Owner | Yes |
| User | Yes |
| Guest User | No |

A custom role with Review Assessment and Update Assigned Assessment is also eligible as a reviewer to review and edit the assessment once assigned.

## Respondent eligibility

| Role | Can be respondent |
| --- | --- |
| Super Admin | Yes |
| Org Admin | Yes |
| Operator | Yes |
| DPO | Yes |
| Module Owner | Yes |
| User | Yes |
| Guest User | Yes |

A custom role with Read Assigned Assessment is eligible to be a respondent. That custom role also needs Update Assigned Assessment to edit the assessment once assigned.

Users without access to the current organization aren't eligible for either role, regardless of their role type.
