# Editing system reference lists

### Prerequisites

You must have one or more of the following roles and have access to the assessment organization to edit assessment automation reference lists.

- Operator
- Super admin
- Module owner
- Assessment owner or question owner

See the user roles and permissions [topic](/v1/docs/understanding-user-roles-and-permissions-before-conducting-assessments) for more information.

You use reference lists to define the available choices for fields such as **Managing Organization** on an assessment. Unlike reference lists for other Securiti modules, you can only edit existing reference lists, you cannot create new reference lists or delete existing ones.

(Optional) You can also configure Multi-Org Units to edit Reference Lists for different organizations. Once you have it enabled for your tenant, in the left sidebar, click your user to select or deselect the organizations you want to include or exclude for your tenant. Now, before you can edit reference lists, under Sections, choose your organization from the Organization menu.

> [!NOTE]
> **Note**
> 
> Multi-Org is a premium feature that is available by subscription. Contact [support@securiti.ai](mailto:support@securiti.ai) to enable it for your Securiti tenant.

To edit an assessment automation reference list:

1. In Securiti, open Assessment Automation and choose **Settings > Reference Lists**.
2. In the left panel, click the section containing the reference list you want to view.

Currently, there is only one section list, **General**.
3. In the list of reference lists for the section, find the reference list and choose **Options** (three dots) **> Edit**.
4. Use the tools on the **Edit Reference List** page to customize the reference list to suit.
  - Use the toggle on the left side of each item to activate or deactivate it.
  - Use the **Delete** (trash can) tool at the right end of an item to remove it from the list.
  - Use the **Add item** text filed at the bottom of the list to add a new item by typing it name.
5. Near the upper right corner of the page, click **Save**.

To edit a risk reference list:

1. In Securiti, open Risk Register and choose **Settings > Reference List**.
2. In the left panel, click the section containing the reference list you want to view.
3. In the list of reference lists for the section, find the reference list and choose **Options** (three dots) **> Edit**.
4. Use the tools on the **Edit Reference List** page to customize the reference list to suit.
  - Use the toggle on the left side of each item to activate or deactivate it.
  - Use the **Delete** (trash can) tool at the right end of an item to remove it from the list.
  - Use the **Add item** text filed at the bottom of the list to add a new item by typing it name.
