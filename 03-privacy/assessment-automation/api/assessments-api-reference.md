# Assessments API reference

The Assessment Automation API documentation lets you create and manage assessments, retrieve assessment details by ID or Data Map entity ID, list assessments by date range, and integrate assessment workflows with your preferred platform.

This API documentation includes operations such as:

- Create internal and vendor assessments
- Retrieve assessments by Assessment ID or Data Map entity ID
- List assessments within a specified date range
- Execute API requests directly from the interactive documentation

Use the Assessment Automation [REST API documentation](https://securiti-doc-router.securiti.ai/modules/internal-assessments/apidocs/index.html) to explore and test Assessment Automation APIs, review HTTP endpoints, JSON request and response formats, query parameters, API schemas, authentication methods, and sample API requests, and access the Postman collection for assessment management operations.
