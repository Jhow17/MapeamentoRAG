# Managing tests

### Editing tests

To edit a test:

1. On the **Tests** list, locate the card for the test you want to edit.
2. At the right end of the card, choose **Options** (three dots) **> Edit**.
3. Update the required details and click **Update Test**.

### Deleting tests

To delete a test:

1. On the Tests list, locate the card for the test you want to delete.
2. At the right end of the card, choose **Options** (three dots) **> Delete**.

Securiti opens a confirmation box.
3. Click **Delete Test** to confirm deletion.

> [!NOTE]
> **Note**
> 
> You can only edit or delete custom tests, but you cannot edit or delete the system tests within the module.

### Disabling tests

To disable a test:

1. On the Tests list, locate the card for the test you want to disable.
2. To disable a test, click the toggle button to the left side of the test.
