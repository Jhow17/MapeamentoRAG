# Filtering the projects list

Using the projects list filter, you can select various filter options to specify the criteria by which you want to filter the projects. Clicking any of the filter options opens its respective menu, displaying a list of values that you can choose from. Once the filter is applied, the list updates to display only the projects that meet the specified criteria.

![FIltering_Projects.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-a582447e-acb1-201f-4020-37de209eb276.png)

- The **Active** menu lets you sort the projects in the list based on the current status, which can be set to active (true) or inactive (false).
- The **Frameworks** menu lets you filter the projects related to a specific framework.
- You can also filter the projects based on the email address of the project **Owner**.
- The **Tags** menu lets you filter projects based on keywords or phrases for tags.
