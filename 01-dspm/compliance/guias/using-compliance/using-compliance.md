# Using Compliance

With the advancement of data growth at an exponential rate, organizations must ensure data security and compliance to regional and global standards. Organizations must establish data policy controls and mechanisms to support governance frameworks to ensure safe, effective and responsible use of data.

The security and compliance status of an organization also plays a major factor in its expansion to different regions and geographies. Due to various frameworks and standards established for different regions, organizations must ensure they comply with and follow the respective standards for data security and compliance. Without the right approach, organizations may risk being vulnerable to data breaches, regulatory non-compliance, and reputation and brand damage.

The Compliance module is a complete solution to help your organization stay compliant, secure and demonstrate trust to your Data subjects. This helps you enhance trust management through one platform instead of achieving your security and trust management objectives from multiple sources.

Securiti’s Compliance module lets you achieve this through projects that let you implement initiatives for specific security and compliance objectives. One of the key features of this module is the set of preloaded frameworks. These frameworks come with built-in controls to evaluate compliance of global frameworks such as GDPR, ISO, HIPAA, etc.

Through the projects, you can use these preloaded frameworks or create new ones for a more refined approach to compliance to these frameworks and standards.

Securiti’s Compliance module, lets you stay on top of your security management program from a single pane of glass by establishing and documenting controls applicable to data assets and processes, and providing remediations to mitigate risks. To evaluate these controls, the compliance module makes use of the transaction data and metadata captured through various modules. This data is received from multiple data systems and plays a key factor in achieving compliance and reducing risk.

### Prerequisites

Relevant [cloud environments](/v1/docs/getting-started-with-iaas-cloud) and data systems must be connected—and scanned if necessary—to evaluate controls defined within the intended compliance frameworks.

### Compliance key features

The Compliance module comes with the following key features:

| Feature | Description |
| --- | --- |
| Built-in data security and compliance standards | Lets you stay informed about continually evolving global standards and frameworks, preloaded with the tenant. |
| Monitor average Compliance Posture | Using the main dashboard, you can get insight into your average compliance posture of your projects containing preloaded or customized frameworks. |
| Organize initiatives through projects | You can achieve specific compliance objectives with customized projects organized into frameworks, categories and subcategories. |
| Evaluate controls to measure compliance status | Ensures timely information on vulnerabilities relevant to non-compliance and potential threats to sensitive data breach with manual and automated test evaluation. |
