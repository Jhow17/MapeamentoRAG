# Creating a new Framework

A framework is a collection of controls used to verify compliance across data systems. During the tenant initialization process, our system automatically loads pre-defined compliance frameworks along with categories, subcategories, and controls. However, you can also add custom frameworks that are tailored to the specific needs and requirements of your organization.

To add a new framework:

1. In Securiti, open **Compliance**, and click **Frameworks > Compliance Frameworks**.
2. At the upper right corner of the Framework dashboard, choose **Create > New Framework.**
3. Enter the **Framework Name** and **Description**. Further, select the **Categories** and **Domains** that you need to add to the framework and click **Create Framework**.

![Frameworks_-_Create_new_framework.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-db9e2fa7-5682-c88b-bdb3-a19c10d5301f.png)

### Enabling a framework

You can enable or disable frameworks based on the needs of your organization.

- On the Frameworks list, click **Option**(3 dots) next to the framework name and select **Enable**.

![Frameworks_enable.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-56d23828-22dc-5c42-8657-249364f42ef0.png)

> [!NOTE]
> **Note**
> 
> The system displays the disabled frameworks in grayed-out or inactive form.

### Edit a framework

You can also edit framework details such as name and description.

1. On the Frameworks list, click **Option**(3 dots) next to the framework name and select **Edit**.
2. Update the framework **Name, Description** and click **Update Framework**.

![Custom_frameworks_Edit.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-01ca3349-1b24-366d-a63e-da117d21ff31.png)

Similarly, to delete a framework, next to the framework choose **Option** (3 dots) **> Delete**.

![Custom_frameworks_Delete.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-3e573d7e-78d6-d05a-4c4d-56b066af3936.png)

> [!NOTE]
> **Note**
> 
> You can edit or delete custom frameworks, but you cannot edit or delete the system frameworks.
