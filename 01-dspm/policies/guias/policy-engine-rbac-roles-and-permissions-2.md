# Policy Engine RBAC Roles and Permissions

## Overview

The new Role-Based Access Control (RBAC) framework provides fine-grained permissions for Policy Engine. It introduces a set of system-generated roles with predefined permissions, while also allowing you to create custom roles with data system-specific permissions. Custom roles can include permissions that are linked to other related permissions, creating dependencies and ensuring consistent access control. In contrast, system-generated roles automatically inherit the specific permissions defined for them.

### Accessing Policy Engine permissions

To navigate to Policy Engine RBAC permissions in ​Securiti, follow the steps provided below:

1. From the upper left corner of the left navigation bar, click the ​**Jewel**​ icon, and choose ​**Settings**​​ from the left navigation bar, as shown below. ![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-X86NTAFD.png)
2. Under the **​Organizational**​, choose ​**Access Management** > **Roles**​, as shown below. ![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-CVRJYLIO.png)
3. On the ​**Roles**​ page, select ​**+ Create Role​**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-JRNP41Q2.png)
4. Under the ​**Permissions**​ section, click the ​**Policy Engine** tab to access the permissions, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-ULBXBVTR.png)

### Policy Engine permissions with custom roles

Securiti lets you select fine-grained permissions for each custom role you create in the Platform.

**Permission:** It is a parent permission that grants specific rights to perform certain actions within the system. For example, `View Policies` , `Manage Policies`, and `View Policy Findings`.

**Explanation:** Describes why the permission is needed and the context in which it is used. For example, Create and Activate Data System permission is required to create a data system and activate its connector.

**Dependent permissions:** These are a set of permissions that are automatically applied in the same or different modules when a parent permission is selected.
