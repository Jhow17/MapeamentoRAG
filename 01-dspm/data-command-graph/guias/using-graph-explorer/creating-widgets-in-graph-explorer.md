# Creating widgets in Graph Explorer

You can save your queries or filters in the Graph Explorer as widgets to create custom reports in the Graph Reporting Dashboards. For more information, see [Using Graph Reporting Dashboards](/v1/docs/using-graph-reporting-dashboards).

To create a widget for your filter.

1. Apply a filter by selecting entities of your choice. For more information, see [Applying filters](/v1/docs/managing-queries-in-the-graph-explorer).
2. On the upper right corner of the page, click **Create Widget**.

![Graph Explorer interface displaying security posture findings and asset rules for AWS Cloud.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Create widget_Graph Explorer.png)
3. On the **Widgets** popup, select the widget you want to create for your metadata.

The following widgets are supported for displaying your metadata.
  - Metric widgets
  - Grid widgets
  - Map widgets (Region)
4. The selected widget appears in the **Widget Name** field in the popup.
5. Next, select the dashboard and dashboard group you want to create widgets in. You can also create a new dashboard and group.
6. Click **Add Widget** to add your widgets to the dashboard.

![Security posture finding grid displaying rules, asset types, and severity levels for AWS resources.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Add Widget options_Graph Explorer.png)
7. Adding widgets to the dashboard displays a success message on the screen, as shown below. Click **View Dashboard** in the message to view your dashboards and the added widgets.

![Dashboard showing successful widget addition and security posture findings in AWS Cloud.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Successful widget creation popup_Graph Explorer.png)

![Dashboard displaying security findings, asset posture scores, and data posture scores overview.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Widgets dashboard_Graoh Explorer.png)

For more information, see [Using Graph Reporting dashboard](/latest/docs/using-graph-reporting-dashboards)
