# Using Securiti Graph Query Agent

**Scenario**

As a **Data Security Officer**, you need to investigate and report on critical findings. Manually building a specific query and then creating a separate dashboard is inefficient.

Now, you can ask the Securiti Graph Query Agent to "create a query for data systems with findings," streamlining the entire workflow from investigation to query building.

## Overview

The Securiti Graph Query Agent is an intelligent AI assistant designed to help you build, understand, and explore your data landscape within the Data Command Graph. It lets you interact with the graph using simple and natural language prompts, removing the need to be an expert in graph query syntax.

> [!WARNING]
> Important
> 
> - If the AI Agents feature is not available in your tenant, contact your Customer Success Manager or Account Representative to confirm whether it is included in your plan and whether your tenant meets the eligibility requirements for its activation.
> - By default, AI Agents use Securiti’s built-in Large Language Model (LLM) Provider with the following daily usage limits:
> 
> To avoid these limitations, you can also configure your LLM provider. For more information on configuring these limits, contact [support@securiti.ai](mailto:support@securiti.ai).
>   - Per User Limit: 100 requests per day
>   - Per Tenant Limit: 1000 requests per day

Key capabilities include:

- Building simple and complex graph queries
- Generating JSON for queries
- Understanding query structure, purpose, and use cases
- Modifying a query

## Using the Graph Query AI Agent

> [!CAUTION]
> Warning
> 
> - Queries generated by AI agents are non-deterministic and may produce varying results. We recommend that you review and validate each generated query to confirm it accurately reflects the intended scenario and scope.
> - The responses provided by this AI agent are for informational purposes only and do not constitute professional or legal advice. Securiti disclaims any liability for errors, omissions, or decisions made based on these responses.

To use the Securiti Graph Query Agent:

1. On the Graph Explorer page, from the left navigation bar or from the upper left corner of the top-level filter, click the AI Assistant icon, as shown below.

![Graph Explorer interface showing options to add filters and begin search.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/graphagent_aiicon.png)
2. In the chat interface, enter your prompt to create a query, as shown below.

![Graph Explorer interface displaying AWS data systems and query creation options.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/graphagent_createquery.png)
3. Click **Run Query** to execute it, as shown below.

![Graph Explorer displaying AWS data systems with query creation options and results overview.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/graphagent_runquery.png)

Use the following table to understand some common scenarios and their prompts to help you get started with the Securiti Graph Query Agent:

| Example | Prompt |
| --- | --- |
| Create a new query for listing AWS data systems | Describe your requirements for the widget in the prompt, as shown below. “Create a query for AWS data systems” ![Graph Explorer interface displaying AWS data systems and query creation options.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/graphagent_createquery(1).png) |

A graph query is a request or command issued to a database, seeking specific information or action. In the context of databases, a query is typically expressed in a structured query language (SQL) or other query languages, and it consists of instructions that define the criteria for selecting, updating, or manipulating data within the database.
