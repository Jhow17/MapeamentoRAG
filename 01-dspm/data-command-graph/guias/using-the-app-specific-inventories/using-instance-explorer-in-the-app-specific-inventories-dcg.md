# Using Instance Explorer in the app-specific inventories (DCG)

In the grid view, you can display details about a particular instance of an entity and all of the related objects using the instance explorer widget. To do so, simply click on the instance you want to visualize from the grid panel. The instance name and ID are shown in the upper left corner of the instance explorer panel.

There are two major components of the instance explorer:

1. A graphical representation of relationship nodes and their counts, as shown below.

![ge_instinspect_graph.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-f6ed5d11-e436-67a3-b2b3-8c5bcd7d66e5(1).png)
2. Table showing all instances of each related node along with their respective counts, as shown below.
