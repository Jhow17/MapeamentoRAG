# Using Inventory

Securiti's Inventory is built upon the Data Command Graph (DCG) technology to provide access to entities and data across all modules. The Inventory provides a platform-wide access to entities and their related data. It lets you browse and navigate through nodes belonging to your modules without accessing the modules separately.

The inventory page offers a complete view of each collected data system, cloud service, File, Table, Column, and any other supported object type that has been ingested into the Data Command Graph.

> [!NOTE]
> **Note**
> 
> The Inventory page supports single-entity property filters; you cannot build relationship-based queries on this page.

Inventory also lets you inspect data and relationships associated with it in a grid view.

The following are some example use cases for Securiti's Inventory:

- How many IaaS cloud accounts and Files are associated with a data system?
- What and how many regions are associated with a data system account?

To access the Inventory.

- On the **New Navigation** sidebar, choose **Inventory**, as shown below.
