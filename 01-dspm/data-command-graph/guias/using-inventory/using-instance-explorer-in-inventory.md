# Using Instance Explorer in Inventory

In the grid view, you can display details about a particular instance of an entity and all of the related objects using the Instance Explorer. To do so, simply click on the instance you want to visualize from the grid panel. The instance name and ID are shown in the upper left corner of the instance explorer panel.

> [!NOTE]
> **Note**
> 
> The Instance Explorer for the Inventory page can be accessed directly using a saved weblink or URL. If you have the URL saved, click it to open the Instance Explorer screen directly for your instance, such as an AI model.

To gain instance-level insights for any entity in Inventory.

1. Click on the instance you want to visualize from the Inventory grid.
2. The **metadata explorer** opens, which provides metadata for your instance. You can view important metadata fields in the modal or open the instance explorer for your instance. Near the top of the metadata explorer, click **Explore**.

![Overview of cloud services with asset details and filtering options displayed on the interface.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Explore Inventory instance.png)
3. The Instance Explorer widget opens where the instance name is shown at the upper left corner.

There are two major components of the instance explorer:
  - A graphical representation of relationship nodes and their counts, as shown below.

![Overview of Workday Policy Connector with related cloud services and properties listed.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Graph View_Inventory.png)
  - Table showing all instances of each related node along with their respective counts, as shown below.
