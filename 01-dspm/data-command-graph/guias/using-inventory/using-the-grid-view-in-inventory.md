# Using the grid view in Inventory

The inventory displays all the filters in a grid view. The grid view of the inventory contains three main components:

- Left sidebar displaying the list of all entities
- Grid on the right side of the page, displaying all instances of a selected entity

The grid on the right displays all instances of an entity. Clicking an entity on the left side displays all instances of that entity on the grid.

![Overview of cloud services with asset names and types listed in an inventory format.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Cloud Service Display_Graph Explorer(1).png)

### Updating filters from grid

Securiti lets you update filters by using the grid, as described below.

- From the left sidebar, select any entity.
- Apply the increment (+ icon) or decrement (- icon) operator to add the entity and attribute as an include or exclude rule to the page filter.
- The added filter appears in the top row of the dashboard with the rest of the filters.

![Cloud service inventory showing filters and asset types with counts for each category.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Adding Filters_Inventory.png)

### Customize grid view

You can customize the grid layout according to your preferences. You can select the columns you want to see and rearrange them by dragging and dropping.

> [!NOTE]
> **Note**
> 
> Securiti automatically saves your layout changes in your profile and eliminates the need for you to readjust the layout every time you visit the page.

To modify the grid layout:

1. On the grid view, near the upper right corner of the grid panel, click **reorder** (window icon).
2. Select columns from the list that you want to display in the table and click **Apply**.
3. You can also resize the columns according to your preference. To resize the columns.
  1. Hover your cursor on the column boundary till it transforms into a resize icon.
  2. Click and drag the boundary to the left or right to adjust the column width according to your preference.
  3. Release the mouse once you have reached your desired width, and the columns will resize accordingly.

> [!NOTE]
> **Note**
> 
> Click **Restore Default** to revert the grid layout to its default view whenever needed.
