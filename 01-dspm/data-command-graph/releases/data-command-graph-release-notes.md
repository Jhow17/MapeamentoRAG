## 1.149

### Release updates - August 2026

#### Resolved issue

- Fixed an issue where filtering by **Securiti Tags** in Graph Explorer and Inventory could return duplicate tag values in the filter list or incomplete query results. Tag filter operators, including **Is one of**, **Is not one of**, **Is equal to**, **Is not equal to**, **Is empty**, and **Is not empty**, now return accurate and consistent results (PRIV-252012).
