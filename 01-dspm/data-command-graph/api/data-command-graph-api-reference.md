# Data Command Graph API reference

The Data Command Graph APIs let you programmatically query and traverse graph data across your connected data systems in Securiti. Use these APIs to create queries, fetch entity connections, filter graph data, and retrieve table structures.

With the Data Command Graph APIs, you can:

- Traverse entity connections and relationships across your data systems
- Fetch all tables and table structures using URN-based or standard traversals
- Create graph filters and queries using graph explorer operations

Use the Data Command Graph APIs with Securiti's REST API endpoints, OAuth 2.0 authentication, and standard HTTP methods. See our [Data Command Graph API reference](https://securiti-doc-router.securiti.ai/modules/data-command-graph/apidocs/index.html) for granular request and response details of all available API calls.
