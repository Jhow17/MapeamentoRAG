# Hyperdrive Access Intelligence

## **Overview**

Activity Analysis in Hyperdrive provides visibility into how users, AI agents, Service Accounts and Applications interact with data across connected data systems. It analyzes activity logs from source systems to help you monitor actual data usage, identify over-provisioned access, and detect risks associated with sensitive data.

With Activity Analysis, you can identify dormant data, detect risky behavior, and ensure that user access remains aligned with actual usage patterns.

## **How Activity Analysis Works**

Activity Analysis collects user activity logs from connected data systems and correlates them with data inventory, access permissions, and sensitivity classifications to generate actionable insights.

### **Key Components**

- **Activity Logs** Captured from source systems and include events such as data access, modifications, queries, and user interactions.
- **Data Inventory** Provides metadata about data resources such as files, and sites.
- **Access and Entitlements** Defines which users, roles, or groups have access to data.
- **Sensitive Data Classification** Identifies regulated or sensitive data within resources.
