# Hyperdrive Access Intelligence for Microsoft 365 OneDrive

## Overview

Hyperdrive Access Intelligence for Microsoft 365 OneDrive gives you visibility into how files are used and who can access them in OneDrive for Business. It brings together two capabilities, Activity Analysis and Entitlement Scan, so you can monitor real user activity and understand access and ownership structures across your OneDrive environment.

## Access Intelligence capabilities

- **Activity Analysis** - Uses Microsoft 365 activity logs to show how users, applications, AI agents, and systems interact with files stored in OneDrive for Business, including file access, sharing actions, and modifications. For more information, see [Hyperdrive Activity Analysis for Microsoft 365 OneDrive](/latest/docs/activity-analysis-for-onedrive-1).
- **Entitlement Scan** - Maps access and ownership across OneDrive resources by capturing entities such as Microsoft 365 groups, users, AI agents, and Microsoft Entra ID applications, along with their relationships to OneDrive files and folders. For more information, see [Hyperdrive Entitlement Scan for Microsoft 365 OneDrive](/latest/docs/hyperdrive-entitlement-scan-for-microsoft-onedrive).

## Prerequisites

Before configuring Access Intelligence for Microsoft 365 OneDrive, ensure the [Microsoft 365 OneDrive (Hyperdrive)](/latest/docs/onedrive) connector is configured and synced in Hyperdrive.
