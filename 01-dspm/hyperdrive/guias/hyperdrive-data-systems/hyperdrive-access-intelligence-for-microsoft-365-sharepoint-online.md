# Hyperdrive Access Intelligence for Microsoft 365 SharePoint Online

## Overview

Hyperdrive Access Intelligence for Microsoft 365 SharePoint Online gives you visibility into how sites, documents, and files are used and who can access them within SharePoint. It brings together two capabilities, Activity Analysis and Entitlement Scan, so you can monitor real user activity and understand access and ownership structures across your SharePoint Online environment.

## Access Intelligence capabilities

- **Activity Analysis** - Uses Microsoft 365 activity logs to show how users, applications, AI agents, and systems interact with sites, documents, and files, including file access, sharing actions, permission changes, and collaboration events. For more information, see [Hyperdrive Activity Analysis for Microsoft SharePoint Online](/latest/docs/activity-analysis-for-microsoft-sharepoint).
- **Entitlement Scan** - Maps access and ownership across SharePoint Online resources by capturing entities such as SharePoint site groups, Microsoft 365 groups and users, AI agents, and Microsoft Entra ID applications, along with their relationships to SharePoint files and folders. For more information, see [Hyperdrive Entitlement Scan for Microsoft 365 SharePoint Online](/latest/docs/hyperdrive-entitlement-scan-for-m-sharepoint-online).

## Prerequisites

Before configuring Access Intelligence for Microsoft 365 SharePoint Online, ensure the [Microsoft 365 SharePoint Online](/latest/docs/sharepoint-online) connector is configured and synced in Hyperdrive.
