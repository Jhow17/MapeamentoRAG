# Hyperdrive Access Intelligence for Microsoft 365

## Overview

Hyperdrive Access Intelligence for Microsoft 365 gives you visibility into how data is used and who can access it across your Microsoft 365 environment. It brings together two capabilities, Activity Analysis and Entitlement Scan, so you can monitor real user activity and understand access and ownership structures across Outlook, OneDrive for Business, SharePoint Online, and Microsoft Teams.

You can configure both capabilities centrally for all supported Microsoft 365 connectors using the Microsoft 365 integration in Hyperdrive, or configure them individually for each connector based on your requirements.

## Access Intelligence capabilities

- **Activity Analysis** - Uses Microsoft Unified Activity Logs to show how users, applications, AI agents, and systems interact with Microsoft 365 data, including file access, sharing actions, mailbox operations, and collaboration events. For more information, see [Hyperdrive Activity Analysis for M365](/latest/docs/activity-analysis-for-microsoft365).
- **Entitlement Scan** - Maps access and ownership across Microsoft 365 resources by capturing entities such as Microsoft 365 users and groups, AI agents, and Microsoft Entra ID applications, along with their relationships to files, sites, and channels. For more information, see [Hyperdrive Entitlement Scan for M365](/latest/docs/hyperdrive-entitlement-scan-for-m365).
