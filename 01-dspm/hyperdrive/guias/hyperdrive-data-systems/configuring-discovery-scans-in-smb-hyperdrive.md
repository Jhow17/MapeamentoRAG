# Configuring discovery scans in SMB (Hyperdrive)

This section describes creating a Discovery scan for SMB.

Once you have completed the SMB connector authentication and scoping inventory sync is complete, you can create discovery scans for the SMB you used in the connector authentication.

## Prerequisites

1. Configure the classification types to let Securiti identify them be identified in discovery scans. For more information, see [Data classifications](/latest/docs/data-classifications).
2. Assign the required permissions as described in the [Prequisite section in SMB](/latest/docs/smb-1#prerequisites).

## Create a discovery scan

On the **Overview** page, scroll down to the Discovery Scan section, and click **Create Discovery Scan**.

It takes you to the Create Discovery scan page, where you can configure the scan scopes and unstructured scan settings.

- For more information on discovery scan, see [Configure discovery scans for SMB](/latest/docs/configuring-discovery-scans-in-smb).
- For more information about Securiti discovery scans, see [Understanding discovery scans](/v1/docs/discovery-scans).
