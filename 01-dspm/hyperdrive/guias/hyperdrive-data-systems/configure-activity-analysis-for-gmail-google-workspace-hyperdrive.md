# Configure Activity Analysis for Gmail (Google Workspace) (Hyperdrive)

This article covers the Activity Analysis configuration for the Gmail (Google Workspace) (Hyperdrive) connector.

## Prerequisites

Before configuring the Activity Analysis scan for Gmail (Google Workspace), complete the following prerequisites

1. [Assign the permissions and enable APIs for Activity Analysis](/latest/docs/assign-permissions-for-gmail-google-workspace-activity-analysis)
2. [Connecting the Gmail (Google Workspace) (self-hosted) with Securiti (Hyperdrive)](/latest/docs/new-ui-connecting-google-workspace-gmail-message-body-attachments-securiti)
3. [Configure Data Inventory Sync for Gmail (Google Workspace) (Hyperdrive)](/latest/docs/configure-data-inventory-sync-for-gmail-google-workspace-hyperdrive)
4. [Configure discovery scans in Gmail (Google Workspace) (self-hosted) (Hyperdrive)](/latest/docs/configure-discovery-scans-in-g-suite-gmail-message-body-attachments-1)

## Configure Activity Analysis

1. After activating your data system connector, under the **Configuration**, click **Activity Analysis**.
2. On the **Activity Analysis** page, mark the **Enable Activity Analysis** checkbox to include the data system in the activity analysis, and click **Save.**
3. Click **Start Sync** to start the activity analysis sync.

The Securiti will start the activity analysis scan for your data system, providing visibility into how users, AI agents, service accounts, and applications interact with data across connected data systems.

For more information, see [Viewing Activity Analysis results for Gmail (Google Workspace)](/latest/docs/hyperdrive-activity-analysis-for-gmail-google-workspace).
