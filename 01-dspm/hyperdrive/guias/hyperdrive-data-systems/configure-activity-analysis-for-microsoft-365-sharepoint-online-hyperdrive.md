# Configure Activity Analysis for Microsoft 365 SharePoint Online (Hyperdrive)

This article covers the Activity Analysis configuration for the Microsoft 365 SharePoint Online (hyperdrive) connector.

## Prerequisites

To use the Activity Analysis feature, you must allow the permissions. For more information, see [Microsoft 365 SharePoint Online](/latest/docs/microsoft-365-sharepoint-online-1).

## Configure Activity Analysis

1. After activating your data system connector, under the **Configuration**, click **Activity Analysis**.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2026-04-02 at 11.49.10.png)
2. On the **Activity Analysis** page, mark the **Enable Activity Analysis** checkbox to include the data system in the activity analysis, and click **Save.**

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2026-04-02 at 11.50.20.png)
3. Click **Start Sync** to start the activity analysis sync.

The Securiti will start the activity analysis scan for your data system, providing visibility into how users, AI agents, service accounts, and applications interact with data across connected data systems. For more information, see [Activity Analysis for Microsoft SharePoint Online](/latest/docs/activity-analysis-for-microsoft-sharepoint).
