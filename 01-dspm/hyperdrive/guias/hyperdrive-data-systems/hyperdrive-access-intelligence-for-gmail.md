# Hyperdrive Access Intelligence for Gmail

## Overview

Hyperdrive Access Intelligence for Gmail gives you visibility into how mail attachments are used and who can access them in your Gmail environment. It brings together two capabilities, Activity Analysis and Entitlement Scan, so you can monitor real user activity and understand access and ownership structures across Gmail.

## Access Intelligence capabilities

- **Activity Analysis** - Analyzes Gmail audit logs to show how users, applications, and automated services interact with email data, including message access, send actions, deletions, and label changes. For more information, see [Hyperdrive Activity Analysis for Gmail](/latest/docs/hyperdrive-activity-analysis-for-gmail-google-workspace).
- **Entitlement Scan** - Maps access and control across mail attachments by capturing which users and AI agents can access discovered mail files, and what sensitive data those files contain. For more information, see [Hyperdrive Entitlement Scan for Gmail](/latest/docs/hyperdrive-entitlement-scan-for-gmail).

## Prerequisites

Before configuring Access Intelligence for Gmail, ensure the [Gmail (Google Workspace)](/latest/docs/gmail-google-workspace-hyperdrive) connector is configured and synced in Hyperdrive.
