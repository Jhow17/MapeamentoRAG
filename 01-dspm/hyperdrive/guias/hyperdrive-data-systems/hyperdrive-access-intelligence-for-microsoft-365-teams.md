# Hyperdrive Access Intelligence for Microsoft 365 Teams

## Overview

Hyperdrive Access Intelligence for Microsoft 365 Teams gives you visibility into how collaboration and communication data is used and who can access it within Microsoft Teams. It brings together two capabilities, Activity Analysis and Entitlement Scan, so you can monitor real user activity and understand access and ownership structures across your Teams environment.

## Access Intelligence capabilities

- **Activity Analysis** - Uses Microsoft 365 activity logs to show how users, applications, AI agents, and systems interact across Teams communication and file collaboration workflows, including chat interactions, meetings, and file operations. For more information, see [Hyperdrive Activity Analysis for Microsoft Teams](/latest/docs/activity-analysis-for-microsoft-teams).
- **Entitlement Scan** - Maps access and ownership across Teams resources by capturing entities such as Microsoft 365 users, teams, channels, AI agents, and Microsoft Entra ID applications, along with their relationships to Microsoft Teams files and folders. For more information, see [Hyperdrive Entitlement Scan for Microsoft Teams](/latest/docs/hyperdrive-entitlement-scan-for-microsoft-teams).

## Prerequisites

Before configuring Access Intelligence for Microsoft Teams, ensure the [Microsoft Teams](/latest/docs/teams) connector is configured and synced in Hyperdrive.
