# Hyperdrive Access Intelligence for Microsoft 365 Outlook

## Overview

Hyperdrive Access Intelligence for Microsoft 365 Outlook gives you visibility into how mailbox data is used and who can access it within Exchange Online. It brings together two capabilities, Activity Analysis and Entitlement Scan, so you can monitor real user activity and understand access and ownership structures across your Outlook environment.

## Access Intelligence capabilities

- **Activity Analysis** - Uses Microsoft 365 activity logs to show how users, applications, AI agents, and systems interact with email data, including mailbox access, message operations, and administrative actions. For more information, see [Hyperdrive Activity Analysis for Microsoft Outlook](/latest/docs/activity-analysis-for-outlook).
- **Entitlement Scan** - Maps access and ownership across Outlook resources by capturing entities such as Microsoft 365 groups (including distribution lists), users, AI agents, and Microsoft Entra ID applications, along with their relationships to Outlook files and folders. For more information, see [Hyperdrive Entitlement Scan for Microsoft 365 Outlook](/latest/docs/hyperdrive-entitlement-scan-for-microsoft-365-outlook).

## Prerequisites

Before configuring Access Intelligence for Microsoft 365 Outlook, ensure the [Microsoft 365 Outlook](/latest/docs/outlook) connector is configured and synced in Hyperdrive.
