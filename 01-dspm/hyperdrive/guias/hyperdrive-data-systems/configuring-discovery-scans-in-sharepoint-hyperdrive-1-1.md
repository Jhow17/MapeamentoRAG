# Configuring Discovery scans in Teams (Hyperdrive)

This section describes creating a Discovery scan for Microsoft Teams. See [Understanding discovery scans](/v1/docs/discovery-scans) for more information about Securiti discovery scans.

Once you have completed the Microsoft Teams connector authentication and scoping inventory sync is complete, you can create discovery scans for the Microsoft Teams you used in the connector authentication.

## Prerequisite

1. Configure the classification types to let Securiti identify them in discovery scans. For more information, see [Data classifications](/latest/docs/data-classifications).
2. Allowlist the URLs for discovery scans specified in [Allowlisting URLs and APIs for Teams (Hyperdrive)](/latest/docs/allowlisting-urls-and-apis-for-outlook-hyperdrive-1).

## Create a discovery scan

On the **Overview** page, scroll down to the Discovery Scan section, and click **Create Discovery Scan**. ![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Teams DS(1).png)

It takes you to the Create Discovery scan page, where you can configure the scan scopes and unstructured scan settings.

For more information on discovery scan, see [configure Microsoft Teams discovery scans](/latest/docs/configure-microsoft-teams-discovery-scans).
