# Configuring discovery scans in Azure Blob Storage (Hyperdrive)

This section describes creating a Discovery scan for Amazon S3.

Once you have completed the Amazon S3 connector authentication and scoping inventory sync is complete, you can create discovery scans for the Amazon S3 you used in the connector authentication.

## Prerequisite

1. Configure the classification types to let Securiti identify them be identified in discovery scans. For more information, see [Data classifications](/latest/docs/data-classifications).
2. Assign the required permissions as described in the [Prequisite section in Azure Blob Storage](/latest/docs/azure-blob-storage-hyperdrive#prerequisites1).

## Create a discovery scan

On the **Overview** page, scroll down to the Discovery Scan section, and click **Create Discovery Scan**.

It takes you to the Create Discovery scan page, where you can configure the scan scopes and unstructured scan settings.

For more information on discovery scan, see [Configure discovery scans in Azure Blob Storage](/latest/docs/configuring-discovery-scans-in-azure-blob-storage).

For more information about Securiti discovery scans, see [Understanding discovery scans](/v1/docs/discovery-scans).
