# Configure discovery scans in NFS (Hyperdrive)

This section describes creating a Discovery scan for NFS

Once you have completed the NFS connector authentication and scoping inventory sync is complete, you can create discovery scans for the NFS you used in the connector authentication.

## Prerequisite

1. Configure the classification types to let Securiti identify them be identified in discovery scans. For more information, see [Data classifications](/latest/docs/data-classifications).
2. Assign the required permissions as described in the [Prequisite section in NFS](/latest/docs/nfs#prerequisites).

## Create a discovery scan

On the **Overview** page of your NFS data system instance, scroll down to the **Discovery Scan** section, and click **Create Discovery Scan**.

It takes you to the **Create Discovery** scan page, where you can configure the scan scopes and unstructured scan settings.

- For more information on NFS discovery scan, see [Configure discovery scans for NFS](/latest/docs/configure-discovery-scans-in-nfs).
- For more information about Securiti discovery scans, see [Understanding discovery scans](/v1/docs/discovery-scans).
