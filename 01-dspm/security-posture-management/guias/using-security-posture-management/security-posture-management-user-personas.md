# User Personas

Use the following table to understand the roles of different types of users and what they are responsible for in the Data Security Posture Management module. From the **Responsibilities** column, use the links of the relevant help topics to learn more about the responsibilities of the following roles.

| Role | Responsibilities |
| --- | --- |
| Cloud Security Engineer | - Schedule and initiate posture scans to identify misconfigurations and sensitive data exposure. - Monitor and review posture scan results to identify potential risks. |
| Security Analyst | - Analyze posture findings and alerts to identify potential security threats. - Share reports of their in-depth findings with the DevOps Engineer. |
| DevOps Engineer | - Configure Security Posture Management integration within the DevOps pipeline to ensure automatic posture scans. - Align [Security Posture Management](/latest/docs/using-security-posture-management) with the CI/CD pipeline for continuous security monitoring. - Define and configure automatic remediation for selective [Security posture rules](/latest/docs/test) within the DevOps pipeline. - Ensure the pipeline can automatically address identified *misconfigurations* |
| Compliance Manager | - Access the DSPM interface to [view posture findings and alerts](/latest/docs/configuring-security-posture-policies) and track compliance. - Review reports and work with application teams to remediate non-compliance. |
