# Security Posture Management API reference

The Security Posture Management API documentation lets you detect and manage security misconfigurations across your IaaS cloud accounts and SaaS data systems, configure and initiate posture scans, remediate misconfigurations, and manage posture findings and rules.

This API documentation includes operations such as:

- Fetch posture findings and their severity (open, fixed, and suppressed)
- Configure and initiate posture scans for IaaS and SaaS connectors
- Manage posture rules for cloud and SaaS data systems
- Suppress or unsuppress posture findings
- Export posture findings
- Remediate security misconfigurations (manual or automatic)

Use the Security Posture Management [REST API documentation](https://securiti-doc-router.securiti.ai/modules/security-posture-management/apidocs/index.html) to explore and test Security Posture Management APIs, review HTTP endpoints, JSON request and response formats, query parameters, API schemas, authentication methods, and sample API requests, and access the Postman collection.
