## 1.149

### Release updates - August 2026

#### Expanding posture scan support for OCI

Securiti has expanded posture scan support to include OCI Datascience Model, helping strengthening the posture of your cloud environment. You can now run a posture scan on OCI Datascience Model assets to evaluate posture misconfigurations.

For more information, see [List of Supported Cloud Native Services](/latest/docs/data-security-posture-management#supported-oci-cloud-native-services).

#### Introducing new compliance tests for Amazon Aurora DSQL

Securiti now lets you reduce risk exposure across your cloud environment with new graph-based compliance tests for Amazon Web Services (AWS). These tests enforce encryption best practices and secure configurations for Amazon Aurora DSQL. Use the following table to understand the details of the new graph-based tests:

| Cloud | Service | Test | Severity |
| --- | --- | --- | --- |
| AWS | Aurora DSQL | Ensure AWS Aurora DSQL Cluster uses customer managed encryption key (CMEK) for data encryption. | High |
| AWS | Aurora DSQL | Ensure deletion protection is enabled for AWS Aurora DSQL Cluster. | High |

For more information, see [Rule center](/latest/docs/rule-center-overview).
