# Using the Workflows editor

You use the Workflow Editor page to create and manage workflows, the Workflow Editor page has the following parts:

- On the left side of the page, use the dropdown menu to view all existing workflows. To locate a specific workflow, use the search bar.

![Workflow editor displaying Marketo Consent Workflow with execution options and status details.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/wf-editor-1(1).png)

![Workflow editor displaying various consent management options and execution paths.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/wf-editor-2(1).png)
- The drawing board is where you create workflows by placing nodes and connecting them together.

![Workflow editor displaying Marketo Consent Workflow with various decision points and actions.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/wf-editor-3.png)
- The left panel displays all important information regarding the workflow, including; status, description, group, organization, total number of execution, and all the passed and failed executions.

![Workflow editor displaying Marketo Consent Workflow with execution details and subscription updates.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/wf-left-panel-executions.png)
- See the following topics for more information:
  - [Placing and modifying workflow nodes](/v1/docs/placing-and-modifying-workflow-nodes)
  - [Creating and deleting workflow connections](/v1/docs/creating-and-deleting-workflow-connections)
