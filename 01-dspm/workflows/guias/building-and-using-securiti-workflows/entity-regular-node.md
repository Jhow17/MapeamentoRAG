# Entity

Manage data catalog items (institutions)

| Parameters |
| --- |
| Operation | List | List all entities in the data catalog |
| Get details | Get details of a entity |
| Create | Create an entity |
| Delete | Delete an entity |
| Update | Update an entity |
| Entity | The entity to operate on |
| Template | For Create operations, the template to use |
| Organization | For Create operations, he name of the organization |
| Name | The name to use for the new entity |
| Short Description | Short description of the entity |
| Purpose | Purpose of the entity |
| Properties | The entity properties to update: - Field - Value |
