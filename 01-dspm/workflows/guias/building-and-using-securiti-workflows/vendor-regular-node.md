# Vendor

Manage data catalog vendors

| Parameters |
| --- |
| Operation | List | List all vendors in the data catalog |
| Get details | Get details of a vendor |
| Create | Create a vendor |
| Delete | Delete a vendor |
| Update | Update a vendor |
| Vendor | The vendor to operate on |
| Template | For Create operations, the template to use |
| Technology Type | The technology type to use |
| Name | The name to use for the new vendor |
| Short Description | Short description of the vendor |
| Purpose | Purpose of the vendor |
| Properties | The vendor properties to update: - Field - Value |
