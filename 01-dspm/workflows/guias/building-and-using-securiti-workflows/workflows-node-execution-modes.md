# Workflows node execution modes

Securiti offers two modes of executing a workflow: Manual mode and Automated mode.

### Manual Mode

You can execute the workflow nodes manually without saving the workflow. You can just add the nodes to the canvas and start its execution. If necessary, double-click the node to open the node popup, and use this popup to configure the node. Securiti lets you execute the node by performing one of the following actions:

1. Hover over the node and click **Execute Node**.

![Workflow interface showing an 'Assessments Trigger' with an execution button below.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/manual-mode.png)
2. Double-click the node and near the upper right corner of the node popup click **Execute**.

![User interface displaying parameters for executing assessments with an execute button highlighted.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/manual-mode-2.png)

### Automated Mode

You must save a workflow before activating the **Active** toggle, present above the top-right corner of the canvas, to execute the workflow in automated mode. You can save the workflow by clicking **Save** (floppy disk icon). Securiti prompts you for a name and a group for the workflow. Enter a name and group, then click **Save**.

You can activate the workflow so that it is always running.

1. From the list of existing workflows, click the workflow you want to activate to open it in the canvas.
2. Near the upper right corner of the canvas, click the **Active** toggle to activate it.

![Workflow interface showing an active assessments trigger and execute button.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/automated-node.png)
