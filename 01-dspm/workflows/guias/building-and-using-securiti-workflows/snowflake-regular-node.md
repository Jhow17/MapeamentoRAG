# Snowflake

Get, add, and update data in Snowflake.

| Parameters |
| --- |
| DataSource Name | Name of the configured DataSource |
| Connect to Database | Name of the database to connect with the node |
| Operation | Execute Query | SQL query to execute |
| Insert | Inserts a new row in the database table(s) |
| Update | Updates an existing row in the database table(s) |
| Query | The SQL query to execute |
| Database | Database to perform the operation on |
| Schema | Database schema to perform the operation on |
| Table | Database table to perform the operation on |
| Columns | Columns to perform an operation on. Provide a comma-separated list of the properties to use as columns for the new rows |
| Update Key | Provide the name of the property such as “id” which decides which rows in the database should update |
