# Regular nodes

The regular nodes in Workflows module refer to the nodes that work in a regular fashion and do not require any trigger action to work. A regular node is a generic term for any node within the workflow that is not specifically designed to trigger the flow. Regular nodes perform various tasks or operations as part of the workflow. They can include functions like data manipulation, filtering, conditional branching, database interactions, or any other action needed to complete the automation process.
