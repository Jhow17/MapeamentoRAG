# Start

The start node is the first node in a Workflow. It exists by default when you create a new Workflow and is responsible for initiating the Workflow. In case there is no Trigger node in the Workflow, the Workflow starts by the Start node.

You can only have one Start node. This node has no parameters and is usually connected to the first node of the Workflow. Here is how it looks like within a Workflow:

| Parameters |
| --- |
| The node does not have any parameters |

This node exists on the Workflow generator page by default every time you start creating a new Workflow.

A series of connected nodes to automate a process. The Data System and Connector nodes in a workflow carry different operations of Securiti data systems. See Building and using workflows, for more information.
