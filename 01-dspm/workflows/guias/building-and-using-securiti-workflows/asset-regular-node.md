# Asset

Manage data catalog assets

| Parameters |
| --- |
| Operation | List | List all assets in the data catalog |
| Get details | Get details of an asset |
| Create | Create an asset |
| Delete | Delete an asset |
| Update | Update an asset |
| Asset | The asset to operate on |
| Template | For Create operations, the template to use |
| Vendor | The asset vendor |
| Name | The name to use for the new asset |
| Short Description | Short description of the asset |
| Purpose | Purpose of the asset |
| Properties | The asset properties to update: - Field - Value |
