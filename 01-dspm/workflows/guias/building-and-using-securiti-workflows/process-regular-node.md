# Process

Manage data catalog processes

| Parameters |
| --- |
| Operation | List | List all processes in the data catalog |
| Get details | Get details of a process |
| Create | Create a process |
| Delete | Delete a process |
| Update | Update a process |
| Process | The process to operate on |
| Template | For Create operations, the template to use |
| Name | The name to use for the new process |
| Short Description | Short description of the process |
| Purpose | Purpose of the process |
| Properties | The process properties to update: - Field - Value |
