# Trigger nodes

The trigger Nodes in the Workflows module are the Nodes that are triggered on an event triggered based on the node. Trigger Nodes can be configured to respond to specific events or conditions. These events can be external inputs, such as HTTP requests, timer events, or other types of signals that activate the Workflow. When the trigger node detects the specified event or condition, it starts the flow and passes control to the subsequent Nodes in the Workflow.

A node in workflow refers to a specific step or task within the overall process. Workflows are sequences of interconnected steps that represent a process or a set of activities to achieve a specific goal and each step or task in the workflow is referred to as a node. Nodes can represent various activities, such as data processing, decision points, approvals, or any other task that needs to be completed as part of the larger process.

A series of connected nodes to automate a process. The Data System and Connector nodes in a workflow carry different operations of Securiti data systems. See Building and using workflows, for more information.
