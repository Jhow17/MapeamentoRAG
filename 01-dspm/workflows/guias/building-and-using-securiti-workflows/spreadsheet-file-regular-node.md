# Spreadsheet File

Read and write data to and from a spreadsheet file

| Parameters |
| --- |
| Operation | Read from file | Reads data from a spreadsheet file |
| Write to file | Writes Workflow data to a spreadsheet file |
| File Format | CSV | Comma-separated values |
| HTML | HTML table |
| ODS | OpenDocument Spreadsheet |
| RTF | Rich Text Format |
| XLS | Excel |
| Binary Property | Name of the binary property from which to read or write data |
| Options | RAW Data | Enable to return data as RAW instead of parsed |
| Read As String | Enable if it is necessary to read data specifically as a string in order to correctly render special characters |
| Sheet Name | Name of the sheet to read from in the spreadsheet. When omitted, data is read from the first |
| File Name | The file name to set in binary data. When omitted, the name "spreadsheet" is used |

A series of connected nodes to automate a process. The Data System and Connector nodes in a workflow carry different operations of Securiti data systems. See Building and using workflows, for more information.
