# Managing Workflows groups

Groups provide a logical layer of organization to keep your workspace clean and secure. They allow you to categorize workflows.

- The dashboard provides a tabular view of all the existing workflow groups. It displays all important information regarding a workflow group including; **Group Name**, **Organization**, **Workflows**, **Created At**, and **Last Modified** etc.

![Workflow groups display organizational structure and workflow details for efficient management.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/group-1.png)
- You can perform actions including; **Edit** and **Delete** using the **Options** (three dots) at the end of each row.

![Workflow management interface displaying groups, workflows, and options for editing or deleting.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/group-2.png)
  - When editing, you can update the group name, its description, and associated workflows. The updated information will automatically be reflected across all associated workflows.

![Editing a workflow group named 'Assessment' with associated workflows and descriptions.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/group-3.png)
- You can customize the columns of the table according to your preference using the column selector as shown below.

![Workflow management interface displaying groups, workflows, and organizational details for users.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/group-4.png)
- You can also customize the dashboard view using the filters provided.

![Workflow management interface displaying group filtering options and workflow details.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/group-5.png)
- You can also search for a specific workflow group using the global search bar.

![Workflow management interface displaying groups and search functionality for organizing workflows.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/group-6.png)
- To create a new workflow group, click **+ New Workflow Group** from the top-right corner of the page.

![Workflow management interface displaying groups, organizations, and workflow details for categorization.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/group-7.png)
