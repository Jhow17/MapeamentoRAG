# Using the Workflows library

The Workflow Library is your central repository. It stores the master templates used to trigger and scale your repeatable processes.

![Workflow Library displaying various consent remediation workflows for different systems.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/wf-lib-1(1).png)

Use the **Options** (three dots) at the end of each row to either **Preview** or **Clone** a template.

![Workflow Library displaying various consent remediation options for Salesforce, Dynamics, and Marketo.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/wf-lib-2.png)
