# Using the Workflows dashboard

The Workflows dashboard provides you a centralized view to monitor and manage your workflows. This dashboard has the following parts:

- The dashboard provides a tabular view of all the existing workflows. It displays all important information regarding a workflow including; **Status**, **ID**, **Name**, **Group**, **Organization** etc.

![Overview of workflows showing active and inactive statuses with execution details.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/wf-db-1.png)
- You can perform actions including; **View**, **Edit** and **Delete** using the **Options** (three dots) at the end of each row.

> [!NOTE]
> Note
> 
> You cannot edit or delete an active workflow.

![Overview of workflows with active and inactive statuses, including options to view or delete.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/wf-db-2.png)
- You can customize the columns of the table according to your preference using the column selector as shown below.

![Workflow management interface displaying active and inactive workflows with filter options.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/wf-db-3.png)
- You can also customize the dashboard view using the filters provided.

![Workflow management interface displaying filter options for status and properties.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/wf-db-4.png)
- You can also search for a specific workflow using the global search bar.

![Workflow management interface displaying active and inactive workflows with search functionality.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/wf-db-5.png)
- The widgets below the global search bar display important information including; total number of workflows, total number of active workflows, and total number of inactive workflows.

![Overview of workflows showing active and inactive counts with detailed workflow information.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/wf-db-6.png)
- To create a new workflow, click **+ New Workflow** from the top-right corner of the page.

![Overview of workflows with active and inactive statuses, including execution details.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/wf-db-7.png)

To learn how to build a new workflow using the Workflow Editor, see [Using the Workflow Editor](/latest/docs/using-the-workflow-generator).
