# Placing and modifying workflow nodes

### Adding a new node

To add a new Workflow node:

1. Do one of the following:

Securiti opens the Create Node panel to let you choose the type of node.
  - To create a new independent node, near the upper right corner of the Workflow Editor page, click **+**.
  - To create a new node connected to a prior node, click the connection bubble on the prior node, drag the cursor to an empty spot on the drawing board, and release.

![DSR Trigger node with instructions to drop connection for creating a new node.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/pm-1.png)
2. On the Create Node panel, use the tools to filter the list of available node types.
  - Use the **Regular**, **Trigger**, or **All** tab to filter the available nodes by type, then scroll the list to find the one you want.

The first node in any workflow is either the default Start node, or a trigger node.
  - Use the filter box above the tabs to filter the available nodes by name.

![Creating a node for DSR tasks with options for sub-tasks and attachments.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/pm-2.png)
3. Once you locate the node you want to add, click it to add it to the current workflow.

Securiti adds the new node and opens a configuration popup for the new node.

### Moving a node

To move a node to a different position on the drawing board:

- Click on the node and drag it to the new position. The node connections, if any, stretch and bend to accommodate the move.

### Removing a node

To remove a node from an existing workflow:

- Hover over the node and click **Delete** (trash can icon).

![Workflow diagram showing DSR Trigger and Okta with a delete node option highlighted.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/pm-3.png)

### Viewing ToolTip help for a node parameter

- Hover over the parameter to reveal the (?) bubble, then hover over the bubble.
