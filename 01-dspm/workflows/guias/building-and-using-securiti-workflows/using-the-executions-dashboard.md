# Using the Executions dashboard

Workflow Executions provide a live window into your automated operations. A real-time view to oversee active processes and track performance. This dashboard has the following components:

![Overview of workflow executions showing success statuses and execution details.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/wf-exe.png)

- A tabular view that displays important information including **Status**, **Workflow**, **Execution ID**, **Correlation ID** etc.
- A column selector to customize the tabular view.
- Filters including **Status**, **Workflow**, **Execution ID**, **Correlation ID**, **Started At**, **Stopped At**, and **Mode** to customize the dashboard view.
- A global search bar to search for specific executions using the workflow name or correlation ID.
