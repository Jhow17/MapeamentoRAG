# Dashboard prerequisites

To use the Graph Reporting Dashboards, you must be subscribed to Securiti's **Data Command Graph**.

Once you have access to Securiti's **Data Command Graph** module, the data across all modules is collected and is displayed on the dashboard, in the form of widgets, which are created in the aforementioned modules. Predefined widgets are also present under the **System** dashboards, which can be used at any time for data analysis.

For more information, see [Creating widgets in Graph Explorer](/v1/docs/creating-widgets-in-graph-explorer)

### Adding widgets to a dashboard

You can create widgets from your queries in the **Graph Explorer** or use the data from entities in **Inventory** or module-specific **Data Command Graph** pages. You can create widgets using one of the following methods.

> [!NOTE]
> **Note**
> 
> Widgets can be added in **Custom** dashboards only.

- **Creating widgets from filters:**
  - Near the upper right corner of the grid, click **More Actions** (three-dots) icon and select **Create Widget**.

![Overview of IaaS Cloud services with data system counts for various providers.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/createwidget_inventory.png)
  - In the modal, specify the details such as widget name, description, as well as the module and the dashboard group to save the widget in.

Once you choose the widget name, you can select the dashboard group and name to create widgets in, or you can create a new dashboard and dashboard group, from the **Widgets** popup.

![Widget configuration interface displaying Hosting Grid with various data counts.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/addingwidgets_inventory.png)
- **Creating Widget from JSON**: You can also create widgets using JSON queries using the **Create Widget from JSON** option. For more information, see [Creating widgets from JSON queries](/v1/docs/creating-widgets-from-json-queries).

![Dashboard overview displaying asset posture score and security findings metrics.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/createwidgetfromjson_reportingdashboard(2).png)
