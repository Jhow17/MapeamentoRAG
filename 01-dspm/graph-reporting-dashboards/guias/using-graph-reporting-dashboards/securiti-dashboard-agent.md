# Using Securiti Dashboard Agent

**Scenario**

As a **Data Security Officer**, you need to investigate and report on critical findings. Manually building a specific query and then creating a separate dashboard is inefficient.

Now, you can ask the Securiti Dashboard Agent to "create a dashboard for these findings," streamlining the entire workflow from investigation to reporting.

## Overview

The Securiti Dashboard Agent is an AI assistant that automates the process of creating and discovering reports. You can use natural language prompts to generate entire dashboards or individual widgets, streamlining the process of visualizing your data.

> [!WARNING]
> Important
> 
> - If the AI Agents feature is not available in your tenant, contact your Customer Success Manager or Account Representative to confirm whether it is included in your plan and whether your tenant meets the eligibility requirements for its activation.
> - By default, AI Agents use Securiti’s built-in Large Language Model (LLM) Provider with the following daily usage limits:
> 
> To avoid these limitations, you can also configure your LLM provider. For more information on configuring these limits, contact [support@securiti.ai](mailto:support@securiti.ai).
>   - Per User Limit: 100 requests per day
>   - Per Tenant Limit: 1000 requests per day

Key capabilities include:

- Generating a complete, multi-widget dashboard from a single prompt
- Creating and adding specific, individual widgets to any dashboard
- Change a widget’s type using its query

## Using the Dashboard AI Agent

> [!CAUTION]
> Warning
> 
> - Queries generated by AI agents are non-deterministic and may produce varying results. We recommend that you review and validate each generated query to confirm it accurately reflects the intended scenario and scope.
> - The responses provided by this AI agent are for informational purposes only and do not constitute professional or legal advice. Securiti disclaims any liability for errors, omissions, or decisions made based on these responses.

To use the Securiti Dashboard Agent:

1. On the Reporting dashboard page, from the left navigation bar, click the AI Assistant icon, as shown below.

![Overview of data security findings, asset posture score, and compliance metrics.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/dashagent_aiicon.png)
2. In the chat interface, enter your prompt to create a dashboard or widget, as shown below.

![Overview of data security findings and asset posture score for compliance dashboard.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/dashagent_chatwindow.png)
3. Securiti also lets you add widgets to a new or existing dashboard with the **New** option, as shown below.

![Creating a new dashboard with options for name and group selection in security overview.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/dashagent_newdashboardpopup.png)
4. Enter the dashboard name and select the dashboard group from the menu.
5. Enable the **Initialize Dashboard Agent** toggle to initialize the AI Agent and use it to create widgets.

![Creating a new dashboard with options for name and group selection in security overview.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/dashagent_newdashboardpopup(1).png)
6. Click **Save**.
7. Enter your prompt for widget creation in the chat interface, as shown below.
8. For the AI-generated widget, from the upper right corner of the widget, click **Add**.

![Dashboard interface displaying top data systems with high security posture findings summary.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/dashagent_addwidgetsoption.png)
9. Choose one of the following options from the menu:
  - **Add to current dashboard:** Adds the widget to the existing dashboard.
  - **Add to another dashboard:** Adds the widget to another dashboard. After you select this option, select the dashboard and dashboard group to move the widget to, as shown below.

![Dashboard selection interface for AWS Risk Analysis with highlighted options.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/dashagent_addwidgetto_anotherdashboard.png)
