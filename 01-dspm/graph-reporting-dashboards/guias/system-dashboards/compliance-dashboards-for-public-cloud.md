# Compliance dashboards for Public Cloud

The Compliance dashboards let you gain insights into your public cloud environment's compliance open issues.

![Dashboard displaying AWS compliance issues and security posture findings for various services.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/compliance_dashboards.png)

The below tables show supported widgets in the Compliance system dashboards. The widgets are available in each cloud provider's dashboards.

**AWS widgets**

| Widget title | Widget type | Description |
| --- | --- | --- |
| AWS - NIST 800-53 Top 5 Compliance Open Issues | Chart | Provides an overview of the top compliance challenges currently faced within AWS, Azure, and Google Cloud environments as they pertain to NIST 800-53 standards. The chart displays a list of the most significant open issues, quantified by their occurrence counts. |
| AWS - NIST 800-53 Top 5 Compliance Open Issues by Data System Type | Chart | Provides an overview of the top compliance challenges currently faced within AWS and Google Cloud environments as they pertain to NIST 800-53 standards. The pie chart displays all the data systems with the most significant open issues, quantified by their occurrence counts. |
| AWS - NIST 800-53 Top 5 Compliance Open Issues by Account | Chart | Provides an overview of the top compliance challenges currently faced within AWS accounts, Azure subscriptions, and Google Cloud projects as they pertain to NIST 800-53 standards. The pie chart displays all the accounts with the most significant open issues, quantified by their occurrence counts. |
| AWS - ISO 27001:2013 Top 5 Compliance Open Issues | Chart | Provides an overview of the top compliance challenges currently faced within AWS, Azure, and Google Cloud environments as they pertain to ISO 27001:2013 standards. The chart displays a list of the most significant open issues, quantified by their occurrence counts. |
| AWS - ISO 27001:2013 Top 5 Compliance Open Issues by Data System Type | Chart | Provides an overview of the top compliance challenges currently faced within AWS and Google Cloud environments as they pertain to ISO 27001:2013 standards. The pie chart displays all the data systems with the most significant open issues, quantified by their occurrence counts. |
| AWS - ISO 27001:2013 Top 5 Compliance Open Issues by Account | Chart | Provides an overview of the top compliance challenges currently faced within AWS accounts, Azure subscriptions, and Google Cloud projects as they pertain to ISO 27001:2013 standards. The pie chart displays all the accounts with the most significant open issues, quantified by their occurrence counts. |
