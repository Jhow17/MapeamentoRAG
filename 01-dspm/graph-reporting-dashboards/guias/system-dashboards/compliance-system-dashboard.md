# Compliance dashboard

Securiti's **Compliance** system dashboard provides insights into your organization's compliance status across multiple frameworks and cloud environments.

The table below provides an overview of the predefined widgets in the Compliance dashboard.

| Widget title | Widget type | Description |
| --- | --- | --- |
| Test Coverage by Cloud | Chart | A pie chart widget that shows the distribution of tests across different cloud environments such as AWS, Azure, GCP, and SaaS platforms, helping you understand cloud-specific compliance status. |
| Test Coverage by Framework | Chart | A donut chart that displays the distribution of tests across multiple compliance frameworks like NIST, ISO/IEC 27001, HIPAA, and others, offering a framework-specific compliance overview. |
| Pass/Fail Controls | Chart | Circular widgets that are used to display the status of your compliance controls, showing the number of pass/fail instances. |
| Pass/Fail Controls Trends | Graph | A line graph that shows trends in pass/fail rates over a selected time period, enabling you to track control performance and identify patterns. |
| Pass/Fail Tests | Chart | Circular widgets that help you track tests that either passed or failed compliance checks, providing an overview of test compliance status. |
| Pass/Fail Tests Trend | Graph | A line graph that shows trends in pass/fail test rates over a selected time period, enabling you to track test performance and identify patterns. |
| Pass/Fail Assets | Chart | Circular widgets that help you track assets that either passed or failed compliance checks, providing an overview of asset compliance status. |
| Pass/Fail Assets Trend | Graph | A line graph that shows trends in pass/fail asset rates over a selected time period, enabling you to track asset performance and identify patterns. |
| Findings List | Grid | A table that provides detailed information on each compliance-related finding, such as the asset name, type, hosting environment, region, and any related security posture findings. You can also view links to these findings for further exploration. |
| Findings Trend | Graph | A trend graph that showcases the number of findings over time, helping you visualize compliance performance and potential issues. |
| List of Projects | Grid | A table that provides a list of projects showing their status (e.g., In Progress, Complete, Under Review) along with any relevant descriptions, letting you track compliance projects across the organization. |
