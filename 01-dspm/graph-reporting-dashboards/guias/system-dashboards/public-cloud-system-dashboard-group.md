# Public Cloud Overview dashboard

The Public Cloud Overview dashboard lets you gain a high level overview about your data systems, cloud accounts and where they are hosted with the following available widgets.

![Overview of public cloud services, including data systems and regional hosting information.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/publiccloud_overviewdash.png)

| Widget title | Widget type | Description |
| --- | --- | --- |
| IaaS Clouds | Grid | Provides information about IaaS cloud accounts, their data systems and regions in table rows. |
| Regions Map | Map | Shows hosting locations for cloud accounts on a map. |
| Data Systems Overview by Region | Grid | Provides an overview of data systems according to their region such as in **us-east-1**. |
