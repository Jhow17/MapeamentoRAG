# Data Security

Securiti's **Data Security** dashboard group provides an in-depth view of your organization's data security posture, offering insights into security findings, sensitive data elements, structured and unstructured data. These dashboards let you monitor risks, compliance, and potential vulnerabilities in your data systems.

To access the **Data Security** system dashboard group, open the **Reporting Dashboard** and on the left side of the page, click on **System** to view a list of all system dashboard groups. From the list, choose the **Data Security** dashboard group.

![Dashboard displaying Data Security options and report details for various modules.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/accessDatadashboards1.png)

Securiti also lets you access the **Data Security** system dashboard by navigating to **Reporting > Manage dashboards > System** , and from the left panel, select **Data Security** from the list of system dashboard groups.

![Overview of data security findings, including counts and risk severity levels.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Dataandaisecurity_groupoverview.png)
