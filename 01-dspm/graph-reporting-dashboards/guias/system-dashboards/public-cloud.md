# Public Cloud

Securiti's **Public Cloud** system dashboard group lets you view and analyse metrics for your public cloud environment's accounts, data, and security posture.

To access the **Public Cloud** system dashboards, open the **Reporting Dashboard** and on the left side of the page, click on **System** to view a list of all system dashboard groups. From the list, choose the **Public Cloud** group.

![Overview of public cloud systems, highlighting AWS cloud data and regions.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/publicdashaccess_1.png)

Securiti also lets you access the **Public Cloud** system dashboards by navigating to **Dashboard > Manage dashboards > System** and from the left panel, select **Public Cloud** from the list of system dashboard groups.

![Dashboard displaying various cloud security modules and compliance options for data management.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/publicdash_access2.png)

The Public Cloud dashboard group contains the following system dashboards for each IaaS service provider.

| System dashboard | Description |
| --- | --- |
| Public Cloud Overview | The Public Cloud Overview system dashboard serves as an overall aggregate of all cloud provider's dashboards. The dashboard provides an overview of all cloud accounts and their data systems with the **IaaS Clouds**, **Regions Map**, and **Data Systems Overview** widgets. |
| Data Discovery and Classification | The Data Discovery and Classification dashboards let you gain insights into your public cloud environment's data systems, cloud accounts, data volume and data classification. Following dashboards are available in the **Reporting** module for each cloud provider's data. 1. **AWS - Data Discovery and Classification**: Contains widgets for all the AWS cloud accounts, discovered data objects, assets and AI resources. 2. **Azure - Data Discovery and Classification**: Contains widgets for all the Azure cloud accounts/subscriptions, discovered data objects, assets and AI resources. 3. **Google Cloud - Data Discovery and Classification**: Contains widgets for all the GCP cloud accounts/projects, discovered data objects, assets and AI resources. |
| Data Security | The Data Security dashboards let you gain insights into your public cloud environment's security posture such as open findings. Following dashboards are available in the **Reporting** module for each cloud provider's data. 1. **AWS - Data Security**: Contains widgets for all the AWS cloud accounts with risks, findings, and data systems with security misconfigurations and risks. 2. **Azure - Data Security**: Contains widgets for all the Azure cloud accounts with risks, findings, and data systems with security misconfigurations and risks. 3. **Google Cloud - Data Security**: Contains widgets for all the GCP cloud accounts with risks, findings, and data systems with security misconfigurations and risks. |
| Compliance | The Compliance dashboards let you gain insights into your public cloud environment's compliance open issues. Following dashboards are available in the **Reporting** module for each cloud provider's data. 1. **AWS - Compliance**: Contains widgets for all the NIST 800-53 and ISO 27001:2013 open issues associated with AWS data systems. 2. **Azure - Compliance**: Contains widgets for all the NIST 800-53 and ISO 27001:2013 open issues associated with Azure data systems. 3. **Google Cloud - Compliance**: Contains widgets for all the NIST 800-53 and ISO 27001:2013 open issues associated with GCP data systems. |
