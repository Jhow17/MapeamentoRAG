# AI Security

Securiti's **AI Security** dashboard group provides an in-depth view of your organization's AI infrastructure, offering insights into security findings, sensitive data, and toxic combinations for AI Agents and platforms. These dashboards let you monitor risks, compliance, and potential vulnerabilities in your AI systems.

To access the **AI Security** system dashboard group, open the **Reporting Dashboard** and on the left side of the page, click on **System** to view a list of all system dashboard groups. From the list, choose the **AI Security** dashboard group.

![Dashboard displaying AI models, agents, and knowledge base counts for enterprise inventory.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/accessAIdashboards1.png)

Securiti also lets you access the **Data Security** system dashboard by navigating to **Reporting > Manage dashboards > System** , and from the left panel, select **AI Security** from the list of system dashboard groups.

![Dashboard displaying AI Security options and related data management modules.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/accessAIdashboards2.png)
