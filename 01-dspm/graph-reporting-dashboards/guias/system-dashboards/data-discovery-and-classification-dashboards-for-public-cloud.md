# Data Discovery and Classification dashboards for Public Cloud

The Data Discovery and Classification dashboards let you gain insights into your public cloud environment's data systems, cloud accounts, data volume and data classification.

![Overview of AWS data discovery and classification dashboard with various cloud services listed.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/datadiscovery_dashboards.png)

The tables below show supported widgets in the Data Discovery and Classification system dashboards. The widgets are available in each cloud provider's dashboards.

**AWS widgets**

| Widget title | Widget type | Description |
| --- | --- | --- |
| AWS - IaaS Clouds | Grid | Provides information about AWS cloud accounts, their data systems and regions in table rows. |
| AWS - Regions Map | Map | Shows hosting locations for AWS accounts on a map. |
| AWS - Data Systems Overview by Region | Grid | Provides an overview of AWS data systems according to their region such as in **us-east-1**. |
| AWS - Data Systems Overview | Grid | Provides an overview of AWS data systems such as their assets, sensitive data, findings, and data size. |
| AWS - Cloud Accounts Overview | Grid | Provides an overview of AWS cloud accounts such as the account name, ID, sensitive data, findings, and data size. |
| AWS – Top 5 Accounts by Data Size | Chart | Shows tops 5 AWS accounts classified on the basis of their data volume in the form of pie chart. |
| AWS – Top 5 Accounts by Data Objects | Chart | Shows tops 5 AWS accounts classified on the basis of their data objects in the form of pie chart. |
| AWS - Top 5 Accounts by High and Critical Findings | Chart | Shows tops 5 AWS accounts classified on the basis of their high and critical findings as a pie chart. |
| AWS – Top 5 Accounts by Sensitive Data Elements | Chart | Shows tops 5 AWS accounts classified on the basis of their sensitive data elements discovered during scans as a pie chart. |
| AWS - Sensitive Data Overview | Metric | Shows metric counts for the following information about sensitive data discovered for AWS data systems. - Total Data Elements - Sensitive Data Element Types - Tables with Sensitive Data - Columns with Sensitive Data |
| AWS - Top 5 Data Classification Profiles | Grid | Provides information related to the top 5 data classification profiles discovered for AWS data systems such as the display name, data volume, and data system. |
| AWS - Top 5 Data Classification Categories | Grid | Provides information related to the top 5 data classification categories discovered for AWS data systems such as the category name, sensitive data, table, column, database and data system. |
| AWS - Top 5 Data Classification Types | Grid | Provides information related to the top 5 data classification types discovered for AWS data systems such as the display name, sensitive data, table, column, database and data system. |
| AWS - Top 5 Bedrock Provisioned Throughputs | Grid | Provides an overview of top 5 AWS Bedrock provisioned throughputs such as their assets, model units, deployment name, and other properties. |
| AWS - Top 5 SageMaker Deployments | Grid | Provides an overview of top 5 Sagemaker deployments such as the assets, resource type, account, and region |
| AWS - AI Services Overview | Metric | Shows metric counts for the following information in GCP AI services. - Accounts Using AI Services - Regions Using AI Services - Custom Models - AWS SageMaker Model Endpoints - AWS Bedrock Model Throughputs |
