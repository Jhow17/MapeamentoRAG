# System dashboards

System dashboards are predefined dashboards that Securiti provides for your business use cases. Each system dashboard contains a fixed set of widgets scoped to a specific area of analysis, such as public cloud posture, data and AI security, or compliance readiness.

You can view and analyze system dashboards, but you cannot edit them. To work with a system dashboard's widgets, clone the dashboard or copy its widgets into a custom dashboard.

Securiti supports the following system dashboard groups:

| Dashboard group | Dashboards |
| --- | --- |
| **Public Cloud** | - [Public Cloud Overview dashboard](/latest/docs/public-cloud-system-dashboard-group) - [Data Discovery and Classification dashboards for Public Cloud](/latest/docs/data-discovery-and-classification-dashboards-for-public-cloud) - [Data Security dashboards for Public Cloud](/latest/docs/data-security-dashboards-for-public-cloud) - [Compliance dashboards for Public Cloud](/latest/docs/compliance-dashboards-for-public-cloud) |
| **Data Security** | - [Data and AI Security Overview dashboard](/latest/docs/data-and-ai-security-overview) - [Unstructured Data Overview dashboard](/latest/docs/unstructured-data-overview-dashboard) - [Structured Data Overview dashboard](/latest/docs/structured-data-overview-dashboard) - [Microsoft 365 Data and AI Security dashboard](/latest/docs/microsoft-365-data-and-ai-security-dashboard) |
| **AI Security** | - [AI Security: Toxic Combinations](/latest/docs/ai-security-toxic-combinations) - [Agents with Access to Sensitive Data](/latest/docs/agents-with-access-to-sensitive-data) - [Sensitive Data Accessible by AI system dashboard](/latest/docs/sensitive-data-accessible-by-ai-system-dashboard) - [Inventory: AI Models & Agents system dashboard](/latest/docs/inventory-ai-models-agents) |
| **Data Remediation** | - [Data Remediation dashboards (File Insights, File ROT, File Quarantine)](/latest/docs/data-remediation-system-dashboards) - [File Labeling dashboard](/latest/docs/data-labeling-reporting-dashboard) - [Using the Duplicate Files dashboard](/latest/docs/duplicate-files-dashboard) |
