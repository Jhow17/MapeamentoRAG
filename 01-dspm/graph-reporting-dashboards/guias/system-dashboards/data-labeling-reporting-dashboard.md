# File Labeling dashboard

The File Labeling dashboard provides visibility into labeled files across your data systems. Use this dashboard to monitor labeling trends, review policy outcomes, and understand how labels are distributed across your data.

- Use the policy filter at the top of the dashboard to filter data by a specific policy, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-OJFU0NSW.png)
- After you select a policy, the dashboard displays insights in the following widgets:

| Widget Name | Widget Type | Description |
| --- | --- | --- |
| Global Metrics Trend | Trend Chart | Displays the trend of files labeled externally and files labeled by Securiti. |
| Policy Metrics Trend | Trend Chart | Displays the trend of files scoped and labeled by Securiti for the selected policy. |
| Label Distribution Trend | Trend Chart | Displays the distribution of labeled files over time by classification label. |
| Labeled Data | Metric | Displays the total number and size of labeled files. |
| Files grouped by label | Grid | Displays the number and size of labeled files grouped by classification label. |
| Labeled Files by Owner | Grid | Displays the number and size of labeled files grouped by file owner. |
| Labeled Files by Format | Treemap | Displays the number of labeled files grouped by file format. |
