# Compliance

Securiti's **Compliance** system dashboard group provides insights into your organization's compliance status across multiple frameworks and cloud environments. These dashboards let you monitor control effectiveness, pass or fail trends, asset compliance, and findings in real-time. You can customize widgets and apply filters to drill down into specific data.

To access the **Compliance** system dashboard group, open the **Dashboards** app and on the left side of the page, click on **System** to view the list of all system dashboard groups. From the list, choose the **Compliance** dashboard group.

![Dashboard displaying backup and disaster recovery metrics and compliance options for cloud assets.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/compliancedashboard.png)

Alternatively, you can access the **Compliance** system dashboard by navigating to **Dashboard > Manage dashboards > System** and from the left pane, select **Compliance** from the list of system dashboard groups.

![Dashboard interface displaying system compliance and data security options for reporting.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/systemdashboards_compliance.png)

The Compliance dashboard group includes the following system dashboards:

- [Compliance](/latest/docs/compliance-system-dashboard)
- [Backup and Disaster Recovery](/latest/docs/backup-and-disaster-recovery-dashboard-1)

From the top-left corner of the page, use the selector to filter by a specific framework or project, as shown below. This lets you view widget data relevant to your Compliance project only.

![Dashboard displaying project selection and data backup statistics for cloud management.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/dashboard_selector_compliance.png)
