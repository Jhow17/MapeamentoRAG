# Managing dashboards

On the Dashboards page, you can access all system, custom, and shared dashboards under the respective **System**, **Custom**, and **Shared with me** tabs. This page provides an overview of all dashboards and lets you perform quick actions on your dashboard. Selecting a dashboard group displays all the dashboards under it, along with the details on the right grid. You can also search the dashboard groups from the left panel, as shown below.

![Dashboard displaying data security reports with descriptions and creation dates listed.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/reportingdashboards.png)

You can create new dashboards for your reporting purposes, manage visibility of your dashboards, and clone or delete dashboards to stay organized.

The table below describes the dashboard actions supported for each type of dashboard.

> [!NOTE]
> **Note**
> 
> System dashboard groups cannot be modified. You can clone a system dashboard as a custom dashboard to edit widgets and make any modifications.

| Dashboard action | Description | System | Custom | Shared |
| --- | --- | --- | --- | --- |
| View | Opens a dashboard to display all the widgets and their data for reporting and analysis purposes. You can only view dashboards you have access to. | ✓ | ✓ | ✓ |
| Edit | Opens a custom dashboard in **Edit** mode to let you modify widget details, chart types, dashboard name, description, and more. For more information, see [Editing dashboards and widget](/v1/docs/editing-dashboards-and-widgets). | **X** | ✓ | **X** |
| Clone | Copies a dashboard as a custom dashboard in the dashboard group you specify. The copied version has a *copy* suffix at the end of the dashboard name. > [!NOTE] > **Note** > > Cloning a system dashboard creates a copy of the dashboard in the custom section. | ✓ | ✓ | ✓ |
| Share | Edits a dashboard's visibility to share with users across your tenant. You can make a dashboard publicly or privately visible or share it with specific users in your tenant only. For more information, see [Managing dashboard access](/v1/docs/managing-dashboard-access). | **X** | ✓ | **X** |
| Mark As Default | Marks a dashboard with a **default** label and makes it appear on the **Reporting dashboard** screen automatically when you log in. Marking a dashboard as default makes the dashboard easy to access. | ✓ | ✓ | ✓ |
| Delete | Deletes a custom dashboard and all the widgets in it. | **X** | ✓ | **X** |
