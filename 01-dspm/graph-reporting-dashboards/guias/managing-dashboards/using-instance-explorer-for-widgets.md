# Using Instance Explorer for widgets

The Instance Explorer lets you view details and explore all entity relationships for a particular instance. It provides a granular view of a single instance and its connections in a graphical view while displaying counts for each entity.

> [!NOTE]
> **Important**
> 
> The Instance Explorer can be used for grid widgets by clicking on the column containing the display name only.

Graph Reporting Dashboards leverage the instance explorer feature from the Data Command Graph for its widgets. To use the Instance Explorer for your widget, click the **Instance Viewer** icon adjacent to any row of your grid widget.

![Overview of data security metrics for public and SaaS cloud data systems.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/instanceviewer_reportingdashboard.png)

The Instance Explorer modal provides you with the following features for your selected column.

- Graphical representation of all entities and their connections
- Granular view of all relationships for a selected entity
- Counts for all entities
- Grid view of all related entities with their counts and instances.
