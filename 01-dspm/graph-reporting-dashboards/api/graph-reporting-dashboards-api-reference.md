# Graph Reporting Dashboards API reference

The Graph Reporting Dashboards APIs let you programmatically manage dashboards, widgets, and scheduled reports in Securiti. Use these APIs to use dashboard operations, retrieve widget data, and utilize the reporting capabilities into your workflows.

With the Graph Reporting Dashboards APIs, you can:

- Fetch, clone, edit, and delete custom dashboards
- Mark a dashboard as default or change its visibility (public or private)
- Fetch widget data using aggregate and graph queries
- Copy widgets between dashboards and add rich text widgets
- Generate on-demand reports and schedule daily or weekly report exports
- Share dashboards with users across your tenant
- Refresh widget data and cancel active refresh requests

Use the Reporting Dashboard APIs with Securiti's REST API endpoints, OAuth 2.0 authentication, and standard HTTP methods. See our [Reporting Dashboard API reference](https://securiti-doc-router.securiti.ai/modules/reporting-dashboard/apidocs/index.html) for granular request and response details of all available API calls.
