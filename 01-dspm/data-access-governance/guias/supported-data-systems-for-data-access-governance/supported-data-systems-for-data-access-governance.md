# Supported Data Systems for Data Access Governance

Securiti supports different data systems for Data Access Governance features such as access control policies, privilege analysis, cross-border data transfer policies, etc. To get more information about the Access Governance features supported for different data systems, see [Data System Coverage for Data Access Governance](/v1/docs/data-access-governance-dag-overview#data-system-coverage-for-data-access-governance).
