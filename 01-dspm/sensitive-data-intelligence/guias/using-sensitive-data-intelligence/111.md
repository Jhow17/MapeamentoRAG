# Accessing evidence files for policies

When investigating policy violations, reviewing evidence for a flagged file helps you understand what sensitive data was detected and where it occurs. The **Evidence Viewer** provides scan details and information about detected data elements, including their categories, counts, and individual occurrences.

To view evidence for a file on the Data Remediation dashboard:

1. For the file whose evidence you want to view, click **Options (three dots) > View Evidence**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-VRMT759A.png)

> [!WARNING]
> Important
> 
> - The **View Evidence** option is available only when you have configured at least one Private Cloud Storage (PCS).
> - If you click **View Evidence** and see the message **No evidence paths found for this file**, it means the discovery scan ran without enabling the evidence option.
> - If you click **View Evidence** and see the message **Unsupported evidence path found, please re-scan the file to view the evidences,** it means the file was scanned using an older scan version, inventory method, or appliance. You must re-scan the file to generate a new evidence path in the currently supported format.
  - This opens the **Evidence Viewer** panel for the selected file. The **Scan Job** field at the top of the panel displays the scan job associated with the evidence, as shown below. If evidence is available for multiple scan jobs, use the **Scan Job** menu to select the scan job whose evidence you want to view. ![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-PI9CFRN8.png)
2. Review the **Evidence** tab on the left side of the **Evidence Viewer** panel, as shown below. The tab provides the following information for each detected data element:

| Properties | Description |
| --- | --- |
| Data Element | Displays the name of the detected data element. |
| Data Element Category | Displays the category associated with the detected data element. |
| Count | Displays the number of occurrences of the data element. |

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-IC8QF7DH.png)
  - The **Evidence Viewer** displays the first 20 occurrences for each data element. To view all occurrences, click **Download** to download the full evidence file, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-PXXM4ILC.png)
3. Expand a data element to view its individual occurrences, as shown below. Depending on the available evidence, the expanded view provides the following information:

| Properties | Description |
| --- | --- |
| Text | Displays the detected text for the data element. |
| Context | Displays the context in which the data element was detected. |
| Sheet Name | Displays the name of the sheet containing the detected data element. |
| Record Number | Displays the record number associated with the detected data element. |
| Column Name | Displays the name of the column containing the detected data element. |
| Best Positive Anchor | Displays the anchor text associated with the detected data element, along with the distance or line information indicating its position relative to the detection. If no positive anchor term is available, the field is empty. |
| Exact Data Maches | Displays the exact data matches associated with the detected data element. |

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-L1CROIZV.png)
4. Review the **Summary** tab on the right side of the **Evidence Viewer** panel. The tab provides the following information about the evidence:

| Properties | Description |
| --- | --- |
| Scan Job ID | Displays the unique ID of the scan job that generated the evidence. For example, `fa37e39b-f6b1-4392-aa8e-1de0e8845209`. |
| Message Type | Displays the type of scan message. For example, `file-summary`. |
| Scanned Bytes | Displays the amount of data scanned during the scan job. For example, `11.6KB`. |
| Total PDs | Displays the total number of policy detections identified in the file. For example, `90`. |
| Content Profiles | Displays the content profiles matched during the scan. |
| Exact Data Profiles | Displays the exact data profiles matched during the scan. |
| Document Types | Displays the document types detected during the scan. |
| Document Categories | Displays the document categories detected during the scan. |
| Time Stamp | Displays the date and time associated with the evidence. For example, `Feb 13 2026, 6:24 pm`. |
| Full Evidence Download | Lets you download the complete evidence file. |
| Full Evidence Path | Displays the path where the evidence is stored. For example, `CC/SingleFileEvidences/83705469`. |
| Object | Displays the name of the scanned file. For example, `cc_automation_dsr.xlsx`. |
| Prefix Path | Displays the source path or URL of the scanned file. For example, `https://outlook.office365.com/owa/?ItemID=AAMkAD`. |
| Payload Version | Displays the version of the generated evidence payload. For example, `v1` |
