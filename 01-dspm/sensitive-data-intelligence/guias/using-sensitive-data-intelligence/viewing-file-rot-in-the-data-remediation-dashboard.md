# Viewing File ROT in the Data Remediation dashboard

Managing redundant, obsolete, or trivial (ROT) data across multiple systems can be complex and time-consuming when done manually. You can view all File ROT findings generated by File ROT policies in the **Data Remediation** dashboard, as shown below. For more information, see [Using Data Remediation Dashboard](/latest/docs/using-data-remediation-dashboards).
