# Supported data systems for exact data indexes

Supported data systems for exact data indexes. The following table lists the data systems that support exact data indexes, which you can use to configure exact data profiles. These profiles can then be selected during discovery scan setup to let Securiti perform exact data matching for the defined data elements.

| --- | --- | --- |
| **Structured** | Amazon Aurora for PostgreSQL | ✓ | ✓ |
| Amazon Redshift | ✓ | ✓ |

| MariaDB | ✓ | ✓ |
