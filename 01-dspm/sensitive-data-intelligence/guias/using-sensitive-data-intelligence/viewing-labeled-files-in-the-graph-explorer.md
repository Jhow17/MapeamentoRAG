# Viewing labeled files in the Graph Explorer

You can view files with applied data labeling policies in the Graph Explorer, as shown below. The Graph Explorer lets you browse labeled files, review their associated metadata, and understand how data labeling policies apply across your connected data systems, such as Google Drive.
