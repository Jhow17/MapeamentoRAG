# Viewing File Quarantine in the Data Remediation dashboard

Managing suspicious or non-compliant files across multiple data systems can be complex and time-consuming when done manually. You can view all File Quarantine findings generated by File Quarantine policies in the **Data Remediation** dashboard, as shown below. For more information, see [Using Data Remediation Dashboard](/latest/docs/using-data-remediation-dashboards).
