# Quarantining files

When a file poses a security risk or violates a data policy, quarantining it isolates the file from its original location to prevent unauthorized access or further exposure. This lets you contain the risk immediately while you investigate and determine the appropriate remediation action.

For example, a discovery scan flags a file containing unencrypted personally identifiable information (PII) that is broadly shared across the organization. You can select the file directly from the dashboard and quarantine it to restrict access until the data owner reviews and resolves the violation.

To quarantine file(s):

1. Select the file(s), and click **Quarantine**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-4XLC48SZ.png)
2. Mention the reason of quarantining file(s), and click **Quarantine File** to confirm, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-JXJOS77S.png)
