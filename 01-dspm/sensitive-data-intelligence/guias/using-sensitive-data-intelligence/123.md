# Viewing Data Labeling in the Data Remediation dashboard

Manually tracking sensitivity labels and metadata applied across multiple data systems can be complex and time-consuming. You can view all labeled files generated by Data Labeling policies in the **Data Remediation dashboard**, as shown below. For more information, see [Using Data Remediation Dashboards](/latest/docs/using-data-remediation-dashboards).
