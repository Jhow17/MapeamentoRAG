# Viewing and syncing Microsoft Purview Information Protection sensitivity labels

You can use the Microsoft Purview Information Protection (MIP) data system in Securiti to define and apply sensitivity labels and metadata to files. This works across unstructured data systems, such as Amazon S3, Azure Files, SharePoint, OneDrive, and SMB file shares. The connector applies labels based on data discovery and classification results, which supports your Data Loss Prevention (DLP) efforts and helps protect sensitive information consistently. It also synchronizes the data labeling schema from Microsoft Purview, so you can set up policies that apply labels to discovery scan results and strengthen compliance and security for sensitive data handling.

> [!NOTE]
> **Note**
> 
> You can create and apply Data Labeling policies in any organization with a configured [Microsoft Purview Information Protection (MIP)](/latest/docs/new-ui-connecting-microsoft-purview-information-protection-with-securiti) connector, not just the default organization.

To open the Microsoft Purview Information Protection page:

1. Go to **Settings**, then select **Policy Center > Classification Labels > Microsoft Purview Information Protection**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-VTZZ1MR2.png)
2. To sync labels with Microsoft Purview Information Protection, click **Sync Labels**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-PTE34JUW.png)
3. To navigate to the Microsoft Purview Information Protection, click **Purview Portal**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-JF493XGE.png)
4. To find a specific label, click **+** and select one of the following properties to filter by:
  - Label
  - Parent Name
  - Description
  - Priority
  - Protection

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-UDKPV742.png)
