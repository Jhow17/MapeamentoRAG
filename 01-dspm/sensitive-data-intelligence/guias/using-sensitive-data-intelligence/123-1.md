# Viewing labeled files in the File Labeling dashboard

You can analyze labeled files through various widgets in the File Labeling dashboard, as shown below. The dashboard lets you explore trends, review labeled file metrics, and understand how data labeling policies are applied across your connected data systems, such as Google Drive.
