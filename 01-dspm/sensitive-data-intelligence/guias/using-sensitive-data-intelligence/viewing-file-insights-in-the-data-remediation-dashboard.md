# Viewing File Insights in the Data Remediation dashboard

Managing sensitive files across multiple systems can be complex and time-consuming when done manually. You can view all File Insights findings generated by File Insights policies in the **Data Remediation** dashboard, as shown below. For more information, see [Using Data Remediation Dashboard](/latest/docs/using-data-remediation-dashboards).
