# Viewing Structured Data Insights Findings

> [!WARNING]
> Important
> 
> Securiti is transitioning the Structured Data Insights policy to a new architecture that does not generate findings. Starting with Securiti release 1.152, you can view and manage your policy outcomes on the **Data Remediation** page. You can also view data scoped by your existing Structured Data Insights policies.

The **Structured Data Insights Findings** page lets you review, investigate, and manage findings generated by Structured Data Insights policies. You can filter findings, review their status, analyze relationships in **Graph Explorer**, and perform actions such as suppressing, unsuppressing, or exporting findings.

To view Structured Data Insights findings:

1. From the upper-left corner, click the **Jewel** icon to open the main menu, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-9P69MWC5.png)
2. From the main menu, choose **Findings**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-NFYZVOIZ.png)
3. On the **Findings** page, choose **Structured Data Insights**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-5HTARHT3.png)
4. Use the filters at the top of the page to view findings by **Column Name**, **Content Profiles**, **Database Name**, **Data Elements**, **Data System**, and other properties, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-V6RT4DLD.png)
5. View the total number of **Open**, **Suppressed** and **Resolved** findings, along with their trend lines, as shown below. Each finding has one of the following statuses:

| State | Description |
| --- | --- |
| Open | A newly identified finding that requires review or action. |
| Suppressed | A finding that has been intentionally hidden after review and no longer appears in the active findings list. |
| Resolved | A finding that no longer matches the policy scope or has otherwise been resolved. If you modify the policy query, findings that fall outside the updated scope are automatically marked as **Resolved**. |

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-NLALUZPV.png)
6. You can also group findings by **Policy** or **Data System**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-FO2O9DTW.png)
7. View summary metrics at the top of the page, including the total number of Structured Data Insights policies, and the counts of open, suppressed, and resolved findings, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-KUQENZRH.png)
8. Use the **Column Selector** to show or hide columns such as **Policy Name**, **Policy ID**, **Data Scope**, **Findings**, **Severity**, and others, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-RCWMHLDT.png)
9. Click **Show Policy Metadata**, then select **Explore** to view file relationships in **Graph Explorer**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-838DVTEN.png)

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/Screenshot 2026-08-05 at 1.16.35 PM.png)
10. Expand a policy to view the structured data objects included in the policy scope, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-Z0AUWERO.png)
11. Select one or more findings to access the following options from the bulk action bar:

| Option | Description |
| --- | --- |
| Suppress | Hides the selected findings from the active findings list without deleting them. |
| Unsuppress | Restores previously suppressed findings to the active findings list. |
| Export | Exports the selected findings to a CSV file. |

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-AFYQKFL9.png)

## Suppressing findings

To suppress findings:

1. Select one or more findings, then click **Suppress**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-LHB5QMOS.png)
2. Provide a reason for suppressing the finding(s), then click **Suppress Finding**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-ESNGKT9D.png)

## Unsuppressing findings

To unsuppress findings:

1. Select one or more suppressed findings, then click **Unsuppress**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-DXHESUEF.png)
2. Provide a reason for unsuppressing the finding(s), then click **Unsuppress Finding**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-L5BA4GUS.png)

## Exporting findings

To export findings:

1. Select one or more findings, then click **Export**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-09P71WMH.png)

Securiti generates a CSV file and sends an email containing the download link after the export is complete.
