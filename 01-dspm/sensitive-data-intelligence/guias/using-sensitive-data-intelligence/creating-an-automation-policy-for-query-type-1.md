# Using Automation Templates

Automation templates let you reuse a pre-built ServiceNow or Jira ticket configuration across multiple automation policies, instead of setting up the same ticket fields from scratch each time. Securiti populates each template's fields directly from the metadata it fetches from your ticketing system, such as tables in ServiceNow and labels in Jira, so the fields you see always match what's available in your account.

To access Automation Templates:

1. From the upper-left corner, click the **Jewel** icon to open the main menu, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-SJ631CK2.png)
2. From the main menu, choose **Policies**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-860I99IQ.png)
3. On the **Policies** page, choose **Automation**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-1DZEVUNF.png)
4. Near the upper-right corner of the page, click **Options (three dots)**, then choose **Templates**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-5YYNYS8Y.png)
  - On the **Automation Templates** page, you can see the system templates for ServiceNow and Jira.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-Y9MKHO5K.png)
5. To clone a system template, click **Options (three dots)**, then choose **Clone,** as shown below. You can not edit or delete system template directly; clone it first to create an editable copy.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-TBVCCAZA.png)
6. To edit or delete a custom template, click **Options (three dots)**, then choose **Edit** or **Delete,** as shown below. For more information, see see Creating a ServiceNow task and Creating a Jira Cloud ticket.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-ZW8APEP8.png)
