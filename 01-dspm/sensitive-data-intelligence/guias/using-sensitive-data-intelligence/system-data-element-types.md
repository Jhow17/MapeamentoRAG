# System data element types

This section lists the system data elements available under Securiti platform for data classification under different categories.

In each category below, you can find the data elements falling under the customizable and special categories.

- Customizable refers to the system data elements that Securiti lets you customize according to your requirements.
- Special category refers to the data elements that reveal a data subject's racial or ethnic origin, political opinions, or religious and philosophical beliefs.

> [!NOTE]
> **Note**
> 
> The **Auto enabled (Yes/No)** column refers to the data elements enabled by default when you get onboarded to Securiti.

For more information on configuring data elements, see [Configuring custom data element types](/v1/docs/configuring-custom-data-element-types). For more information on customizing system data elements, see [Customizing system data element types](/v1/docs/data-elements-customizing-system-data-element-types).
