# Removing remediation

If a file's remediation status needs to be reversed, you can remove the previously applied remediation to restore it to active policy evaluation. This is useful when a remediation decision was made in error or when a file's classification or risk status has changed and requires reassessment.

For example, a file was previously marked as excluded after being assessed as non-sensitive, but a recent audit reveals it now contains regulated data that must be monitored. You can remove the remediation from the file to bring it back into scope for policy evaluation, ensuring it is properly flagged and tracked going forward.

To remove remediation from file(s):

1. Select the file(s), and click **Remove Remediation**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-U9W1J4F1.png)
2. Mention the reason for removing remediation from file(s), and click **Remove Remediation** to confirm, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-VB1599TX.png)
