# Accessing policy logs from the data remediation dashboard

Policy logs help you monitor and troubleshoot the execution of your policies by capturing both informational and error-level events. Accessing logs directly from the dashboard lets you quickly diagnose issues and track policy activity across your files.

To view the policy logs, near the upper right corner, click **Policy Logs** to directly go to your selected policy logs page.

For more information, see:

- [Using Data Labeling Policies](/latest/docs/using-data-labeling-policies)
- [Using File Quarantine Policies](/latest/docs/using-file-quarantine-policies)

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-O3U4IKI4.png)

- You can apply filters to policy logs using the following properties:

| Remediation Dashboard | Properties | Description |
| --- | --- | --- |
| - Data Labeling - File Quarantine - File ROT | Data System Type | Lets you filter the logs based on the type of data system where the file is located. For example, `G Suite Google Drive` |
| Data System Name | Lets you filter the logs based on the name of the data system from which the log entry is generated. For example,`John Testing` |
| Log Level | Lets you filter the logs based on the log level of the log entry. The following log levels are supported: - `Informational` - `Error` |
| File Name | Lets you filter the logs based on the name of the file associated with the log entry. For example,`John.json` |
| Timestamp | Lets you filter logs based on the exact date and time when the policy log entry was recorded. For example,`22 Jan, 2026 7:08 pm` |
| Data Labeling | Current Label | Lets you filter the logs based on the label currently applied to the file at the time of the log entry. |
| Original Label | Lets you filter the logs based on the label applied to the file before any policy or remediation action. |
| - File Quarantine - File ROT | Folder Path | Lets you filter logs based on the folder path where the file is stored within the selected data system. |
