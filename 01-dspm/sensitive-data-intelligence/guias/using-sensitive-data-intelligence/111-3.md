# Updating policies from the data remediation dashboard

Managing and adjusting policies directly from the Data Remediation dashboard saves your time by eliminating the need to navigate away to the **Policies** page. This gives you quick access to policy configuration so you can make updates without losing your current dashboard context.

To update your existing policies:

1. Near the upper right corner, click **three dots(option)** and select **Manage Policy** to directly go to your selected policy’s **Policies** page. For more information, see [Data Remediation system dashboards](/latest/docs/data-remediation-system-dashboards).
