# User Personas

Use the following table to understand the roles of different types of users and what they are responsible for using the *Sensitive Data Intelligence* module. From the **Responsibilities** column, use the links to the relative help topics to learn more about the responsibilities of the following roles.

| Role | Responsibilities |
| --- | --- |
| Cloud Engineer | - Defines standards for using cloud environments. Has experience with multiple clouds via [data system](/v1/docs/configuring-connectors-for-monitored-data-systems) connectors. - Configure Securiti to scan cloud accounts and data systems so that data can be scanned. See discovery scans for [structured](/v1/docs/discovery-scans), [unstructured](/v1/docs/discovery-scans), and [streaming](/v1/docs/discovery-scans) data systems. - Defining the Content Classification related parameters, such as [data elements](/v1/docs/data-elements), [document types](/v1/docs/configuring-document-categories-and-types), [content profiles](https://helpcenter.securiti.ai/docs/configuring-content-profiles), etc. |
| Data Analysts | - Analyze and interpret data to get meaningful insights from data explorers such as [structured](/v1/docs/structured-data-discovery-new-experience), [unstructured](/v1/docs/using-the-unstructured-data-discovery), and [streaming](/v1/docs/using-the-streaming-data-discovery-dashboard) data dashboards. - Able to create reports in different formats, such as PDFs and CSVs - Analyze the metadata and generate reporting using the [Universal Data Explorer](/v1/docs/using-the-universal-data-explorer). - They work with the Security Analysts to manage unauthorized access and risks. |
| Data Privacy Officer | - Ensuring user privacy and compliance with data protection regulations - Scanning and managing regulatory [content profiles](/v1/docs/configuring-content-profiles) |
