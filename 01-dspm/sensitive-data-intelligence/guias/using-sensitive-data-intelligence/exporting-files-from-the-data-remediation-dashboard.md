# Exporting files

Exporting files lets you download a CSV report of selected files and their associated metadata for offline analysis, compliance reporting, or sharing with stakeholders. This is especially useful when you need to document policy findings or collaborate with teams who do not have direct access to the dashboard.

For example, a compliance audit requires you to provide a record of all sensitive files flagged under a specific data labeling policy, along with their applied sensitivity labels and ownership details. You can select the relevant files, export them as a CSV, and share the downloaded report with your compliance team for review and documentation.

To export file(s):

1. Select the file(s), and click **Export**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-8CSUCYEI.png)
2. Update the file name if necessary, and click **Export CSV**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-1CP6XLYK.png)

> [!NOTE]
> Note
> 
> In the exported CSV file, the **Sensitivity Labels** column displays values in the following format:
> 
> • [PolicyId] Label Name
> 
> • [External] Label Name (if the label was applied by an external system)
3. Securiti schedules your download and displays the message **Export has been scheduled, you will receive an email with the download link when the file is ready for download**, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-VN0GHU1Z.png)
4. Open your email associated with the Securiti tenant, and click **Download File** to download the CSV file to your local machine, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/image-1781252161211.png)
