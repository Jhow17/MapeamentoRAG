# OCR-supported document types

Securiti uses OCR to extract and classify text from image files and PDF documents during discovery scans. OCR-based detection is available for specific document types, such as passports, driver licenses, and visas.

> [!WARNING]
> Important
> 
> Document type support varies by country.

Use the following table to understand the countries Securiti supports for OCR-based document scanning.

| Document type | Country |
| --- | --- |
| Birth Certificate | - Australia - China - Canada - India - New Zealand - Philippines - United Kingdom - United States - South Africa |
| Credit Card | United States |
| Driver's License | - Australia - New Zealand - United States |
| Passport | - Algeria - Australia - Austria - Bangladesh - Belgium - Bulgaria - Canada - China - Croatia - Cyprus - Czechia - Denmark - Estonia - Fiji - Finland - France - Germany - Greece - Hong Kong - Hungary - India - Ireland - Italy - Japan - Korea - Latvia - Libya - Malaysia - Morocco - New Zealand - Netherlands - Philippines - Samoa - Singapore - Somalia - South Africa - Sudan - Thailand - Tonga - Tunisia - United Kingdom - United States |
| Visa | - New Zealand |
