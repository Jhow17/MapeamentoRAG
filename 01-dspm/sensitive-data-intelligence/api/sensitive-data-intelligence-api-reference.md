# Sensitive Data Intelligence API reference

The Sensitive Data Intelligence (SDI) API documentation lets you discover, classify, and manage sensitive data across structured, unstructured, and streaming data systems. Using these APIs, you can automate discovery scans, configure policies, manage data elements and dictionaries, and export insights for reporting and compliance.

This API documentation includes operations such as:

- Create and manage discovery scans.
- Configure and manage policies, including Automation, Data Labeling, File Insights, File Quarantine, File ROT, Data Tagging, Metadata Registration, and Structured Data Insights policies.
- Create, update, retrieve, and delete data elements, dictionaries, exact data indexes, exact data profiles, content profiles, document categories, and file formats.
- Create and manage content profiles and document categories.
- Manage and explore data across data explorers, including fetching, viewing, and managing results for Validation Workbench, Structured Data discovery, Unstructured Data scans, Streaming Data, and Cluster Analysis.
- Export scan results and policy findings.

Use the Sensitive Data Intelligence [REST API documentation](https://securiti-doc-router.securiti.ai/modules/data-intelligence/apidocs/index.html#section/Getting-Started) to explore and test SDI APIs, review HTTP endpoints, JSON request and response formats, query parameters, API schemas, authentication methods, and sample API requests, and access the Postman collection for SDI operations.
