# Tag management

Tags help you organize and classify assets in Securiti platform using structured, reusable metadata. You can group tags into categories such as Data Type, Priority, or Sensitivity, and apply consistent labeling across your environment.

These tags are currently available in the **Assessment Automation** and **Data Command Graph** modules. Support for tags on other objects in Securiti platform, will be introduced in upcoming releases.

For more information, see the following articles:

- [Managing tags in Securiti](/latest/docs/managing-tags-in-securiti)
- [Applying tags to assets in Inventory](/latest/docs/applying-tags-to-assets-in-inventory)
- [Using tags to organize and filter assessments](/latest/docs/managing-assessment-tags)
