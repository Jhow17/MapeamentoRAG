# Importing organizations

You can import organizations from .csv files into Securiti using a template that you download from Securiti.

> [!NOTE]
> **Important**
> 
> Once you import organizations into Securiti, you cannot delete them; you can only deactivate them. Only import those organizations you are sure you want to use.

1. In Securiti, open **System Settings**, then choose **Organizational > Organizations**.
2. Near the upper right corner of the page, click **Import Organizations**.
3. On the Upload popup, click **Download Template** to download a .csv file template.
4. Open the template and use it as an example to build a list of the organizations to import.
5. Save the list in .csv format.
6. If you don't already have it open, in Securiti open **System Settings**, choose **Organizational > Organizations**, and once again click **Import Organizations**.
7. On the Upload popup, use the tools to select your list of organizations, then click **Upload**.

If the list of organizations in the .csv file is valid, Securiti creates organizations according to the file.

![import_organization.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-c8612880-26e0-127d-63d4-049881d9108f(3).png)
8. Refresh the browser window to view the new organizations in the list.
