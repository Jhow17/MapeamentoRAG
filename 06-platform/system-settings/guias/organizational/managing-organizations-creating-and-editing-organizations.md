# Creating and editing organizations

> [!NOTE]
> **Important**
> 
> You cannot delete organizations once you create them; you can only deactivate them. Once you deactivate the organization, all of its elements or properties become read-only. You may be able to move or copy them to a different organization, but you can no longer change them.

1. Log in to Securiti with your super admin credentials (only super admins can create new organizations).
2. Open **System Settings** and choose **Organizational > Organizations**.
3. On the Organizations page, do one of the following:
  - To create a new organization, near the upper right corner of the page click **+**.
  - To edit an existing organization, at the right end of its tile choose **Options** (three dots) **> Edit**.
4. On the Add an Organization or Update an Organization popup, apply the following settings, then click **Add Organization** or **Update**.

| Organization Name | Enter a convenient name. |
| --- | --- |
| Description | Enter a convenient description. |
| Accessible Domains | (Optional) Use the tools to build a list of domains whose users can access the organization and its resources. With the exception of Super Admins and Securiti support users, only users whose email addresses are within the listed domains can access the organization. This setting overrides organization membership configured for each user on their User Detail panel. If you do not list any domains, users from all domains can access the organization. |
