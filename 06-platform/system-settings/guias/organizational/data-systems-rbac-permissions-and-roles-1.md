# Data Systems RBAC permissions and roles

The new Role-Based Access Control (RBAC) framework provides fine-grained permissions for data system connectors. It introduces a set of system-generated roles with predefined permissions, while also allowing you to create custom roles with data system–specific permissions. Custom roles can include permissions that are linked to other related permissions, creating dependencies and ensuring consistent access control. In contrast, system-generated roles automatically inherit the specific permissions defined for them.

## Accessing Data Systems permissions

To navigate to Data Systems RBAC permissions in Securiti platform, follow the steps provided below:

1. From the upper left corner of the left navigation bar, click the **Jewel** icon, and choose **Settings** from the left navigation bar. ![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/data-systems-rbac-permissions-and-roles-image-z9g70rwr.png)
2. Under the **Organizational**, choose **Access Management > Roles**.
3. On the **Roles** page, select **+ Create Role**. ![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/data-systems-rbac-permissions-and-roles-image-nrnyemzw.png)
4. Under the **Permissions** section, click the **Data Systems** tab to access the permissions, as shown below.

![](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/data-systems-rbac-permissions-and-roles-image-3idakh1s.png)

## Data System permissions with custom roles

Securiti lets you select fine-grained permissions for each custom role you create in the Platform.

**Definitions**

- **Permission**: It is a parent permission that grants specific rights to perform certain actions within the system. For example, `View Data System`, `Update Keying`, and `Delete Data System Driver`.
- **Explanation:** Describes why the permission is needed and the context in which it is used. For example, the Create and Activate Data System permission is required to create a data system and activate its connector.
- **Dependent permissions:** These are a set of permissions that are automatically applied in the same or different modules when a parent permission is selected.

This table lists the Data Systems permissions, explains the actions each permission allows, and specifies any dependent permissions that are automatically applied.
