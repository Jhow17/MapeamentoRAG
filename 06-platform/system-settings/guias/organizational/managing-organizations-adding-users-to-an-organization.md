# Adding users to an organization

> [!NOTE]
> **Important**
> 
> You can add users to organizations, but you cannot remove them.

1. Log in to Securiti with your super admin or organization admin credentials.
  - As a super admin, you can add users to any organization.
  - As an organization admin, you can add users to any organization you belong to, with roles limited to “Organization Admin” or “User” only.
2. In Securiti, open **System Settings** and choose **Organizational > Users**.
3. For each user you want to add to the new organization, click **Edit** (three dots) and choose **Edit User**.
4. On the User Detail tab, near the bottom, in the Organizations area, use the tools to build a list of Organizations to which the user belongs.

![add_orgs_to_users.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-fd643e72-3783-577f-46b3-9e2ca590e7b9(3).png)
5. When you are done, click **Save**.
