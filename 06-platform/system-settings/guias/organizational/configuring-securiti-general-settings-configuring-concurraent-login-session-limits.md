# Configuring concurrent login session limits

By default, Securiti limits users to a specific number of concurrent logins on different browsers or machines. If a user tries to exceed the limit, Securiti shows them an alert and denies the login. The alert has a button that lets the user force logouts for all their active sessions as shown below.

![RN_login_sessions1.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-ad0d43af-79ba-ade3-f5ad-6010575ca537(6).png)

To configure the concurrent log in session limit:

1. If you haven't already done so, log in to Securiti with your admin credentials
2. in Securiti click **Settings** and choose **Organizational > General**.
3. Near the upper right corner of the page, click **Edit** (pencil icon).
4. In the Security Contact area, use the Concurrent User Login Sessions tools as shown below to set the maximum number of concurrent sessions and the message that Securiti displays when users try to exceed the limit.

![RN_login_sessions2.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-6a4e7a1a-8e8e-c52e-f2ad-e222cb34d0b3(3).png)
5. Scroll to the top of the page and click **Save**.
