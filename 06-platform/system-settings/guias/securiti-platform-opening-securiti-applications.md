# Opening Securiti applications

Use the Securiti application navigator to open the various Securiti apps:

1. On the left navigation under the **Apps**, choose the application you want to open.

![Dashboard displaying security findings, asset posture scores, and compliance applications overview.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/open-apps.png)
2. Once you have opened an application, use its menu as shown below (Sensitive Data Intelligence shown, other applications similar).

![Overview of data systems, hosting options, and scanned data metrics in a dashboard.](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/sidebar.png)

### Supported web browsers

To ensure smooth and seamless access to all the advanced functionalities of the Securiti platform on your system, make sure that you are using the supported browser to access the platform. Securiti supports the following web browser versions:

- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari 10+
  - Safari 9 (supported with Polyfill)
- Internet Explorer 11 (supported with Polyfill)

> [!NOTE]
> **Note**
> 
> Securiti does not support the older versions of Internet Explorer and Safari. You cannot use those versions to access the Securiti platform.

### Edit the navigation settings

**Using the navigation, Securiti lets you edit the default landing page and order of services and applications within the list. Let’s begin by setting the platform landing page first.**

#### Set the platform landing page

Securiti lets you set a platform landing page that appears when you log in.

To update the default landing, perform the following steps.

1. On the top right in the navigation sidebar, click **Edit**.

![click-edit.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-73ab0bde-fba7-429e-0455-7fe6fe8e3776(3).png)
2. Scroll down to see the list of apps or services.
3. Click the **Home** icon next to the service or app you want to set as your landing page.

![select-default-page.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-9b250b3b-a4a0-fdd5-968d-d700506be993(3).png)
4. On top of the Navigation, click **Save**.
5. On the top left of the Securiti portal, click the **Jewel** icon to see the selected landing page.

#### Set the landing page for apps

Securiti lets you select the landing page for each app that appears in the navigation list.

To set the landing for apps, perform the following steps:

1. In the Edit mode, locate the app for which you want to set a landing page.
2. Hover over the selected app.

It opens a new app menu.
3. On the app menu, scroll down to see the page options.
4. Click the Home icon right next to the page you want to set as a landing page for the specific app.

In the example screenshot shared below, we have set **By Data System** as the default page for the **Enterprise Data Catalog** app.

![hoveroverapp.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-c35c2f52-1394-03a2-1943-01b18bc2da34(3).png)
5. On top of the navigation, click **Save**.

It saves the newly selected landing page for the app.
6. On the navigation bar, open the Sensitive Data Intelligence app.

It shows you the **By Data System** as a landing page for your **Enterprise Data Catalog** app.

![by-data-system-preview.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-16699f4e-d23b-90dd-52ed-14264624b36a(3).png)

#### Reorder the apps

You can rearrange the applications in the menu. It lets you bring the frequently used applications to the top:

1. Open the navigation bar and click **Edit**.
2. Locate the app or service you want to reorder.
3. Click and hold the **six-dot** icon next to each application.
4. Drag the application up or down to reorder it within your list.

> [!NOTE]
> **Note**
> 
> You can’t place the services into apps and vice versa.
> 
> In the screenshot below, **Inventory** is being reordered to the end of services.

![dragapp.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-78004a7b-3256-8b1b-efc1-a044e8edfaca(3).png)

![drag_app_2.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-8dd8585b-6796-c46d-ec10-d9b0a365d7bd(3).png)
5. Click **Save**.

It saves your reordered list of services and apps according to your preference.
