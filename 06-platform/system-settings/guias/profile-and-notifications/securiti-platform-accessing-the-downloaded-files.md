# Accessing the downloaded files

You can access all the files downloaded across the platform on a single page in the platform. You can then download the required files to your system from the list.

### Viewing the downloaded files

1. In Securiti, near the bottom of the left navigation bar, click your avatar and click on **My Downloads**.
2. You can view the list of all the downloaded files along with file details such as file name, file format, module, export type and file size. Click on the download button against the file to download the file to your system.

![download-files.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-1668e91e-1769-d2e5-c8fc-9f981e593607(3).png)
3. You can also search the files by entering the file name or by applying filters and fetching the files by their file format, name, module, export type, creation time or expiration time.

![downloads-filters.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-226b04a7-3c2e-775f-ef4e-7c6d2570350a(3).png)

### Delete the downloaded files

#### Delete a single file

1. In Securiti, near the bottom of the left navigation bar, click your avatar and click on **My Downloads**.
2. To delete a specific file, click on the bin sign against the file that you need to delete.

![delete-button.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-92bd35ae-3919-85be-27a6-5f8e1197151d(3).png)
3. Click on **Delete file** from the confirmation pop-up to confirm deletion.

![delete-single-file.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-1bccfdd9-7a0d-ea10-a116-6b08ba920920(3).png)

#### Delete multiple files

1. In Securiti, near the bottom of the left navigation bar, click your avatar and click on **My Downloads**.
2. Mark the checkboxes against the files that you need to delete.
3. From the top right of the page, click on **Actions** and select **Delete** to delete the selected files.
4. Click on **Delete files** from the confirmation pop-up to confirm deletion of multiple files.

![delete-multiple-files.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-8797eba9-af6b-f6a0-807a-29c564feba84(3).png)
