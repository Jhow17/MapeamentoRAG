# Metering dimensions

This topic lists potential metrics by the different Securiti platform modules. Although they are listed by module, some of these are reused across modules.

### Data Mapping

- Number of assets
- Number of processing activities
- Number of assessments

### Assessments

- Evidence storage GB

### Cookie consent

- Number of websites and banners
- Number of monthly unique website visitors
- Number of consent records

### Universal Consent

- Number of consent collection endpoints
- Number of preference centers
- Number of consent records
- Number of monthly unique website visitors

### DSR Portal and Workbench

- Number of webforms
- Number of data subjects
- Number of ID verifications

### DSR Fulfillment Automation

- Number of data systems

### Data Breach Management

- Number of incidents

### Vendor Risk Management

- Number of vendors
- Number of vendor assessments
- Evidence storage GB

### Sensitive Data Intelligence

- Data scanning capacity GB
- Number of pods
- Number of SDI credits
- Number of data systems
- Data volume GB

### Sensitive Data Protection

- Number of pods
- Number of SDP credits
- Number of data systems
- Data volume GB

### Workflows

- Number of external workflow endpoints
- Number of workflows
- Number of executions
- Number of pods

### Consulting packs

- Number of data systems
- Number of pods

### Flat Listing

- Number of assets
- Number of processing activities
- Number of assessments
- Evidence storage GB
- Number of websites and banners
- Number of monthly unique website visitors
- Number of consent records
- Number of consent collection endpoints
- Number of preference centers
- Number of webforms
- Number of data subjects
- Number of ID verifications
- Number of data systems
- Number of incidents
- Number of vendors
- Number of pods
- Data volume GB
- Number of SDI credits
- Number of SDP credits
- Number of external workflow endpoints
- Number of workflows
- Number of executions
