# Using saved filters

After you apply filters as described in [Filtering Securiti pages and dashboards](/v1/docs/filtering-securiti-pages-and-dashboards), you can save the filter configuration and load it again later. This feature makes it easy re-apply specific filter sets to your view of the current data. See the following secions for details.

### Saving and loading filters

To save a filter configuration:

1. Apply a set of filters as described in [Filtering Securiti pages and dashboards](/v1/docs/filtering-securiti-pages-and-dashboards).
2. At the top of the filter panel where it lists the number of active filters, choose **Options > Save filter as**.

![D00009.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-ae6ac557-b088-b56e-3f44-b26c2a5e8600(3).png)
3. On the Save new filter box, enter a name. You can also enter an optional description that helps you remember the filter.

![D00010.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-5e161e57-a814-faec-4a10-32178e5facc6(3).png)
4. Click **Save**.

Securiti shows you the saved filter name on the filter banner.

To load a filter configuration that you have previously saved:

1. In the DSR workspace, open the filter panel.
2. On the active filter banner just below the top of the filter panel, click the icon at the right end of the banner and choose **Load Filters** as shown below.

![D00011.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-06526c89-a32d-7649-1a6f-70326c798e69(3).png)
3. Choose the filter from the menu, then click **Done**.

### Modifying a saved filter

1. Load the filter you want to modify as described in Saving and loading filters section above.

Securiti shows you the filter name on the filter banner.
2. Use the filters panel to add or modify filter criteria.

After you make changes, Securiti shows a delta icon on the banner to show that the current filter settings differ from the saved filter.

![D00012.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-246bf219-2f5f-8656-cdef-9901e314813e(3).png)
3. On the banner, choose **Options > Save**.

![D00013.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-4bceb7e9-e1ea-b4aa-076c-85ed10db7f0b(3).png)

Securiti updates the saved filter to match the criteria you selected.

### Cloning a filter

1. Load the filter you want to clone.

Securiti shows you the filter name on the filter banner.
2. Change the filter criteria to suit.
3. On the filter banner, choose **Options > Clone Saved Filter**.

![D00014.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-2ddef66e-2453-d0e7-3a9c-b6a5ee41d83b(3).png)
4. On the Save New Filter box, give the clone a new name and description, then click **Save**.

### Detaching a saved filter

Detaching filter criteria from a saved filter makes it easier for you to create a new filter based on the settings of a previously saved filter.

1. Load the filter you want to detach.

Securiti shows you the filter name on the filter banner.
2. On the filter banner, choose **Options > Detach from saved filter**.

![D00015.png](https://cdn.us.document360.io/37f15d15-eeac-4caf-9724-25918cca6992/Images/Documentation/uuid-c2337da1-e188-e73c-38c9-8b4ec72e7d0e(3).png)

Securiti detaches the criteria from the saved filter, and removes the filter name from the banner to show you that the current filter criteria are separate from any saved filter.
3. Change the filter criteria to suit.
4. If you want, save the filter.

A set of criteria that focuses your view by eliminating elements that fall outside the scope of interest. When you filter Securiti pages and dashboards, you choose criteria in the filter panel to reduce the number of elements Securiti displays to just those of interest.
